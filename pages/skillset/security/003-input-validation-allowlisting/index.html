Strict Input Validation & Allowlisting

Every HTTP request, header, path variable, and message payload is untrusted. Enforce declarative Jakarta Bean Validation constraints (@Valid, @Pattern, @Size, @Positive) on immutable request records so malformed inputs fail fast at the controller boundary.

public record CreateTransferRequest(
    @NotBlank
    @Pattern(regexp = "^[A-Z]{2}[0-9]{2}[A-Z0-9]{11,30}$", message = "Invalid IBAN format")
    String destinationIban,

    @NotNull
    @Positive
    @DecimalMax("50000.00")
    BigDecimal amount,

    @Size(max = 140)
    String reference
) {}

@RestController
@RequestMapping("/transfers")
@Validated
public class TransferController {
    @PostMapping
    public ResponseEntity<TransferDto> create(@Valid @RequestBody CreateTransferRequest req) {
        return ResponseEntity.status(HttpStatus.CREATED).body(service.transfer(req));
    }
}
