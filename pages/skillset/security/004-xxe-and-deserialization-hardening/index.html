XXE & Deserialization Hardening

Default XML parsers expand external entities (SYSTEM "file:///etc/passwd"), leading to local file disclosure and SSRF. Raw Java ObjectInputStream deserialization executes gadget chains leading to Remote Code Execution (RCE). Disable DTDs in XML parsers and use typed JSON records or ObjectInputFilter.

// HARDENED XML PARSER: Disable DOCTYPE declarations and external entities (XXE defense)
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
dbf.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true);
dbf.setFeature("http://xml.org/sax/features/external-general-entities", false);
dbf.setFeature("http://xml.org/sax/features/external-parameter-entities", false);
dbf.setXIncludeAware(false);
dbf.setExpandEntityReferences(false);

// HARDENED JAVA DESERIALIZATION: Enforce a strict class allowlist filter (Java 9+)
ObjectInputFilter allowlistFilter = ObjectInputFilter.Config.createFilter(
    "com.example.dto.*;java.base/*;maxdepth=5;maxarray=1000;!*"
);
try (ObjectInputStream ois = new ObjectInputStream(inputStream)) {
    ois.setObjectInputFilter(allowlistFilter);
    SafePayload payload = (SafePayload) ois.readObject();
}
