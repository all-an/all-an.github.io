Webhook HMAC Verification & Replay Defense

Incoming webhooks (Stripe, GitHub, payment gateways) can be forged or replayed by an attacker unless you verify the HMAC-SHA256 signature over timestamp + "." + rawBody, reject timestamps outside a 5-minute window, and record the event ID in Redis to block duplicates.

public void verifyWebhookOrThrow(String signatureHeader, String timestampHeader, String rawBody) {
    long timestamp = Long.parseLong(timestampHeader);
    long now = Instant.now().getEpochSecond();
    if (Math.abs(now - timestamp) > 300) { // 5-minute replay tolerance window
        throw new SecurityException("Webhook timestamp outside tolerance window");
    }

    String signedPayload = timestampHeader + "." + rawBody;
    String expectedHmac = computeHmacSha256Hex(webhookSecret, signedPayload);

    if (!MessageDigest.isEqual(
            expectedHmac.getBytes(StandardCharsets.UTF_8),
            signatureHeader.getBytes(StandardCharsets.UTF_8))) {
        throw new SecurityException("Invalid webhook HMAC signature");
    }
}
