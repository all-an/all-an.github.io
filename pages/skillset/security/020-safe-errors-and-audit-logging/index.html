Safe Error Handling & Tamper-Evident Audit Logs

Returning stack traces or SQL error messages to clients gives attackers schema names and library versions, while logging raw user input enables CRLF log injection and PII leaks. Return generic RFC 7807 ProblemDetail responses and sanitize/redact all logged values.

@RestControllerAdvice
public class GlobalSecurityExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(GlobalSecurityExceptionHandler.class);

    @ExceptionHandler(Exception.class)
    public ProblemDetail handleUnexpected(Exception ex, HttpServletRequest req) {
        String correlationId = UUID.randomUUID().toString();
        // Sanitize CR/LF from request path to prevent log forging
        String safePath = req.getRequestURI().replaceAll("[\r\n]", "_");
        log.error("correlationId={} path={} unexpected error", correlationId, safePath, ex);

        ProblemDetail problem = ProblemDetail.forStatusAndDetail(
            HttpStatus.INTERNAL_SERVER_ERROR,
            "An internal error occurred. Reference ID: " + correlationId
        );
        problem.setTitle("Internal Server Error");
        return problem;
    }
}
