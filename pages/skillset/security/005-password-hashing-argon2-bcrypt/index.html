Adaptive Password Hashing (Argon2id / BCrypt)

Fast cryptographic hashes like MD5 or unsalted SHA-256 can be cracked at billions of hashes per second on GPUs. Always store passwords using a memory-hard, automatically salted key-derivation function such as Argon2id (OWASP #1 recommendation) or BCrypt.

@Configuration
public class PasswordSecurityConfig {

    // Argon2id resists both GPU cracking (memory-hard) and side-channel timing attacks
    @Bean
    public PasswordEncoder passwordEncoder() {
        int saltLength = 16;   // 128-bit random salt per password
        int hashLength = 32;   // 256-bit output tag
        int parallelism = 1;
        int memoryKb = 65536;  // 64 MB memory cost
        int iterations = 3;
        return new Argon2PasswordEncoder(saltLength, hashLength, parallelism, memoryKb, iterations);
    }
}

// Usage in registration & login verification:
String passwordHash = passwordEncoder.encode(rawPassword);
boolean matches = passwordEncoder.matches(candidatePassword, user.getPasswordHash());
