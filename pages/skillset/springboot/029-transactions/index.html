Transactions

@Transactional wraps a method in a database transaction that commits on success and rolls back on a runtime exception, keeping multi-step writes atomic.

@Service
public class OrderService {
    @Transactional // commit at method end, rollback on RuntimeException
    public Order place(Cart cart) {
        Order order = orders.save(Order.from(cart));
        inventory.reserve(cart.items()); // both succeed or both roll back
        return order;
    }
}
