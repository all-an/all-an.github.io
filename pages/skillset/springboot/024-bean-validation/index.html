Bean validation

Jakarta Bean Validation constraints (@NotBlank, @Size, @Email…) on a request object plus @Valid on the parameter reject bad input automatically with a 400.

public record Signup(
    @NotBlank String name,
    @Email String email,
    @Size(min = 8) String password) {}

@PostMapping("/signup")
public User signup(@Valid @RequestBody Signup form) {
    return service.register(form); // only runs if valid
}
