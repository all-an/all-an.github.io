What is Spring Boot

Spring Boot builds stand-alone, production-grade Spring applications with minimal setup. It favours convention over configuration, bundling an embedded server and opinionated defaults so you can just run your app.
You write a class with main, and Boot wires the rest.

// The whole application in one file
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
