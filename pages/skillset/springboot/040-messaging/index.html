Messaging

Boot integrates message brokers for asynchronous, decoupled communication. A @KafkaListener (or RabbitMQ listener) consumes messages as they arrive.

@Component
public class OrderEventsListener {
    // Invoked for each message on the topic
    @KafkaListener(topics = "orders", groupId = "billing")
    public void onOrder(OrderEvent event) {
        billing.charge(event.orderId());
    }
}
