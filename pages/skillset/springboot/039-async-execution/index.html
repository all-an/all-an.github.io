Async execution

@Async runs a method on a separate thread pool, returning immediately or a CompletableFuture — useful for fire-and-forget work like sending email.

@Service
public class MailService {
    @Async // runs off the caller's thread
    public CompletableFuture<Void> send(Email email) {
        client.deliver(email);
        return CompletableFuture.completedFuture(null);
    }
}
// Enable with @EnableAsync on a configuration class
