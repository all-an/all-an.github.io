Request & response body

@RequestBody deserializes the incoming JSON into a Java object; return values are serialized back to JSON by Jackson. On @RestController this is implicit.

public record CreateUser(String name, String email) {}

@PostMapping("/users")
public User create(@RequestBody CreateUser dto) {
    // JSON body -> CreateUser; returned User -> JSON response
    return service.register(dto.name(), dto.email());
}
