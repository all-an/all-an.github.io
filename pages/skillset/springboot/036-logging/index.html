Logging

Boot uses SLF4J over Logback by default. Log levels are configurable per package in properties, and you log through the SLF4J API in code.

logging:
  level:
    root: INFO
    com.example.store: DEBUG      # verbose for your package
    org.springframework.web: WARN
  pattern:
    console: "%d{HH:mm:ss} %-5level %logger{36} - %msg%n"
