Spring Initializr

Spring Initializr (start.spring.io) generates a ready-to-run project skeleton. Pick your build tool, language, Boot version and starters, and it produces a zip you can open and run.

# Generate a project from the command line
curl https://start.spring.io/starter.zip \
  -d dependencies=web,data-jpa,postgresql \
  -d type=maven-project \
  -d javaVersion=21 \
  -o demo.zip

unzip demo.zip && ./mvnw spring-boot:run
