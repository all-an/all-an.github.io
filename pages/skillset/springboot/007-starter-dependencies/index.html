Starter dependencies

Starters are curated dependency bundles. Adding spring-boot-starter-web pulls in Spring MVC, Jackson and an embedded Tomcat with compatible versions — no version juggling.

<!-- One line brings a whole, version-aligned stack -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
