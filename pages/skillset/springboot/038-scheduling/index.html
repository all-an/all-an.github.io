Scheduling

@Scheduled runs a method on a fixed rate, fixed delay or cron expression — handy for background jobs like cleanups and reports.

@Component
public class ReportJob {
    @Scheduled(cron = "0 0 2 * * *") // every day at 02:00
    public void nightlyReport() {
        // generate and send the report
    }
}
// Activate with @EnableScheduling on a configuration class
