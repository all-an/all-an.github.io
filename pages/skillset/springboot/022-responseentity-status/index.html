ResponseEntity & status

ResponseEntity gives full control over the status code, headers and body of a response, for cases where the default 200 OK is not enough.

@PostMapping("/users")
public ResponseEntity<User> create(@RequestBody CreateUser dto) {
    User saved = service.register(dto);
    return ResponseEntity
        .status(HttpStatus.CREATED)              // 201
        .header("Location", "/users/" + saved.id())
        .body(saved);
}
