Method security

Method-level security guards individual methods with SpEL expressions. @PreAuthorize checks roles or authorities before the method runs.

@Service
public class AdminService {
    @PreAuthorize("hasRole('ADMIN')")
    public void deleteUser(Long id) {
        // Only callable by principals with ROLE_ADMIN
    }
}
// Switch on with @EnableMethodSecurity on a @Configuration class
