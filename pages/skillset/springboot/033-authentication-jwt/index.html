Authentication & JWT

For stateless APIs, clients send a JWT bearer token that Spring Security validates as an OAuth2 resource server, establishing the authenticated principal per request.

@Bean
public SecurityFilterChain api(HttpSecurity http) throws Exception {
    http.authorizeHttpRequests(a -> a.anyRequest().authenticated())
        // Validate incoming JWTs against the configured issuer
        .oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults()));
    return http.build();
}
