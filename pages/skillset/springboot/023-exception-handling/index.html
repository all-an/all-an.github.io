Exception handling

@ControllerAdvice with @ExceptionHandler centralizes error handling across controllers, mapping exceptions to clean HTTP responses (e.g. RFC 7807 ProblemDetail).

@ControllerAdvice
public class ApiExceptionHandler {
    @ExceptionHandler(NotFoundException.class)
    public ProblemDetail handleNotFound(NotFoundException ex) {
        // Maps the exception to a 404 with a structured body
        return ProblemDetail.forStatusAndDetail(
            HttpStatus.NOT_FOUND, ex.getMessage());
    }
}
