Query methods

Spring Data derives queries from method names (findByEmail) and lets you write explicit JPQL or SQL with @Query when names get unwieldy.

public interface OrderRepository extends JpaRepository<Order, Long> {
    // Derived straight from the method name
    List<Order> findByStatusAndTotalGreaterThan(Status status, BigDecimal min);

    @Query("select o from Order o where o.customer.id = :id")
    List<Order> findForCustomer(@Param("id") Long id);
}
