Profiles

Profiles let one build behave differently per environment. Beans and property files can be profile-specific; activate with spring.profiles.active.

@Configuration
@Profile("dev") // only active when the 'dev' profile is on
public class DevDataConfig {
    @Bean
    public DataSource dataSource() {
        return new EmbeddedDatabaseBuilder().build(); // in-memory H2
    }
}
