Database migration

Tools like Flyway apply versioned SQL migrations at startup so your schema evolves in lockstep with the code — tracked, ordered and repeatable across environments.

CREATE TABLE users (
    id     BIGSERIAL PRIMARY KEY,
    email  VARCHAR(255) NOT NULL UNIQUE,
