Auto-configuration

Auto-configuration inspects the classpath and your properties, then configures beans automatically — a DataSource if a JDBC driver is present, a web server if Spring MVC is. Conditions back off when you define your own.

// Boot backs off its defaults when you declare your own bean
@Configuration
public class AppConfig {
    @Bean
    public ObjectMapper objectMapper() {
        return new ObjectMapper().findAndRegisterModules();
    }
}
