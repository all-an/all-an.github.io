Spring IoC container

At the heart of Spring is the Inversion of Control (IoC) container. It creates, wires and manages your objects — called beans — so classes declare what they need instead of constructing it themselves.

// The container builds and injects beans for you
@Service
public class OrderService {
    private final PaymentGateway gateway;

    // Spring supplies the PaymentGateway bean
    public OrderService(PaymentGateway gateway) {
        this.gateway = gateway;
    }
}
