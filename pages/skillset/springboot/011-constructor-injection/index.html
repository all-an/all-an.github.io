Constructor injection

Injecting dependencies through the constructor makes them final and mandatory, yields immutable, easily testable objects, and needs no annotation on a single constructor.

@Service
public class ReportService {
    private final Repo repo;
    private final Clock clock;

    // All dependencies supplied at construction — no nulls, easy to mock
    public ReportService(Repo repo, Clock clock) {
        this.repo = repo;
        this.clock = clock;
    }
}
