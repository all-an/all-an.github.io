Caching

The caching abstraction memoizes method results. @Cacheable stores a return value keyed by arguments; @CacheEvict clears it. Backed by a provider like Caffeine or Redis.

@Service
public class CatalogService {
    @Cacheable("products") // repeated calls with the same id hit the cache
    public Product findById(Long id) {
        return repository.findById(id).orElseThrow();
    }
}
// Enable with @EnableCaching on a configuration class
