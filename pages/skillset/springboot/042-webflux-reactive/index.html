WebFlux / reactive

Spring WebFlux is the reactive, non-blocking web stack built on Project Reactor. Endpoints return Mono (0–1) or Flux (0–N), scaling to many connections with few threads.

@RestController
public class PriceController {
    private final WebClient client;

    @GetMapping("/prices/{symbol}")
    public Mono<Price> price(@PathVariable String symbol) {
        // Non-blocking call; the thread is freed while awaiting
        return client.get().uri("/quote/{s}", symbol)
            .retrieve().bodyToMono(Price.class);
    }
}
