Entity mapping

A JPA @Entity maps a class to a database table. @Id marks the primary key and @GeneratedValue lets the database generate it.

@Entity
@Table(name = "users")
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true)
    private String email;
}
