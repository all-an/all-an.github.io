REST controller

@RestController marks a class whose methods return data serialized straight to the HTTP response body (JSON by default) — the standard way to build REST APIs.

@RestController
@RequestMapping("/api/users")
public class UserController {
    private final UserService users;

    public UserController(UserService users) { this.users = users; }

    @GetMapping
    public List<User> all() { return users.findAll(); }
}
