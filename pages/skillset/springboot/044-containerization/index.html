Containerization

Boot builds optimized OCI container images without a Dockerfile using Cloud Native Buildpacks, layering dependencies and classes for efficient rebuilds and deploys.

# Build a layered container image via buildpacks
./mvnw spring-boot:build-image \
  -Dspring-boot.build-image.imageName=store:latest

# Run it
docker run -p 8080:8080 store:latest
