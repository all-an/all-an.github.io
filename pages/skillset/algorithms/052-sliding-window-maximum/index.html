Sliding window maximum

Medium Sliding Window / Deque

Given an array and a window size k, slide the window one step at a time from left to right and report the maximum of each window — for [1, 3, -1, -3, 5, 3, 6, 7] and k = 3 the answer is [3, 3, 5, 5, 6, 7]. A monotonic deque makes it O(n).

Approach

Recomputing each window's maximum costs O(n·k). Instead keep a deque of indices whose values are in decreasing order. For each new element: (1) drop the front index if it has slid out of the window; (2) pop from the back every index whose value is not larger than the new element — those can never be a maximum while the new one is in the window; (3) push the new index. The front of the deque is now always the index of the current window's maximum.

Every index is pushed once and popped at most once, which is why the total work is linear despite the inner while loop.

Java

// Monotonic deque of indices (values decreasing): the front is the window max.
static int[] maxSlidingWindow(int[] numbers, int k) {
    int n = numbers.length;
    if (n == 0) return new int[0];
    int[] maximums = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        if (!deque.isEmpty() && deque.peekFirst() <= i - k) {
            deque.pollFirst(); // the front index left the window
        }
        while (!deque.isEmpty() && numbers[deque.peekLast()] <= numbers[i]) {
            deque.pollLast();  // smaller values can never be the maximum again
        }
        deque.offerLast(i);
        if (i >= k - 1) {
            maximums[i - k + 1] = numbers[deque.peekFirst()];
        }
    }
    return maximums;
}

JavaScript

// Monotonic deque of indices (values decreasing): the front is the window max.
function maxSlidingWindow(numbers, k) {
  const deque = []; // indices; shift() from the front, pop() from the back
  const maximums = [];
  for (let i = 0; i < numbers.length; i++) {
    if (deque.length > 0 && deque[0] <= i - k) {
      deque.shift(); // the front index left the window
    }
    while (deque.length > 0 && numbers[deque[deque.length - 1]] <= numbers[i]) {
      deque.pop();   // smaller values can never be the maximum again
    }
    deque.push(i);
    if (i >= k - 1) {
      maximums.push(numbers[deque[0]]);
    }
  }
  return maximums;
}

Complexity

  • Time O(n) — each index enters and leaves the deque once
  • Space O(k) — the deque holds at most k indices

A max-heap also works (O(n log n)), removing stale entries lazily. The deque approach is the classic answer, and mirroring it with "greater" flipped gives the sliding-window minimum.
