Jump game (greedy)

Medium Greedy

Each array element is the maximum jump length from that position. Starting at index 0, can you reach the last index? [2, 3, 1, 1, 4] — yes; [3, 2, 1, 0, 4] — no, you always get stuck at the 0.

Approach

You do not need to explore every path. Sweep left to right keeping farthest, the furthest index you could possibly reach so far. At index i: if i > farthest, that position is unreachable, so the answer is false. Otherwise update farthest = max(farthest, i + jumps[i]). If the sweep completes, the last index was reachable.

This is a greedy solution: reachable positions always form a contiguous range starting at 0, so a single number summarises everything you need. The brute-force alternatives (recursion, or DP over reachable indices) are O(2ⁿ) and O(n²).

Java

// Greedy: track the farthest index reachable so far.
static boolean canJump(int[] jumps) {
    int farthest = 0;
    for (int i = 0; i < jumps.length; i++) {
        if (i > farthest) return false;            // stuck: index i can never be reached
        farthest = Math.max(farthest, i + jumps[i]);
    }
    return true;
}

JavaScript

// Greedy: track the farthest index reachable so far.
function canJump(jumps) {
  let farthest = 0;
  for (let i = 0; i < jumps.length; i++) {
    if (i > farthest) return false;            // stuck: index i can never be reached
    farthest = Math.max(farthest, i + jumps[i]);
  }
  return true;
}

Complexity

  • Time O(n) — a single left-to-right pass
  • Space O(1) — one variable

The follow-up "Jump Game II" asks for the minimum number of jumps; it uses the same reach idea, counting a jump each time the sweep passes the end of the current range.
