0/1 Knapsack (DP)

Medium Dynamic Programming

You have items with weights and values and a bag of limited capacity. Choose a set of items — each used at most once — to maximise total value without exceeding the capacity. The "0/1" means each item is taken whole or not at all.

Try it

↓

Approach

Let best[i][w] be the maximum value using the first i items with capacity w. For item i, either skip it (best[i − 1][w]) or, if it fits, take it (best[i − 1][w − weight] + value); keep the larger.

Because row i only reads row i − 1, the table collapses to a single array — but you must loop the capacity downward (from capacity to the item's weight). Going upward would let an item be reused within the same round, turning it into the unbounded knapsack.

Java

// 1-D DP: best[w] = max value with capacity w. Loop w downward so each item is used once.
static int knapsack(int[] weights, int[] values, int capacity) {
    int[] best = new int[capacity + 1];
    for (int item = 0; item < weights.length; item++) {
        for (int w = capacity; w >= weights[item]; w--) {
            best[w] = Math.max(best[w], best[w - weights[item]] + values[item]);
        }
    }
    return best[capacity];
}

JavaScript

// 1-D DP: best[w] = max value with capacity w. Loop w downward so each item is used once.
function knapsack(weights, values, capacity) {
  const best = new Array(capacity + 1).fill(0);
  for (let item = 0; item < weights.length; item++) {
    for (let w = capacity; w >= weights[item]; w--) {
      best[w] = Math.max(best[w], best[w - weights[item]] + values[item]);
    }
  }
  return best[capacity];
}

Complexity

  • Time O(n × W) — n items, capacity W — pseudo-polynomial
  • Space O(W) — the single-row table

The running time depends on the numeric value of the capacity, so it is called pseudo-polynomial; the general problem is NP-hard. Related problems — subset sum, partition equal subset sum, target sum — are knapsack in disguise.
