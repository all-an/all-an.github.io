Median of two sorted arrays

Medium–Hard Binary Search / Divide & Conquer

Given two sorted arrays, find the median of the combined data — [1, 3] and [2] have median 2; [1, 2] and [3, 4] have median 2.5. Merging is easy and O(n + m); the interview asks for O(log(min(n, m))).

Approach

The median splits the combined sorted data into a left half and a right half of (almost) equal size. Choose a cut in the shorter array A; the cut in the longer array B is then forced, so that the two left parts together hold half the elements. The cut is correct exactly when every element on the left is at most every element on the right — and because each array is sorted, that only needs two comparisons: maxLeftA ≤ minRightB and maxLeftB ≤ minRightA.

If maxLeftA > minRightB, A's cut is too far right, so move it left; otherwise move it right. That is a binary search on A's cut. Use ±∞ for empty sides. With the correct cut, an odd total gives the median as max(maxLeftA, maxLeftB), and an even total averages that with min(minRightA, minRightB).

Java

// Binary search the cut in the shorter array so the two halves are balanced and ordered.
static double findMedianSortedArrays(int[] a, int[] b) {
    if (a.length > b.length) return findMedianSortedArrays(b, a); // search the shorter array
    int total = a.length + b.length;
    int half = (total + 1) / 2; // size of the combined left half
    int low = 0, high = a.length;
    while (low <= high) {
        int cutA = (low + high) / 2;
        int cutB = half - cutA;
        int maxLeftA = cutA == 0 ? Integer.MIN_VALUE : a[cutA - 1];
        int minRightA = cutA == a.length ? Integer.MAX_VALUE : a[cutA];
        int maxLeftB = cutB == 0 ? Integer.MIN_VALUE : b[cutB - 1];
        int minRightB = cutB == b.length ? Integer.MAX_VALUE : b[cutB];
        if (maxLeftA <= minRightB && maxLeftB <= minRightA) { // a valid partition
            int maxLeft = Math.max(maxLeftA, maxLeftB);
            if (total % 2 == 1) return maxLeft;
            return (maxLeft + Math.min(minRightA, minRightB)) / 2.0;
        }
        if (maxLeftA > minRightB) high = cutA - 1; // cut in A is too far right
        else low = cutA + 1;                       // cut in A is too far left
    }
    throw new IllegalArgumentException("Input arrays must be sorted");
}

JavaScript

// Binary search the cut in the shorter array so the two halves are balanced and ordered.
function findMedianSortedArrays(a, b) {
  if (a.length > b.length) return findMedianSortedArrays(b, a); // search the shorter array
  const total = a.length + b.length;
  const half = Math.floor((total + 1) / 2); // size of the combined left half
  let low = 0;
  let high = a.length;
  while (low <= high) {
    const cutA = Math.floor((low + high) / 2);
    const cutB = half - cutA;
    const maxLeftA = cutA === 0 ? -Infinity : a[cutA - 1];
    const minRightA = cutA === a.length ? Infinity : a[cutA];
    const maxLeftB = cutB === 0 ? -Infinity : b[cutB - 1];
    const minRightB = cutB === b.length ? Infinity : b[cutB];
    if (maxLeftA <= minRightB && maxLeftB <= minRightA) { // a valid partition
      const maxLeft = Math.max(maxLeftA, maxLeftB);
      if (total % 2 === 1) return maxLeft;
      return (maxLeft + Math.min(minRightA, minRightB)) / 2;
    }
    if (maxLeftA > minRightB) high = cutA - 1; // cut in A is too far right
    else low = cutA + 1;                       // cut in A is too far left
  }
  throw new Error('Input arrays must be sorted');
}

Complexity

  • Time O(log(min(n, m))) — binary search over the shorter array only
  • Space O(1) — a handful of variables

Say the simple version first (merge, or two pointers up to the middle — O(n + m)), then improve on it. Searching the shorter array both minimises the steps and keeps cutB from going negative.
