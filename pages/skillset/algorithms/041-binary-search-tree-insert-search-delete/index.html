Binary search tree: insert, search, delete

Medium Tree / BST

A binary search tree (BST) keeps every node's left subtree smaller and its right subtree larger than the node itself, so insert, search and delete can discard half the tree at each step. Implementing all three — especially delete — is the standard tree-coding interview.

Approach

Search / insert: compare the key with the current node — go left if smaller, right if larger, and stop when you find it (search) or reach an empty spot (insert there).

Delete has three cases. A leaf: just remove it. A node with one child: replace the node with that child. A node with two children: copy in its inorder successor (the smallest value in the right subtree), then delete that successor from the right subtree — the successor has at most one child, so it falls into an easy case.

Java

static class Node {
    int key;
    Node left, right;
    Node(int key) { this.key = key; }
}

// Insert: walk down to the empty spot where the key belongs.
static Node insert(Node node, int key) {
    if (node == null) return new Node(key);
    if (key < node.key) node.left = insert(node.left, key);
    else if (key > node.key) node.right = insert(node.right, key); // duplicates are ignored
    return node;
}

// Search: discard half the tree at every step.
static boolean contains(Node node, int key) {
    while (node != null) {
        if (key == node.key) return true;
        node = key < node.key ? node.left : node.right;
    }
    return false;
}

// Delete: leaf, one child, or two children (use the inorder successor).
static Node delete(Node node, int key) {
    if (node == null) return null;
    if (key < node.key) {
        node.left = delete(node.left, key);
    } else if (key > node.key) {
        node.right = delete(node.right, key);
    } else {
        if (node.left == null) return node.right; // leaf or only a right child
        if (node.right == null) return node.left; // only a left child
        Node successor = node.right;
        while (successor.left != null) successor = successor.left; // smallest in the right subtree
        node.key = successor.key;
        node.right = delete(node.right, successor.key);
    }
    return node;
}

JavaScript

class Node {
  constructor(key) {
    this.key = key;
    this.left = null;
    this.right = null;
  }
}

// Insert: walk down to the empty spot where the key belongs.
function insert(node, key) {
  if (!node) return new Node(key);
  if (key < node.key) node.left = insert(node.left, key);
  else if (key > node.key) node.right = insert(node.right, key); // duplicates are ignored
  return node;
}

// Search: discard half the tree at every step.
function contains(node, key) {
  while (node) {
    if (key === node.key) return true;
    node = key < node.key ? node.left : node.right;
  }
  return false;
}

// Delete: leaf, one child, or two children (use the inorder successor).
function remove(node, key) {
  if (!node) return null;
  if (key < node.key) {
    node.left = remove(node.left, key);
  } else if (key > node.key) {
    node.right = remove(node.right, key);
  } else {
    if (!node.left) return node.right; // leaf or only a right child
    if (!node.right) return node.left; // only a left child
    let successor = node.right;
    while (successor.left) successor = successor.left; // smallest in the right subtree
    node.key = successor.key;
    node.right = remove(node.right, successor.key);
  }
  return node;
}

Complexity

  • Time O(h) — h is the tree height — O(log n) when balanced, O(n) when skewed
  • Space O(h) — recursion depth (the iterative search needs O(1))

Inserting already-sorted keys builds a linked-list-shaped tree with O(n) operations. Self-balancing trees (AVL, red-black — behind Java's TreeMap) rotate nodes after updates to keep the height at O(log n).
