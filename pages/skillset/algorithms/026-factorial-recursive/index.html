Factorial (recursive)

Easy–Medium Recursion

The factorial n! = n × (n − 1) × … × 1 has a natural recursive definition: n! = n × (n − 1)!, with 0! = 1. It is the standard first example of recursion — a base case plus a smaller subproblem.

Approach

Every recursive solution needs two parts. The base case stops the recursion: factorial(0) (and 1) return 1. The recursive case reduces the problem: factorial(n) returns n * factorial(n − 1). Each call waits on the stack for the smaller call to return, then multiplies on the way back up.

Forgetting the base case, or passing a negative n, recurses forever until the stack overflows — so validate the input.

Java

// Recursive factorial: n! = n * (n - 1)!
static long factorial(int n) {
    if (n < 0) {
        throw new IllegalArgumentException("n cannot be negative");
    }
    if (n <= 1) {
        return 1; // base case: 0! = 1! = 1
    }
    return n * factorial(n - 1);
}

JavaScript

// Recursive factorial: n! = n * (n - 1)!
function factorial(n) {
  if (n < 0) {
    throw new Error('n cannot be negative');
  }
  if (n <= 1) {
    return 1; // base case: 0! = 1! = 1
  }
  return n * factorial(n - 1);
}

Complexity

  • Time O(n) — n calls, one multiplication each
  • Space O(n) — each pending call occupies a stack frame

Compare with the iterative version: same time, but O(1) space. A very large n overflows the stack (StackOverflowError in Java, RangeError in JavaScript). Neither language guarantees tail-call optimization.
