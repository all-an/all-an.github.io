Fibonacci (iterative)

Beginner Math / DP

The Fibonacci sequence starts 0, 1 and every following number is the sum of the previous two: 0, 1, 1, 2, 3, 5, 8, 13, …. Given n, return the n-th number. Computed with a loop it is the simplest example of dynamic programming.

Approach

The naive recursion recomputes the same values exponentially many times. The loop version notices that each step only needs the last two numbers: keep previous and current, and on each iteration slide them forward — previous takes the value of current, and current becomes their sum.

Only two values are ever stored, which is the classic "space-optimized DP" move: a table of all n results shrinks to two variables.

Java

// Iterative Fibonacci: slide a two-number window along the sequence.
static long fibonacci(int n) {
    if (n < 0) {
        throw new IllegalArgumentException("n cannot be negative");
    }
    long previous = 0;
    long current = 1;
    for (int i = 0; i < n; i++) {
        long next = previous + current;
        previous = current;
        current = next;
    }
    return previous; // after n steps, previous holds F(n)
}

JavaScript

// Iterative Fibonacci: slide a two-number window along the sequence.
function fibonacci(n) {
  if (n < 0) {
    throw new Error('n cannot be negative');
  }
  let previous = 0;
  let current = 1;
  for (let i = 0; i < n; i++) {
    [previous, current] = [current, previous + current];
  }
  return previous; // after n steps, previous holds F(n)
}

Complexity

  • Time O(n) — one addition per step
  • Space O(1) — just the two sliding values

A long holds Fibonacci numbers up to F(92); beyond that use BigInteger. For astronomically large n, matrix exponentiation computes F(n) in O(log n).
