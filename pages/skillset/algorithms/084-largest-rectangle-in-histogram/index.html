Largest rectangle in histogram

Hard Stack

Given the heights of adjacent bars (each of width 1) forming a histogram, find the area of the largest rectangle that fits inside it — for [2, 1, 5, 6, 2, 3] the answer is 10 (the two bars of height 5 and 6 give a 5 × 2 rectangle).

Try it

↓

Approach

For each bar, the widest rectangle using that bar as its shortest bar extends left and right until it meets a bar that is shorter. The trick is finding those two boundaries for every bar in one pass, with a monotonic stack of bar indices whose heights increase.

Scan left to right. While the current bar is lower than the bar on top of the stack, that top bar can extend no further right: pop it, and compute its rectangle — height times a width running from just after the new top of the stack (its left boundary) to just before the current index. Then push the current bar. A sentinel of height 0 at the end flushes everything left on the stack.

Java

// Monotonic stack of indices with increasing heights.
static int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();
    int best = 0;
    for (int i = 0; i <= heights.length; i++) {
        int current = i == heights.length ? 0 : heights[i]; // a final 0-height bar flushes the stack
        while (!stack.isEmpty() && heights[stack.peek()] >= current) {
            int height = heights[stack.pop()];
            int left = stack.isEmpty() ? 0 : stack.peek() + 1; // first bar the rectangle can cover
            best = Math.max(best, height * (i - left));
        }
        stack.push(i);
    }
    return best;
}

JavaScript

// Monotonic stack of indices with increasing heights.
function largestRectangleArea(heights) {
  const stack = [];
  let best = 0;
  for (let i = 0; i <= heights.length; i++) {
    const current = i === heights.length ? 0 : heights[i]; // a final 0-height bar flushes the stack
    while (stack.length > 0 && heights[stack[stack.length - 1]] >= current) {
      const height = heights[stack.pop()];
      const left = stack.length > 0 ? stack[stack.length - 1] + 1 : 0; // first bar the rectangle can cover
      best = Math.max(best, height * (i - left));
    }
    stack.push(i);
  }
  return best;
}

Complexity

  • Time O(n) — each bar is pushed and popped once
  • Space O(n) — the stack can hold every bar

The brute force expands from every bar in O(n²). This problem is the building block for "maximal rectangle" in a binary matrix: treat each row as the base of a histogram and run this on every row.
