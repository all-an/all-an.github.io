Trie: insert, search, starts-with

Medium–Hard Trie / Design

A trie (prefix tree) stores strings character by character along the edges of a tree, so words that share a prefix share a path. It supports insert, search (whole word) and startsWith (any word with this prefix) in time proportional to the word's length.

Approach

Each node holds its children (keyed by character) and a flag isWord marking where a stored word ends. Insert: walk the word's characters from the root, creating missing child nodes, and set isWord on the last node. Search: follow the characters; the word exists only if the path exists and the last node has isWord. startsWith: the same walk, but only the existence of the path matters.

Children can be an array of 26 slots (fast, but wasteful when sparse) or a hash map (flexible, works for any alphabet). Tries excel at autocomplete, spell-check and longest-prefix matching.

Java

// A trie node with 26 child slots (lowercase a-z).
static class TrieNode {
    TrieNode[] children = new TrieNode[26];
    boolean isWord; // true if a stored word ends here
}

static class Trie {
    private final TrieNode root = new TrieNode();

    // Walk the word, creating missing nodes, and mark the last one as a word end.
    void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int slot = c - 'a';
            if (node.children[slot] == null) node.children[slot] = new TrieNode();
            node = node.children[slot];
        }
        node.isWord = true;
    }

    // True only if the exact word was inserted.
    boolean search(String word) {
        TrieNode node = find(word);
        return node != null && node.isWord;
    }

    // True if any inserted word begins with the prefix.
    boolean startsWith(String prefix) {
        return find(prefix) != null;
    }

    // Follow the characters; null when the path does not exist.
    private TrieNode find(String text) {
        TrieNode node = root;
        for (char c : text.toCharArray()) {
            node = node.children[c - 'a'];
            if (node == null) return null;
        }
        return node;
    }
}

JavaScript

// A trie node: children keyed by character, plus an end-of-word flag.
class TrieNode {
  constructor() {
    this.children = new Map();
    this.isWord = false; // true if a stored word ends here
  }
}

class Trie {
  constructor() {
    this.root = new TrieNode();
  }

  // Walk the word, creating missing nodes, and mark the last one as a word end.
  insert(word) {
    let node = this.root;
    for (const char of word) {
      if (!node.children.has(char)) node.children.set(char, new TrieNode());
      node = node.children.get(char);
    }
    node.isWord = true;
  }

  // True only if the exact word was inserted.
  search(word) {
    const node = this.find(word);
    return node !== null && node.isWord;
  }

  // True if any inserted word begins with the prefix.
  startsWith(prefix) {
    return this.find(prefix) !== null;
  }

  // Follow the characters; null when the path does not exist.
  find(text) {
    let node = this.root;
    for (const char of text) {
      node = node.children.get(char);
      if (!node) return null;
    }
    return node;
  }
}

Complexity

  • Time O(L) — per operation, where L is the length of the word or prefix
  • Space O(N × L) — worst case for N words with no shared prefixes

A hash set answers search just as fast, but it cannot answer startsWith without scanning every word — that prefix query is the whole reason to use a trie.
