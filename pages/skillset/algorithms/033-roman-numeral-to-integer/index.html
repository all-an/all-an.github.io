Roman numeral to integer

Easy–Medium String / Math

Convert a Roman numeral to an integer — "III" is 3, "LVIII" is 58, "MCMXCIV" is 1994. Symbols are usually added left to right, except that a smaller value before a larger one is subtracted (IV = 4, IX = 9).

Try it

↓

Approach

Map each symbol to its value: I=1, V=5, X=10, L=50, C=100, D=500, M=1000. Scan left to right. If the current symbol is smaller than the one after it, it is part of a subtractive pair, so subtract it; otherwise add it. For MCMXCIV: +1000, −100, +1000, −10, +100, −1, +5 = 1994.

An equivalent trick scans right to left, subtracting a symbol only when it is smaller than the one you just processed.

Java

// Left to right: subtract a symbol that precedes a larger one, otherwise add it.
static int romanToInt(String roman) {
    Map<Character, Integer> values = Map.of(
        'I', 1, 'V', 5, 'X', 10, 'L', 50, 'C', 100, 'D', 500, 'M', 1000);
    int total = 0;
    for (int i = 0; i < roman.length(); i++) {
        int current = values.get(roman.charAt(i));
        boolean subtractive = i + 1 < roman.length() && current < values.get(roman.charAt(i + 1));
        total += subtractive ? -current : current;
    }
    return total;
}

JavaScript

// Left to right: subtract a symbol that precedes a larger one, otherwise add it.
function romanToInt(roman) {
  const values = { I: 1, V: 5, X: 10, L: 50, C: 100, D: 500, M: 1000 };
  let total = 0;
  for (let i = 0; i < roman.length; i++) {
    const current = values[roman[i]];
    const next = values[roman[i + 1]]; // undefined at the end, so the comparison is false
    total += next > current ? -current : current;
  }
  return total;
}

Complexity

  • Time O(n) — one pass over the numeral
  • Space O(1) — the symbol table has a fixed size

The reverse problem — integer to Roman — is a common follow-up: walk a table of values from 1000 down to 1 (including 900, 400, 90, 40, 9, 4) and repeatedly subtract, appending the symbol each time.
