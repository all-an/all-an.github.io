Two Sum (hash map)

Easy Hashing

Given an array of integers and a target, return the indices of the two numbers that add up to the target — for [2, 7, 11, 15] and target 9 the answer is indices 0 and 1. It is the most-asked interview question there is, and the showcase for trading memory for speed with a hash map.

Approach

The brute force tries every pair, which is O(n²). The insight: for each number x, the partner you need is target − x. Walk the array once, and for each element ask a hash map "have I already seen the complement?". If yes, you are done; if not, record the current number and its index and move on.

Checking the map before inserting the current number guarantees you never pair an element with itself.

Java

// Approach 1 — brute force: try every pair.
static int[] twoSumBruteForce(int[] numbers, int target) {
    for (int i = 0; i < numbers.length; i++) {
        for (int j = i + 1; j < numbers.length; j++) {
            if (numbers[i] + numbers[j] == target) return new int[] { i, j };
        }
    }
    throw new IllegalArgumentException("No two sum solution");
}

// Approach 2 — hash map: remember each value's index, look up the complement.
static int[] twoSum(int[] numbers, int target) {
    Map<Integer, Integer> indexByValue = new HashMap<>();
    for (int i = 0; i < numbers.length; i++) {
        Integer partner = indexByValue.get(target - numbers[i]);
        if (partner != null) return new int[] { partner, i };
        indexByValue.put(numbers[i], i);
    }
    throw new IllegalArgumentException("No two sum solution");
}

JavaScript

// Approach 1 — brute force: try every pair.
function twoSumBruteForce(numbers, target) {
  for (let i = 0; i < numbers.length; i++) {
    for (let j = i + 1; j < numbers.length; j++) {
      if (numbers[i] + numbers[j] === target) return [i, j];
    }
  }
  throw new Error('No two sum solution');
}

// Approach 2 — hash map: remember each value's index, look up the complement.
function twoSum(numbers, target) {
  const indexByValue = new Map();
  for (let i = 0; i < numbers.length; i++) {
    const complement = target - numbers[i];
    if (indexByValue.has(complement)) return [indexByValue.get(complement), i];
    indexByValue.set(numbers[i], i);
  }
  throw new Error('No two sum solution');
}

Complexity

  • Time O(n) — one pass, constant-time map lookups
  • Space O(n) — the map may hold every element

The brute force is O(n²) time but O(1) space — the classic time/space trade. If the array is sorted, a two-pointer sweep from both ends achieves O(n) time with O(1) space.
