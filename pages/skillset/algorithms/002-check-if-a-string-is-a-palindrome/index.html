Check if a string is a palindrome

Beginner String / Two Pointers

A palindrome reads the same forwards and backwards — "racecar" and "noon" are palindromes, "hello" is not. Given a string, return whether it is one. It is the classic introduction to the two-pointer technique.

Try it

↓

Approach

The one-liner is to compare the string with its reverse, but interviews want the two-pointer version: put one index at the start and one at the end, compare the characters they point at, and step both toward the middle. The moment two differ, it is not a palindrome; if the pointers meet without a mismatch, it is. Reject a null input by throwing an exception.

The variant you will often be asked next — "valid palindrome" — first normalizes the string by lower-casing it and dropping every non-alphanumeric character, so that "A man, a plan, a canal: Panama" counts. The comparison loop is identical; only the pre-processing changes.

Java

import java.util.Objects;

// Approach 1 — built-in: compare the string against its reverse.
static boolean isPalindrome(String s) {
    return s.equals(new StringBuilder(s).reverse().toString());
}

// Approach 2 — two pointers: walk in from both ends, comparing as you go.
static boolean isPalindromeCheck(String stringToCheck) {
    if (Objects.isNull(stringToCheck)) {
        throw new IllegalArgumentException("String cannot be null");
    }
    int left = 0;
    int right = stringToCheck.length() - 1;
    while (left < right) {
        if (stringToCheck.charAt(left) != stringToCheck.charAt(right)) {
            return false; // characters differ — not a palindrome
        }
        left++;
        right--;
    }
    return true; // pointers met with every pair matching
}

JavaScript

// Approach 1 — built-in: compare the string with its reversed form.
// [...s] spreads by code point so emoji and accents compare correctly.
function isPalindrome(s) {
  return s === [...s].reverse().join('');
}

// Approach 2 — two pointers: walk in from both ends, comparing as you go.
function isPalindromeCheck(stringToCheck) {
  if (stringToCheck == null) {
    throw new Error('String cannot be null');
  }
  let left = 0;
  let right = stringToCheck.length - 1;
  while (left < right) {
    if (stringToCheck[left] !== stringToCheck[right]) {
      return false; // characters differ — not a palindrome
    }
    left++;
    right--;
  }
  return true; // pointers met with every pair matching
}

Complexity

  • Time O(n) — each character is compared at most once
  • Space O(1) — the two-pointer version keeps only two indices

The reverse-and-compare one-liner is also O(n) time but O(n) space, because it builds a whole second string. The two-pointer loop also stops early on the first mismatch, so a string like "zebra..." is rejected after a single comparison.
