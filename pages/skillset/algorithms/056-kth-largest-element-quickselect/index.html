Kth largest element (quickselect)

Medium Quickselect

Find the k-th largest element of an unsorted array — the k-th largest of [3, 2, 1, 5, 6, 4] with k = 2 is 5. Sorting works, but quickselect finds it in average O(n).

↓

Approach

The k-th largest element is the one that would sit at index n − k in the sorted array. Quickselect is quick sort that only follows one side: partition around a pivot; the pivot lands at its final sorted index. If that index is the target, done; if it is too low, continue on the right part; if too high, on the left. Half the work of quick sort disappears at every step, so the expected cost is n + n/2 + n/4 + … = O(n).

A min-heap of size k is the simpler alternative: push each element and pop whenever the size exceeds k; the top is the answer (O(n log k), and it works on streams). Choosing a random pivot avoids the O(n²) worst case.

Java

// Approach 1 — min-heap of size k: the top is the k-th largest.
static int findKthLargestHeap(int[] numbers, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>();
    for (int n : numbers) {
        heap.add(n);
        if (heap.size() > k) heap.poll(); // drop the smallest of the k+1
    }
    return heap.peek();
}

// Approach 2 — quickselect: partition, then follow only the side holding index n - k.
static int findKthLargest(int[] numbers, int k) {
    int[] work = numbers.clone();
    int target = work.length - k;
    int low = 0, high = work.length - 1;
    Random random = new Random();
    while (low < high) {
        swap(work, low + random.nextInt(high - low + 1), high); // random pivot to the end
        int pivot = work[high];
        int boundary = low;
        for (int i = low; i < high; i++) {
            if (work[i] < pivot) swap(work, i, boundary++);
        }
        swap(work, boundary, high);
        if (boundary == target) return work[boundary];
        if (boundary < target) low = boundary + 1;
        else high = boundary - 1;
    }
    return work[target];
}

static void swap(int[] a, int i, int j) {
    int temp = a[i];
    a[i] = a[j];
    a[j] = temp;
}

JavaScript

// Quickselect: partition, then follow only the side holding index n - k.
function findKthLargest(numbers, k) {
  const work = [...numbers];
  const target = work.length - k;
  let low = 0;
  let high = work.length - 1;
  while (low < high) {
    const randomIndex = low + Math.floor(Math.random() * (high - low + 1));
    [work[randomIndex], work[high]] = [work[high], work[randomIndex]]; // random pivot to the end
    const pivot = work[high];
    let boundary = low;
    for (let i = low; i < high; i++) {
      if (work[i] < pivot) {
        [work[i], work[boundary]] = [work[boundary], work[i]];
        boundary++;
      }
    }
    [work[boundary], work[high]] = [work[high], work[boundary]];
    if (boundary === target) return work[boundary];
    if (boundary < target) low = boundary + 1;
    else high = boundary - 1;
  }
  return work[target];
}

Complexity

  • Time O(n) — average case for quickselect; O(n²) worst case (heap: O(n log k))
  • Space O(1) — partitions in place on a copy (heap: O(k))

Duplicates count: the k-th largest of [3,3,2] with k = 2 is 3, not 2 — you want the k-th in sorted order, not the k-th distinct value.
