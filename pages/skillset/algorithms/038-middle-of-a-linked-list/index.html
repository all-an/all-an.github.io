Middle of a linked list

Easy–Medium Linked List / Two Pointers

Return the middle node of a singly linked list in a single pass — for 1 → 2 → 3 → 4 → 5 it is 3; for an even-length list of 1 → 2 → 3 → 4 return the second middle, 3. A linked list has no length field and no indexing, which is what makes it interesting.

Approach

The naive route counts the nodes in one pass, then walks n/2 steps in a second. The two-pointer trick does it in one: move slow one node per step and fast two. When fast reaches the end, slow has covered exactly half the distance — it is on the middle node.

Stopping condition fast != null && fast.next != null returns the second middle for even lengths; use fast.next != null && fast.next.next != null if you need the first.

Java

static class ListNode {
    int value;
    ListNode next;
    ListNode(int value) { this.value = value; }
}

// Slow/fast pointers: when fast reaches the end, slow is in the middle.
static ListNode middleNode(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;       // one step
        fast = fast.next.next;  // two steps
    }
    return slow;
}

JavaScript

class ListNode {
  constructor(value, next = null) {
    this.value = value;
    this.next = next;
  }
}

// Slow/fast pointers: when fast reaches the end, slow is in the middle.
function middleNode(head) {
  let slow = head;
  let fast = head;
  while (fast && fast.next) {
    slow = slow.next;       // one step
    fast = fast.next.next;  // two steps
  }
  return slow;
}

Complexity

  • Time O(n) — fast traverses the list once
  • Space O(1) — two pointers

This slow/fast idea is reused all over linked-list problems: it is the first half of "palindrome linked list", "reorder list" and merge sort on a list.
