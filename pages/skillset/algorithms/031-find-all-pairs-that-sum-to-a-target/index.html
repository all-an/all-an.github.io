Find all pairs that sum to a target

Easy–Medium Hashing / Two Pointers

Find all pairs of numbers in an array that add up to a target — in [1, 5, 7, -1, 5] with target 6 the pairs are (1, 5), (7, -1) and (1, 5) again. Unlike Two Sum you must report every pair, not just one.

Approach

Hash map: count each value; for every number x, its partner is target − x. Look the partner up and add the number of ways to combine the two counts (careful when x equals its own partner — then you need c × (c − 1) / 2 pairs). Two pointers: sort, then put a pointer at each end; if the sum is too small move the left one up, if too big move the right one down, and record a pair when it matches.

Decide up front how duplicates are handled: pairs by value, pairs by index, or unique pairs only. The version below collects unique value pairs, skipping repeated values after a match.

Java

// Two pointers on a sorted copy: close in from both ends.
static List<int[]> findPairs(int[] numbers, int target) {
    int[] sorted = numbers.clone();
    Arrays.sort(sorted);
    List<int[]> pairs = new ArrayList<>();
    int left = 0, right = sorted.length - 1;
    while (left < right) {
        int sum = sorted[left] + sorted[right];
        if (sum == target) {
            pairs.add(new int[] { sorted[left], sorted[right] });
            int leftValue = sorted[left], rightValue = sorted[right];
            while (left < right && sorted[left] == leftValue) left++;    // skip repeated values
            while (left < right && sorted[right] == rightValue) right--;
        } else if (sum < target) {
            left++;  // need a bigger sum
        } else {
            right--; // need a smaller sum
        }
    }
    return pairs;
}

JavaScript

// Two pointers on a sorted copy: close in from both ends.
function findPairs(numbers, target) {
  const sorted = [...numbers].sort((a, b) => a - b);
  const pairs = [];
  let left = 0;
  let right = sorted.length - 1;
  while (left < right) {
    const sum = sorted[left] + sorted[right];
    if (sum === target) {
      pairs.push([sorted[left], sorted[right]]);
      const leftValue = sorted[left];
      const rightValue = sorted[right];
      while (left < right && sorted[left] === leftValue) left++;    // skip repeated values
      while (left < right && sorted[right] === rightValue) right--;
    } else if (sum < target) {
      left++;  // need a bigger sum
    } else {
      right--; // need a smaller sum
    }
  }
  return pairs;
}

Complexity

  • Time O(n log n) — dominated by the sort; the two-pointer sweep is O(n)
  • Space O(1) — beyond the sorted copy (the hash-map version is O(n) time, O(n) space)

Pick the hash map when the data is unsorted and you want linear time; pick two pointers when it is already sorted or memory is tight. This pattern extends to 3Sum and 4Sum.
