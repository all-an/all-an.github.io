Longest common prefix in a string array

Easy–Medium String

Given an array of strings, return the longest prefix they all share — ["flower", "flow", "flight"] share "fl"; ["dog", "car"] share nothing, so the answer is the empty string.

Try it

↓

Approach

Vertical scanning: look at the first character of every word, then the second, and so on. Stop the moment some word is too short or has a different character at that column — everything before that column is the prefix. The loop can never run longer than the shortest word.

Alternatives: shrink a candidate prefix (starting with the first word) until every other word starts with it, or sort the array and compare just the first and last words, since those are the most different.

Java

// Vertical scan: compare column by column against the first word.
static String longestCommonPrefix(String[] words) {
    if (words == null || words.length == 0) return "";
    for (int column = 0; column < words[0].length(); column++) {
        char expected = words[0].charAt(column);
        for (String word : words) {
            if (column == word.length() || word.charAt(column) != expected) {
                return words[0].substring(0, column); // mismatch or word too short
            }
        }
    }
    return words[0]; // the first word is a prefix of all the others
}

JavaScript

// Vertical scan: compare column by column against the first word.
function longestCommonPrefix(words) {
  if (!words || words.length === 0) return '';
  for (let column = 0; column < words[0].length; column++) {
    const expected = words[0][column];
    for (const word of words) {
      if (column === word.length || word[column] !== expected) {
        return words[0].slice(0, column); // mismatch or word too short
      }
    }
  }
  return words[0]; // the first word is a prefix of all the others
}

Complexity

  • Time O(S) — S is the total number of characters in all words
  • Space O(1) — only indices — the result is a slice of an existing word

In the worst case (all words identical) every character is inspected once, so O(S) cannot be beaten. For many repeated prefix queries against a fixed word set, a trie is the better structure.
