FizzBuzz

Beginner Math / Simulation

Print the numbers from 1 to n, but print Fizz for multiples of 3, Buzz for multiples of 5 and FizzBuzz for multiples of both. It is a famous screening question because it checks that you can order conditions correctly.

Try it

↓

Approach

Loop from 1 to n and use the remainder operator. The trap is checking i % 3 before i % 15: 15 would then print only Fizz. Test the combined case first (or build the word by appending Fizz and Buzz separately and falling back to the number when the word is empty).

Java

// Approach 1 — check the combined case first, then each single case.
static List<String> fizzBuzz(int n) {
    List<String> result = new ArrayList<>();
    for (int i = 1; i <= n; i++) {
        if (i % 15 == 0) result.add("FizzBuzz");
        else if (i % 3 == 0) result.add("Fizz");
        else if (i % 5 == 0) result.add("Buzz");
        else result.add(String.valueOf(i));
    }
    return result;
}

// Approach 2 — build the word by appending; no combined check needed.
static List<String> fizzBuzzAppend(int n) {
    List<String> result = new ArrayList<>();
    for (int i = 1; i <= n; i++) {
        String word = "";
        if (i % 3 == 0) word += "Fizz";
        if (i % 5 == 0) word += "Buzz";
        result.add(word.isEmpty() ? String.valueOf(i) : word);
    }
    return result;
}

JavaScript

// Approach 1 — check the combined case first, then each single case.
function fizzBuzz(n) {
  const result = [];
  for (let i = 1; i <= n; i++) {
    if (i % 15 === 0) result.push('FizzBuzz');
    else if (i % 3 === 0) result.push('Fizz');
    else if (i % 5 === 0) result.push('Buzz');
    else result.push(String(i));
  }
  return result;
}

// Approach 2 — build the word by appending; no combined check needed.
function fizzBuzzAppend(n) {
  const result = [];
  for (let i = 1; i <= n; i++) {
    let word = '';
    if (i % 3 === 0) word += 'Fizz';
    if (i % 5 === 0) word += 'Buzz';
    result.push(word || String(i));
  }
  return result;
}

Complexity

  • Time O(n) — one constant-time check per number
  • Space O(n) — the output list holds n entries (O(1) if you print as you go)

The append version scales better when new rules appear ("Bazz" for 7): each rule is one more if, whereas the combined-check version needs a branch for every combination.
