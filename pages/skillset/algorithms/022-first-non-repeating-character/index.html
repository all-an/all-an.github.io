First non-repeating character

Easy String / Hashing

Return the first character in a string that appears only once — in "swiss" that is 'w', in "aabb" there is none. It needs two things at once: counting, and remembering order.

Try it

↓

Approach

Do two passes. First pass: count how often each character occurs in a hash map. Second pass: walk the string again in its original order and return the first character whose count is 1. The second pass over the string (not over the map) is what gives you "first" — a plain HashMap does not remember insertion order.

Decide what to return when every character repeats: null, an empty string or a sentinel such as '\0'.

Java

// Two passes: count every character, then find the first with count 1.
static Character firstNonRepeating(String text) {
    Map<Character, Integer> counts = new HashMap<>();
    for (char c : text.toCharArray()) counts.merge(c, 1, Integer::sum);
    for (char c : text.toCharArray()) {
        if (counts.get(c) == 1) return c; // first in original order
    }
    return null; // every character repeats
}

JavaScript

// Two passes: count every character, then find the first with count 1.
function firstNonRepeating(text) {
  const counts = new Map();
  for (const char of text) counts.set(char, (counts.get(char) || 0) + 1);
  for (const char of text) {
    if (counts.get(char) === 1) return char; // first in original order
  }
  return null; // every character repeats
}

Complexity

  • Time O(n) — two linear passes
  • Space O(k) — k distinct characters — O(1) for a fixed alphabet

When the input is a stream you cannot re-read, keep a LinkedHashMap (Java) or a Map (JavaScript, insertion-ordered) of counts and take the first entry with count 1.
