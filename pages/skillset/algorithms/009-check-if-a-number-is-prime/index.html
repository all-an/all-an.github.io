Check if a number is prime

Beginner Math

A prime is a number greater than 1 whose only divisors are 1 and itself — 2, 3, 5, 7, 11, …. Given n, decide whether it is prime. The interview point is knowing you only have to test divisors up to √n.

↓

Approach

Numbers below 2 are not prime, and 2 is the only even prime. For everything else, try dividing by 3, 5, 7, … — if any divisor works, n is composite. You can stop at √n because divisors come in pairs: if n = a × b then one of them is at most √n. Written as divisor * divisor <= n it avoids computing a square root.

Skipping even divisors after handling 2 halves the work again.

Java

// Trial division up to the square root, skipping even divisors.
static boolean isPrime(int n) {
    if (n < 2) return false;
    if (n % 2 == 0) return n == 2; // 2 is the only even prime
    for (long divisor = 3; divisor * divisor <= n; divisor += 2) {
        if (n % divisor == 0) {
            return false; // found a factor
        }
    }
    return true;
}

JavaScript

// Trial division up to the square root, skipping even divisors.
function isPrime(n) {
  if (!Number.isInteger(n) || n < 2) return false;
  if (n % 2 === 0) return n === 2; // 2 is the only even prime
  for (let divisor = 3; divisor * divisor <= n; divisor += 2) {
    if (n % divisor === 0) {
      return false; // found a factor
    }
  }
  return true;
}

Complexity

  • Time O(√n) — at most √n / 2 divisions
  • Space O(1) — only a loop counter

To find every prime up to n, the Sieve of Eratosthenes does it in O(n log log n) — far cheaper than testing each number separately.
