Pascal's triangle

Easy–Medium Array / DP

Pascal's triangle starts with a single 1; every following row begins and ends with 1, and each inner number is the sum of the two numbers above it. Given n, return the first n rows.

Try it

↓

Approach

Build the triangle row by row. Row r has r + 1 entries: put 1 at both ends and, for each position in between, add the two neighbours from the previous row — row[c] = prev[c − 1] + prev[c]. It is a tiny example of dynamic programming: each row depends only on the one before it.

The entries are the binomial coefficients C(r, c), so a single row can also be computed directly without building the rows above it.

Java

// Build each row from the previous one by summing adjacent pairs.
static List<List<Integer>> pascalTriangle(int rowCount) {
    List<List<Integer>> rows = new ArrayList<>();
    for (int r = 0; r < rowCount; r++) {
        List<Integer> row = new ArrayList<>();
        row.add(1); // every row starts with 1
        for (int c = 1; c < r; c++) {
            List<Integer> above = rows.get(r - 1);
            row.add(above.get(c - 1) + above.get(c));
        }
        if (r > 0) row.add(1); // ...and ends with 1 (the first row is just [1])
        rows.add(row);
    }
    return rows;
}

JavaScript

// Build each row from the previous one by summing adjacent pairs.
function pascalTriangle(rowCount) {
  const rows = [];
  for (let r = 0; r < rowCount; r++) {
    const row = [1]; // every row starts with 1
    for (let c = 1; c < r; c++) {
      row.push(rows[r - 1][c - 1] + rows[r - 1][c]);
    }
    if (r > 0) row.push(1); // ...and ends with 1 (the first row is just [1])
    rows.push(row);
  }
  return rows;
}

Complexity

  • Time O(n²) — the triangle has about n²/2 entries
  • Space O(n²) — all rows are stored (O(n) if you keep only the previous row)

To return only row k, roll a single array: update it from right to left (row[j] += row[j − 1]) so each sum uses the values from the previous row.
