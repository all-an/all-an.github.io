Floyd-Warshall algorithm

Medium–Hard Graph / Shortest Path

Floyd-Warshall computes the shortest distance between every pair of nodes at once, handling negative edges (but not negative cycles). Three nested loops and a tiny recurrence — it is famous for its brevity.

Try it

↓

Approach

Let dist[i][j] start as the direct edge weight (0 on the diagonal, ∞ if there is no edge). Then consider each node k in turn as a possible intermediate stop: for every pair (i, j), if dist[i][k] + dist[k][j] < dist[i][j], going through k is shorter, so update. After processing all k, every entry is the true shortest distance.

The order of the loops matters: the intermediate node k must be the outermost loop. Afterwards, a negative value on the diagonal (dist[i][i] < 0) reveals a negative cycle through i.

Java

// Floyd-Warshall: dist is an n x n matrix with 0 on the diagonal and INF where there is no edge.
static final int INF = 1_000_000_000; // large, but 2 * INF still fits in an int

static void floydWarshall(int[][] dist) {
    int n = dist.length;
    for (int via = 0; via < n; via++) {          // intermediate node (must be the outer loop)
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (dist[i][via] + dist[via][j] < dist[i][j]) {
                    dist[i][j] = dist[i][via] + dist[via][j];
                }
            }
        }
    }
}

JavaScript

// Floyd-Warshall: dist is an n x n matrix with 0 on the diagonal and Infinity where there is no edge.
function floydWarshall(dist) {
  const n = dist.length;
  for (let via = 0; via < n; via++) {          // intermediate node (must be the outer loop)
    for (let i = 0; i < n; i++) {
      for (let j = 0; j < n; j++) {
        if (dist[i][via] + dist[via][j] < dist[i][j]) {
          dist[i][j] = dist[i][via] + dist[via][j];
        }
      }
    }
  }
  return dist;
}

Complexity

  • Time O(V³) — three nested loops over the nodes
  • Space O(V²) — the distance matrix, updated in place

Use it for small or dense graphs when you need all pairs; for a sparse graph, running Dijkstra from every node (O(V · E log V)) is usually faster. Setting dist[i][j] to a reachability flag with OR/AND gives the transitive closure.
