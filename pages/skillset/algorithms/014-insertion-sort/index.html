Insertion sort

Easy Sorting

Insertion sort builds the sorted array one element at a time, the way you sort a hand of playing cards: take the next card and slide it left until it sits in the right place among the cards you already hold.

Approach

Treat the first element as a sorted prefix of length one. For each following element, remember its value (the "key"), then shift every larger element in the sorted prefix one step to the right, and drop the key into the gap that opens up. After processing the last element the whole array is sorted.

It shines on small or nearly-sorted inputs, where very few elements need to move — which is why real sort implementations (e.g. Timsort) use it for short runs.

Java

// Insertion sort: grow a sorted prefix, inserting one element at a time.
static void insertionSort(int[] numbers) {
    for (int i = 1; i < numbers.length; i++) {
        int key = numbers[i];
        int j = i - 1;
        while (j >= 0 && numbers[j] > key) {
            numbers[j + 1] = numbers[j]; // shift the larger element right
            j--;
        }
        numbers[j + 1] = key; // drop the key into the gap
    }
}

JavaScript

// Insertion sort: grow a sorted prefix, inserting one element at a time.
function insertionSort(numbers) {
  for (let i = 1; i < numbers.length; i++) {
    const key = numbers[i];
    let j = i - 1;
    while (j >= 0 && numbers[j] > key) {
      numbers[j + 1] = numbers[j]; // shift the larger element right
      j--;
    }
    numbers[j + 1] = key; // drop the key into the gap
  }
  return numbers;
}

Complexity

  • Time O(n²) — worst case for reversed input; O(n) when already sorted
  • Space O(1) — sorts in place

Like bubble sort it is stable and in-place, but it does far fewer writes on nearly-sorted data, so it is the quadratic sort worth actually using — usually inside a faster algorithm for small partitions.
