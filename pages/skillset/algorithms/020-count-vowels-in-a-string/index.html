Count vowels in a string

Easy String

Count how many vowels — a, e, i, o, u — appear in a string; "Hello World" has 3. A small exercise in iteration, membership tests and case handling.

Try it

↓

Approach

Lower-case the string first so 'A' and 'a' count alike, then loop over its characters and increment a counter whenever the character is one of the five vowels. Storing the vowels in a string or a Set makes the membership test one line.

Clarify with the interviewer whether y counts (here it does not) and how non-letters and accented letters are treated.

Java

// Approach 1 — loop: test each character against the vowel string.
static int countVowels(String text) {
    int count = 0;
    for (char c : text.toLowerCase().toCharArray()) {
        if ("aeiou".indexOf(c) >= 0) count++;
    }
    return count;
}

// Approach 2 — streams: filter the vowels and count them.
static long countVowelsStream(String text) {
    return text.toLowerCase().chars().filter(c -> "aeiou".indexOf(c) >= 0).count();
}

JavaScript

// Approach 1 — loop: test each character against the vowel string.
function countVowels(text) {
  let count = 0;
  for (const char of text.toLowerCase()) {
    if ('aeiou'.includes(char)) count++;
  }
  return count;
}

// Approach 2 — regex: match every vowel and count the matches.
function countVowelsRegex(text) {
  return (text.match(/[aeiou]/gi) || []).length; // match() returns null when there are none
}

Complexity

  • Time O(n) — each character is checked once
  • Space O(1) — the vowel set has a fixed size

Watch the empty-match trap in JavaScript: match returns null, not an empty array, when nothing matches — hence the || [].
