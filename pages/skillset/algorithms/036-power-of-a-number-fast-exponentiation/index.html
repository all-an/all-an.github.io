Power of a number (fast exponentiation)

Easy–Medium Math / Divide & Conquer

Compute xⁿ without multiplying x by itself n times. Fast exponentiation (exponentiation by squaring) uses the identity xⁿ = (x²)^(n/2) to finish in about log₂ n multiplications.

↓

Approach

Halve the exponent each step. If n is even, xⁿ = (x²)^(n/2); if it is odd, peel off one factor: xⁿ = x × xⁿ⁻¹. Recursively that is a few lines; iteratively you keep a running result and a square, and for every 1 bit in n's binary form multiply the current square into the result.

Negative exponents: compute the positive power and take the reciprocal. Watch Integer.MIN_VALUE — negating it overflows, so widen n to a long first.

Java

// Iterative exponentiation by squaring, one bit of the exponent at a time.
static double power(double base, int exponent) {
    long remaining = exponent; // widen so -Integer.MIN_VALUE cannot overflow
    if (remaining < 0) {
        base = 1 / base;
        remaining = -remaining;
    }
    double result = 1;
    while (remaining > 0) {
        if ((remaining & 1) == 1) result *= base; // odd: take one factor out
        base *= base;                              // square the base
        remaining >>= 1;                           // halve the exponent
    }
    return result;
}

// Recursive version: x^n = (x^(n/2))^2, times x when n is odd.
static double powerRecursive(double base, int exponent) {
    if (exponent == 0) return 1;
    double half = powerRecursive(base, exponent / 2);
    return exponent % 2 == 0 ? half * half : half * half * base;
}

JavaScript

// Iterative exponentiation by squaring, one bit of the exponent at a time.
function power(base, exponent) {
  let remaining = Math.abs(exponent);
  let square = exponent < 0 ? 1 / base : base;
  let result = 1;
  while (remaining > 0) {
    if (remaining % 2 === 1) result *= square; // odd: take one factor out
    square *= square;                          // square the base
    remaining = Math.floor(remaining / 2);     // halve the exponent
  }
  return result;
}

// Recursive version: x^n = (x^(n/2))^2, times x when n is odd.
function powerRecursive(base, exponent) {
  if (exponent === 0) return 1;
  const half = powerRecursive(base, Math.trunc(exponent / 2));
  return exponent % 2 === 0 ? half * half : half * half * base;
}

Complexity

  • Time O(log n) — the exponent is halved every step
  • Space O(1) — iterative version (the recursive one uses O(log n) stack)

The same idea underlies modular exponentiation (xⁿ mod m), which is how RSA and many hash schemes work: apply % m after every multiplication so the numbers never grow.
