Maximum subarray (Kadane's algorithm)

Medium Array / DP

Find the contiguous subarray with the largest sum — in [-2, 1, -3, 4, -1, 2, 1, -5, 4] it is [4, -1, 2, 1] with sum 6. Kadane's algorithm solves it in a single pass.

Try it

↓

Approach

At each position ask: "what is the best sum of a subarray ending here?" It is either the current element alone, or the current element added to the best subarray ending at the previous position — whichever is larger: current = max(x, current + x). Equivalently, whenever the running sum drops below zero it can only hurt any later subarray, so discard it and start fresh. The answer is the maximum current seen along the way.

Initialise both variables with the first element, not 0, so an all-negative array correctly returns its largest (least negative) element instead of an empty-subarray sum of 0.

Java

// Kadane's algorithm: best sum of a subarray ending at each position.
static int maxSubArray(int[] numbers) {
    int current = numbers[0]; // best sum ending at the current index
    int best = numbers[0];    // best sum seen anywhere
    for (int i = 1; i < numbers.length; i++) {
        current = Math.max(numbers[i], current + numbers[i]); // extend, or start over
        best = Math.max(best, current);
    }
    return best;
}

JavaScript

// Kadane's algorithm: best sum of a subarray ending at each position.
function maxSubArray(numbers) {
  let current = numbers[0]; // best sum ending at the current index
  let best = numbers[0];    // best sum seen anywhere
  for (let i = 1; i < numbers.length; i++) {
    current = Math.max(numbers[i], current + numbers[i]); // extend, or start over
    best = Math.max(best, current);
  }
  return best;
}

Complexity

  • Time O(n) — a single pass
  • Space O(1) — two variables

To return the subarray itself, remember where the current run started (as the demo does). This is the simplest dynamic-programming problem to reach for when asked about subarrays — its cousin, "maximum product subarray", also needs the minimum tracked.
