Trapping rain water

Hard Two Pointers / Stack

Given the heights of bars of width 1, compute how much rain water is trapped between them after it rains — for [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1] the answer is 6. Water sits above a bar up to the lower of the tallest walls on its left and right.

Try it

↓

Approach

The water above bar i is min(tallestLeft, tallestRight) − height[i] (never negative). The direct way precomputes the tallest wall to the left and to the right of every bar in two arrays — O(n) time and O(n) space.

Two pointers remove the arrays. Start at both ends, tracking the tallest wall seen from each side. Whichever side currently has the lower bar is the bottleneck: the water above that bar is limited by its own side's wall, since the other side has an even taller wall somewhere. So settle that bar's water, and move that pointer inward.

Java

// Approach 1 — prefix and suffix maximum arrays.
static int trapWithArrays(int[] heights) {
    int n = heights.length;
    if (n == 0) return 0;
    int[] leftWall = new int[n];  // tallest bar at or before i
    int[] rightWall = new int[n]; // tallest bar at or after i
    leftWall[0] = heights[0];
    for (int i = 1; i < n; i++) leftWall[i] = Math.max(leftWall[i - 1], heights[i]);
    rightWall[n - 1] = heights[n - 1];
    for (int i = n - 2; i >= 0; i--) rightWall[i] = Math.max(rightWall[i + 1], heights[i]);
    int water = 0;
    for (int i = 0; i < n; i++) {
        water += Math.min(leftWall[i], rightWall[i]) - heights[i];
    }
    return water;
}

// Approach 2 — two pointers, O(1) space.
static int trap(int[] heights) {
    int left = 0, right = heights.length - 1;
    int leftWall = 0, rightWall = 0;
    int water = 0;
    while (left < right) {
        if (heights[left] < heights[right]) { // the left side is the bottleneck
            leftWall = Math.max(leftWall, heights[left]);
            water += leftWall - heights[left++];
        } else {                              // the right side is the bottleneck
            rightWall = Math.max(rightWall, heights[right]);
            water += rightWall - heights[right--];
        }
    }
    return water;
}

// Approach 1 — prefix and suffix maximum arrays.
function trapWithArrays(heights) {
  const n = heights.length;
  if (n === 0) return 0;
  const leftWall = new Array(n);  // tallest bar at or before i
  const rightWall = new Array(n); // tallest bar at or after i
  leftWall[0] = heights[0];
  for (let i = 1; i < n; i++) leftWall[i] = Math.max(leftWall[i - 1], heights[i]);
  rightWall[n - 1] = heights[n - 1];
  for (let i = n - 2; i >= 0; i--) rightWall[i] = Math.max(rightWall[i + 1], heights[i]);
  let water = 0;
  for (let i = 0; i < n; i++) {
    water += Math.min(leftWall[i], rightWall[i]) - heights[i];
  }
  return water;
}

// Approach 2 — two pointers, O(1) space.
function trap(heights) {
  let left = 0;
  let right = heights.length - 1;
  let leftWall = 0;
  let rightWall = 0;
  let water = 0;
  while (left < right) {
    if (heights[left] < heights[right]) { // the left side is the bottleneck
      leftWall = Math.max(leftWall, heights[left]);
      water += leftWall - heights[left++];
    } else {                              // the right side is the bottleneck
      rightWall = Math.max(rightWall, heights[right]);
      water += rightWall - heights[right--];
    }
  }
  return water;
}

Complexity

  • Time O(n) — each bar is processed once
  • Space O(1) — two pointers (the array version needs O(n))

A monotonic stack solves it too (compute water layer by layer as taller bars appear). Do not confuse it with "container with most water", which picks just two bars.
