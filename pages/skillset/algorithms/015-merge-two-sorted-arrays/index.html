Merge two sorted arrays

Easy Two Pointers

Given two sorted arrays, produce one sorted array containing all their elements — merging [1, 3, 5] and [2, 4, 6] gives [1, 2, 3, 4, 5, 6]. It is the core step of merge sort and a first taste of the two-pointer technique on two inputs.

Approach

Put one pointer at the start of each array. Repeatedly compare the two elements they point at, copy the smaller into the output and advance that pointer. When one array runs out, copy whatever remains of the other — it is already sorted and every value in it is at least as large as everything copied so far.

Using <= when the values tie takes the element from the left array first, which keeps the merge stable.

Java

// Merge two sorted arrays with one pointer per array.
static int[] mergeSorted(int[] left, int[] right) {
    int[] merged = new int[left.length + right.length];
    int i = 0, j = 0, k = 0;
    while (i < left.length && j < right.length) {
        merged[k++] = left[i] <= right[j] ? left[i++] : right[j++]; // take the smaller
    }
    while (i < left.length) merged[k++] = left[i++];   // leftovers from left
    while (j < right.length) merged[k++] = right[j++]; // leftovers from right
    return merged;
}

JavaScript

// Merge two sorted arrays with one pointer per array.
function mergeSorted(left, right) {
  const merged = [];
  let i = 0;
  let j = 0;
  while (i < left.length && j < right.length) {
    merged.push(left[i] <= right[j] ? left[i++] : right[j++]); // take the smaller
  }
  while (i < left.length) merged.push(left[i++]);   // leftovers from left
  while (j < right.length) merged.push(right[j++]); // leftovers from right
  return merged;
}

Complexity

  • Time O(n + m) — every element of both arrays is copied once
  • Space O(n + m) — the merged output array

A common follow-up is merging in place into the first array when it has spare room at the end: fill it from the back, largest elements first, so nothing is overwritten before it is read.
