Maximum flow (Ford-Fulkerson / Edmonds-Karp)

Hard Graph / Max Flow

In a network where each edge has a capacity, the maximum flow is the most that can be pushed from a source to a sink. Ford-Fulkerson repeatedly finds a path with spare capacity and pushes flow along it; choosing the paths with BFS gives the Edmonds-Karp variant with a guaranteed running time.

Approach

Keep a residual graph: for each edge, the capacity still available forward, plus a reverse edge holding the flow already sent (which lets a later path "undo" part of an earlier choice). Repeat: find any path from source to sink using only edges with residual capacity > 0 (an augmenting path); its bottleneck is the smallest residual capacity along it; push that amount — subtract it from each forward edge and add it to each reverse edge — and add it to the total flow. When no augmenting path exists, the flow is maximum.

Finding the path with DFS is plain Ford-Fulkerson (running time depends on the capacities); using BFS — the shortest path in edges — is Edmonds-Karp, whose O(V·E²) bound does not depend on the capacity values. By the max-flow min-cut theorem, the answer also equals the capacity of the smallest cut separating source from sink.

Java

// Edmonds-Karp on an adjacency matrix of residual capacities. The matrix is modified in place.
static int maxFlow(int[][] residual, int source, int sink) {
    int n = residual.length;
    int flow = 0;
    while (true) {
        int[] parent = new int[n]; // BFS tree: how each node was reached
        Arrays.fill(parent, -1);
        parent[source] = source;
        Queue<Integer> queue = new ArrayDeque<>();
        queue.add(source);
        while (!queue.isEmpty() && parent[sink] == -1) {
            int node = queue.remove();
            for (int next = 0; next < n; next++) {
                if (parent[next] == -1 && residual[node][next] > 0) { // spare capacity
                    parent[next] = node;
                    queue.add(next);
                }
            }
        }
        if (parent[sink] == -1) return flow; // no augmenting path left

        int bottleneck = Integer.MAX_VALUE;  // the smallest spare capacity on the path
        for (int node = sink; node != source; node = parent[node]) {
            bottleneck = Math.min(bottleneck, residual[parent[node]][node]);
        }
        for (int node = sink; node != source; node = parent[node]) {
            residual[parent[node]][node] -= bottleneck; // use up forward capacity
            residual[node][parent[node]] += bottleneck; // allow the flow to be undone later
        }
        flow += bottleneck;
    }
}

JavaScript

// Edmonds-Karp on an adjacency matrix of residual capacities. The matrix is modified in place.
function maxFlow(residual, source, sink) {
  const n = residual.length;
  let flow = 0;
  for (;;) {
    const parent = new Array(n).fill(-1); // BFS tree: how each node was reached
    parent[source] = source;
    const queue = [source];
    while (queue.length > 0 && parent[sink] === -1) {
      const node = queue.shift();
      for (let next = 0; next < n; next++) {
        if (parent[next] === -1 && residual[node][next] > 0) { // spare capacity
          parent[next] = node;
          queue.push(next);
        }
      }
    }
    if (parent[sink] === -1) return flow; // no augmenting path left

    let bottleneck = Infinity; // the smallest spare capacity on the path
    for (let node = sink; node !== source; node = parent[node]) {
      bottleneck = Math.min(bottleneck, residual[parent[node]][node]);
    }
    for (let node = sink; node !== source; node = parent[node]) {
      residual[parent[node]][node] -= bottleneck; // use up forward capacity
      residual[node][parent[node]] += bottleneck; // allow the flow to be undone later
    }
    flow += bottleneck;
  }
}

Complexity

  • Time O(V × E²) — Edmonds-Karp: at most V·E augmentations, each a BFS of O(E)
  • Space O(V²) — the residual matrix (O(V + E) with adjacency lists)

Max flow models more than pipes: bipartite matching (assign jobs to workers), project selection and image segmentation all reduce to it. Dinic's algorithm is the faster choice for large instances.
