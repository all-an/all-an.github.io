Decode ways (DP)

Medium Dynamic Programming

A message of digits encodes letters with 1 = A, 2 = B, …, 26 = Z. Count the ways to decode a digit string — "12" decodes as "AB" (1, 2) or "L" (12), so there are 2 ways; "06" has none, since a leading zero is invalid.

Approach

Let ways[i] be the number of decodings of the first i digits. The last digit can be decoded alone, if it is not '0', adding ways[i − 1]. The last two digits can be decoded together, if they form a number from 10 to 26, adding ways[i − 2]. A '0' can only ever be part of 10 or 20.

Like Fibonacci and climbing stairs, each value needs only the previous two, so two variables replace the array. Start with ways[0] = 1 (the empty prefix) and handle a leading zero explicitly.

Java

// DP with two rolling counts over the digits.
static int numDecodings(String digits) {
    if (digits.isEmpty() || digits.charAt(0) == '0') return 0; // a leading zero cannot be decoded
    int twoBack = 1; // decodings of the empty prefix
    int oneBack = 1; // decodings of the first digit
    for (int i = 1; i < digits.length(); i++) {
        int current = 0;
        if (digits.charAt(i) != '0') current += oneBack;    // last digit alone (1-9)
        int pair = Integer.parseInt(digits.substring(i - 1, i + 1));
        if (pair >= 10 && pair <= 26) current += twoBack;   // last two digits together
        twoBack = oneBack;
        oneBack = current;
    }
    return oneBack;
}

JavaScript

// DP with two rolling counts over the digits.
function numDecodings(digits) {
  if (digits === '' || digits[0] === '0') return 0; // a leading zero cannot be decoded
  let twoBack = 1; // decodings of the empty prefix
  let oneBack = 1; // decodings of the first digit
  for (let i = 1; i < digits.length; i++) {
    let current = 0;
    if (digits[i] !== '0') current += oneBack;         // last digit alone (1-9)
    const pair = Number(digits.slice(i - 1, i + 1));
    if (pair >= 10 && pair <= 26) current += twoBack;  // last two digits together
    [twoBack, oneBack] = [oneBack, current];
  }
  return oneBack;
}

Complexity

  • Time O(n) — one pass over the digits
  • Space O(1) — two rolling counts

Test the zeroes carefully: "10" → 1, "100" → 0, "301" → 0. Most wrong answers to this problem come from a stray '0'.
