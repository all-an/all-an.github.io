Binary search

Easy Searching

Given a sorted array and a target, return the target's index, or −1 if it is absent. Instead of checking every element it halves the search range each step — the textbook O(log n) algorithm.

Try it

↓

Approach

Keep a search window [low, high]. Look at the middle element: if it equals the target you are done; if it is smaller, the target can only be in the right half, so move low past the middle; if larger, move high before it. Repeat until the window is empty.

Compute the middle as low + (high − low) / 2 rather than (low + high) / 2 — in Java the latter can overflow for huge arrays. The array must be sorted, or the halving logic is meaningless.

Java

// Approach 1 — iterative: shrink the window [low, high] until it is empty.
static int binarySearch(int[] sorted, int target) {
    int low = 0;
    int high = sorted.length - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2; // avoids int overflow of low + high
        if (sorted[mid] == target) return mid;
        if (sorted[mid] < target) low = mid + 1;  // target is in the right half
        else high = mid - 1;                      // target is in the left half
    }
    return -1;
}

// Approach 2 — recursive: the same halving, expressed as a self-call.
static int binarySearchRecursive(int[] sorted, int target, int low, int high) {
    if (low > high) return -1;
    int mid = low + (high - low) / 2;
    if (sorted[mid] == target) return mid;
    return sorted[mid] < target
        ? binarySearchRecursive(sorted, target, mid + 1, high)
        : binarySearchRecursive(sorted, target, low, mid - 1);
}

JavaScript

// Approach 1 — iterative: shrink the window [low, high] until it is empty.
function binarySearch(sorted, target) {
  let low = 0;
  let high = sorted.length - 1;
  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (sorted[mid] === target) return mid;
    if (sorted[mid] < target) low = mid + 1;  // target is in the right half
    else high = mid - 1;                      // target is in the left half
  }
  return -1;
}

// Approach 2 — recursive: the same halving, expressed as a self-call.
function binarySearchRecursive(sorted, target, low = 0, high = sorted.length - 1) {
  if (low > high) return -1;
  const mid = Math.floor((low + high) / 2);
  if (sorted[mid] === target) return mid;
  return sorted[mid] < target
    ? binarySearchRecursive(sorted, target, mid + 1, high)
    : binarySearchRecursive(sorted, target, low, mid - 1);
}

Complexity

  • Time O(log n) — the window halves every step
  • Space O(1) — iterative version keeps three indices (the recursive one uses O(log n) stack)

A million-element array needs only about 20 comparisons. Many harder problems ("binary search on the answer", first/last occurrence, rotated arrays) are this same loop with a different condition.
