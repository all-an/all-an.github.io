Level-order traversal (BFS on a tree)

Easy–Medium Tree / BFS

Visit a binary tree level by level, left to right — for the tree 3 / (9, 20 / (15, 7)) the levels are [3], [9, 20], [15, 7]. It is breadth-first search (BFS) applied to a tree.

Try it

Approach

Use a queue. Start with the root in it. While the queue is not empty, note its current size — that is exactly the number of nodes on this level — then remove that many nodes, recording their values and adding each node's left and right children to the back of the queue. The children form the next level.

Snapshotting the queue size at the start of each round is the trick that separates the levels; without it you get a flat BFS order.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

// BFS with a queue, processing one whole level per outer iteration.
static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> levels = new ArrayList<>();
    if (root == null) return levels;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        int levelSize = queue.size(); // nodes on the current level
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.remove();
            level.add(node.value);
            if (node.left != null) queue.add(node.left);
            if (node.right != null) queue.add(node.right);
        }
        levels.add(level);
    }
    return levels;
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// BFS with a queue, processing one whole level per outer iteration.
function levelOrder(root) {
  const levels = [];
  if (!root) return levels;
  const queue = [root];
  while (queue.length > 0) {
    const levelSize = queue.length; // nodes on the current level
    const level = [];
    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift();
      level.push(node.value);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    levels.push(level);
  }
  return levels;
}

Complexity

  • Time O(n) — every node is enqueued and dequeued once
  • Space O(w) — w is the widest level — up to about n/2 for a full tree

In JavaScript Array.shift() is O(n) on big arrays; for large trees keep a head index instead of shifting. Variants — zigzag order, right-side view, level averages — all reuse this loop.
