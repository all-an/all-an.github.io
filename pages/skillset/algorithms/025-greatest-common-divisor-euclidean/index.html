Greatest common divisor (Euclidean)

Easy Math

The greatest common divisor of two integers is the largest number that divides both — gcd(48, 18) = 6. Euclid's 2,000-year-old algorithm finds it without factoring anything.

Try it

↓

Approach

The key fact: gcd(a, b) = gcd(b, a mod b) — replacing the larger number by the remainder never changes the answer, because any common divisor of a and b also divides the remainder. Repeat until the remainder is 0; the last non-zero value is the GCD.

Once you have the GCD, the least common multiple falls out: lcm(a, b) = a / gcd(a, b) × b (divide first to avoid overflow).

Java

// Approach 1 — iterative Euclid: replace (a, b) with (b, a mod b).
static int gcd(int a, int b) {
    while (b != 0) {
        int remainder = a % b;
        a = b;
        b = remainder;
    }
    return Math.abs(a);
}

// Approach 2 — recursive: the same rule as a self-call.
static int gcdRecursive(int a, int b) {
    return b == 0 ? Math.abs(a) : gcdRecursive(b, a % b);
}

JavaScript

// Approach 1 — iterative Euclid: replace (a, b) with (b, a mod b).
function gcd(a, b) {
  while (b !== 0) {
    [a, b] = [b, a % b];
  }
  return Math.abs(a);
}

// Approach 2 — recursive: the same rule as a self-call.
function gcdRecursive(a, b) {
  return b === 0 ? Math.abs(a) : gcdRecursive(b, a % b);
}

Complexity

  • Time O(log min(a, b)) — the remainder shrinks at least by half every two steps
  • Space O(1) — iterative version keeps two variables (recursive: O(log n) stack)

Because the numbers shrink so quickly, even 64-bit inputs finish in under a hundred iterations. Java's BigInteger.gcd provides it for arbitrarily large values.
