Fibonacci (recursive + memoization)

Easy–Medium Recursion / DP

The recursive definition F(n) = F(n − 1) + F(n − 2) is elegant but, written naively, painfully slow — it recomputes the same values again and again. Adding memoization (caching results) turns an exponential algorithm into a linear one.

Approach

The call tree of naive fib(n) branches twice at every level, so fib(30) makes over 2 million calls, almost all repeats. Memoization stores each result the first time it is computed — in a map or array — and every later request for the same n is a lookup. Each value is now computed once, so only about 2n calls happen.

This "recursion + cache" recipe is top-down dynamic programming, and it applies to any recursion with overlapping subproblems.

Java

// Naive recursion: exponential, because it recomputes the same values.
static long fibNaive(int n) {
    return n < 2 ? n : fibNaive(n - 1) + fibNaive(n - 2);
}

// Memoized recursion: each F(k) is computed once and cached.
static long fibonacci(int n) {
    return fibonacci(n, new HashMap<>());
}

static long fibonacci(int n, Map<Integer, Long> cache) {
    if (n < 2) return n; // base cases: F(0) = 0, F(1) = 1
    Long cached = cache.get(n);
    if (cached != null) return cached;
    long result = fibonacci(n - 1, cache) + fibonacci(n - 2, cache);
    cache.put(n, result);
    return result;
}

JavaScript

// Naive recursion: exponential, because it recomputes the same values.
function fibNaive(n) {
  return n < 2 ? n : fibNaive(n - 1) + fibNaive(n - 2);
}

// Memoized recursion: each F(k) is computed once and cached.
function fibonacci(n, cache = new Map()) {
  if (n < 2) return n; // base cases: F(0) = 0, F(1) = 1
  if (cache.has(n)) return cache.get(n);
  const result = fibonacci(n - 1, cache) + fibonacci(n - 2, cache);
  cache.set(n, result);
  return result;
}

Complexity

  • Time O(n) — memoized: each value computed once (naive: O(2ⁿ))
  • Space O(n) — the cache plus the recursion stack

Recursion depth is still n, so very large n overflows the stack — at that point switch to the iterative loop, which needs only O(1) space.
