Count occurrences of a character in a string

Beginner String / Hashing

Given a string and a character, count how many times the character appears — 'l' appears 3 times in "hello world". The natural extension is counting every character at once, which is the doorway to hashing.

Try it

↓

Approach

For a single character, loop over the string and increment a counter each time the character matches. To count every character in one pass, keep a hash map from character to count: read the current count (defaulting to 0), add one, and store it back.

Decide about case up front — is 'H' the same as 'h'? — and normalize with toLowerCase() if it is.

Java

// Approach 1 — one character: scan and count the matches.
static int countChar(String text, char target) {
    int count = 0;
    for (int i = 0; i < text.length(); i++) {
        if (text.charAt(i) == target) count++;
    }
    return count;
}

// Approach 2 — every character: a map from character to its count.
static Map<Character, Integer> countAllChars(String text) {
    Map<Character, Integer> counts = new LinkedHashMap<>();
    for (char c : text.toCharArray()) {
        counts.merge(c, 1, Integer::sum); // insert 1, or add 1 to the existing count
    }
    return counts;
}

JavaScript

// Approach 1 — one character: scan and count the matches.
function countChar(text, target) {
  let count = 0;
  for (const char of text) {
    if (char === target) count++;
  }
  return count;
}

// Approach 2 — every character: a Map from character to its count.
function countAllChars(text) {
  const counts = new Map();
  for (const char of text) {
    counts.set(char, (counts.get(char) || 0) + 1); // default to 0 on first sight
  }
  return counts;
}

Complexity

  • Time O(n) — each character is visited once
  • Space O(k) — k is the number of distinct characters; O(1) for a single-character count

For a fixed alphabet such as lowercase ASCII, an int[26] array replaces the map and is faster, since indexing an array beats hashing.
