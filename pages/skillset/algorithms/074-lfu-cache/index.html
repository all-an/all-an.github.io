LFU Cache

Medium–Hard Design

An LFU (least frequently used) cache evicts the entry that has been accessed the fewest times, breaking ties by evicting the least recently used among those. It is a harder cousin of the LRU cache, and get and put must both be O(1).

Approach

Keep three structures: a map key → value, a map key → use count, and a map count → ordered set of keys with that count (insertion-ordered, so the front is the least recently used of that count). Also track minCount, the smallest count currently present.

On every access, remove the key from its current count's set and add it to the set for count + 1; if the old set was the minCount one and is now empty, increase minCount. On inserting a new key when full, evict the front key of the minCount set, then insert the new key with count 1 and reset minCount = 1.

Java

static class LfuCache {
    private final int capacity;
    private int minCount = 0;
    private final Map<Integer, Integer> values = new HashMap<>();
    private final Map<Integer, Integer> counts = new HashMap<>();
    // count -> keys with that count, oldest first (LinkedHashSet keeps insertion order)
    private final Map<Integer, LinkedHashSet<Integer>> keysByCount = new HashMap<>();

    LfuCache(int capacity) { this.capacity = capacity; }

    int get(int key) {
        if (!values.containsKey(key)) return -1;
        touch(key);
        return values.get(key);
    }

    void put(int key, int value) {
        if (capacity == 0) return;
        if (values.containsKey(key)) {
            values.put(key, value);
            touch(key);
            return;
        }
        if (values.size() == capacity) {
            int evicted = keysByCount.get(minCount).iterator().next(); // least used, then oldest
            keysByCount.get(minCount).remove(evicted);
            values.remove(evicted);
            counts.remove(evicted);
        }
        values.put(key, value);
        counts.put(key, 1);
        keysByCount.computeIfAbsent(1, c -> new LinkedHashSet<>()).add(key);
        minCount = 1; // a brand-new key always has the lowest count
    }

    // Record one more use: move the key from its count's set to the next count's set.
    private void touch(int key) {
        int count = counts.get(key);
        keysByCount.get(count).remove(key);
        if (count == minCount && keysByCount.get(count).isEmpty()) minCount++;
        counts.put(key, count + 1);
        keysByCount.computeIfAbsent(count + 1, c -> new LinkedHashSet<>()).add(key);
    }
}

JavaScript

class LfuCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.minCount = 0;
    this.values = new Map();
    this.counts = new Map();
    this.keysByCount = new Map(); // count -> Set of keys, oldest first (Sets keep insertion order)
  }

  get(key) {
    if (!this.values.has(key)) return -1;
    this.touch(key);
    return this.values.get(key);
  }

  put(key, value) {
    if (this.capacity === 0) return;
    if (this.values.has(key)) {
      this.values.set(key, value);
      this.touch(key);
      return;
    }
    if (this.values.size === this.capacity) {
      const oldestSet = this.keysByCount.get(this.minCount);
      const evicted = oldestSet.values().next().value; // least used, then oldest
      oldestSet.delete(evicted);
      this.values.delete(evicted);
      this.counts.delete(evicted);
    }
    this.values.set(key, value);
    this.counts.set(key, 1);
    if (!this.keysByCount.has(1)) this.keysByCount.set(1, new Set());
    this.keysByCount.get(1).add(key);
    this.minCount = 1; // a brand-new key always has the lowest count
  }

  // Record one more use: move the key from its count's set to the next count's set.
  touch(key) {
    const count = this.counts.get(key);
    const currentSet = this.keysByCount.get(count);
    currentSet.delete(key);
    if (count === this.minCount && currentSet.size === 0) this.minCount++;
    this.counts.set(key, count + 1);
    if (!this.keysByCount.has(count + 1)) this.keysByCount.set(count + 1, new Set());
    this.keysByCount.get(count + 1).add(key);
  }
}

Complexity

  • Time O(1) — per get and put — every step is a hash or ordered-set operation
  • Space O(capacity) — three maps sized to the number of cached keys

The tie-breaking rule is the classic trap: among keys with the same lowest count, evict the least recently used — that is why each count owns an ordered set rather than a plain one.
