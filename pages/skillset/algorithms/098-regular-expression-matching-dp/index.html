Regular expression matching (DP)

Hard Dynamic Programming

Implement matching of a string against a pattern where . matches any single character and * means "zero or more of the preceding element". The match must cover the entire string — "aa" does not match "a", but does match "a*" and ".*".

Approach

Let table[i][j] be true if the first i characters of the text match the first j characters of the pattern. If pattern[j − 1] is a normal character or .: it matches when the text character agrees (or the pattern has .) and table[i − 1][j − 1] is true.

If pattern[j − 1] is *, it applies to the previous pattern element p = pattern[j − 2], and there are two options. Zero copies: ignore p* — table[i][j − 2]. One more copy: if p matches the current text character, consume that character but keep the p* in the pattern — table[i − 1][j]. The match holds if either option does. The first row handles patterns like a*b* that can match the empty string.

Java

// DP over prefixes: table[i][j] = text[0..i) matches pattern[0..j).
static boolean isMatch(String text, String pattern) {
    boolean[][] table = new boolean[text.length() + 1][pattern.length() + 1];
    table[0][0] = true; // empty matches empty
    for (int j = 2; j <= pattern.length(); j++) {
        if (pattern.charAt(j - 1) == '*') table[0][j] = table[0][j - 2]; // "a*" can vanish
    }
    for (int i = 1; i <= text.length(); i++) {
        for (int j = 1; j <= pattern.length(); j++) {
            char p = pattern.charAt(j - 1);
            if (p == '*') {
                char before = pattern.charAt(j - 2);
                boolean beforeMatches = before == '.' || before == text.charAt(i - 1);
                table[i][j] = table[i][j - 2]                    // zero copies of the element
                           || (beforeMatches && table[i - 1][j]); // one more copy
            } else {
                table[i][j] = (p == '.' || p == text.charAt(i - 1)) && table[i - 1][j - 1];
            }
        }
    }
    return table[text.length()][pattern.length()];
}

JavaScript

// DP over prefixes: table[i][j] = text[0..i) matches pattern[0..j).
function isMatch(text, pattern) {
  const table = Array.from({ length: text.length + 1 }, () => new Array(pattern.length + 1).fill(false));
  table[0][0] = true; // empty matches empty
  for (let j = 2; j <= pattern.length; j++) {
    if (pattern[j - 1] === '*') table[0][j] = table[0][j - 2]; // "a*" can vanish
  }
  for (let i = 1; i <= text.length; i++) {
    for (let j = 1; j <= pattern.length; j++) {
      const p = pattern[j - 1];
      if (p === '*') {
        const before = pattern[j - 2];
        const beforeMatches = before === '.' || before === text[i - 1];
        table[i][j] = table[i][j - 2]                    // zero copies of the element
                   || (beforeMatches && table[i - 1][j]); // one more copy
      } else {
        table[i][j] = (p === '.' || p === text[i - 1]) && table[i - 1][j - 1];
      }
    }
  }
  return table[text.length][pattern.length];
}

Complexity

  • Time O(m × n) — one cell per pair of text and pattern prefixes
  • Space O(m × n) — the DP table

A recursive solution with memoization is equivalent and often easier to derive; write the recursion first, then cache on (i, j). The pattern is assumed to be well-formed — a leading * is invalid input.
