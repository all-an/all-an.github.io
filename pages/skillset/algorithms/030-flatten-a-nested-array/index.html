Flatten a nested array

Easy–Medium Recursion

Given an array that may contain other arrays nested to any depth, produce a single flat array — [1, [2, [3, 4]], 5] becomes [1, 2, 3, 4, 5]. It is a natural fit for recursion.

Try it

↓

Approach

Walk the array. For each element, if it is itself an array, flatten it recursively and append the results; otherwise append the element as is. The recursion mirrors the nesting, so any depth is handled automatically.

An iterative alternative keeps an explicit stack: pop an item; if it is a list, push its elements back (in reverse); otherwise output it. This avoids deep recursion. JavaScript also offers arr.flat(Infinity) built in.

Java

// Recursive flatten: a nested List<Object> holds Integers and further Lists.
static void flatten(List<?> nested, List<Integer> flat) {
    for (Object item : nested) {
        if (item instanceof List<?> inner) {
            flatten(inner, flat); // open up the nested list
        } else {
            flat.add((Integer) item);
        }
    }
}

// Convenience wrapper that returns a new flat list.
static List<Integer> flatten(List<?> nested) {
    List<Integer> flat = new ArrayList<>();
    flatten(nested, flat);
    return flat;
}

JavaScript

// Approach 1 — built-in: flat(Infinity) flattens to any depth.
function flattenBuiltIn(items) {
  return items.flat(Infinity);
}

// Approach 2 — recursive: open up nested arrays, keep everything else.
function flatten(items) {
  const flat = [];
  for (const item of items) {
    if (Array.isArray(item)) {
      flat.push(...flatten(item)); // recurse into the nested array
    } else {
      flat.push(item);
    }
  }
  return flat;
}

Complexity

  • Time O(n) — n is the total number of elements, nested ones included
  • Space O(d) — d is the nesting depth (plus the O(n) output)

Java's static typing has no built-in "array of anything" for this, hence the List<?> and instanceof check. Clarify whether depth is limited — flat() with no argument only flattens one level.
