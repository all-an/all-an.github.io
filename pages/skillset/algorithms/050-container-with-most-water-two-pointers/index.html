Container with most water (two pointers)

Medium Two Pointers

Given the heights of vertical lines standing at positions 0, 1, 2, …, choose two lines that, together with the x-axis, hold the most water. The area is width × the shorter height — for [1, 8, 6, 2, 5, 4, 8, 3, 7] the best is 49.

Approach

Brute force checks all O(n²) pairs. Two pointers do it in one pass: start with the widest container (first and last line) and compute its area. Then move one pointer inward — always the one at the shorter line. Why? The area is capped by the shorter line, so keeping it and shrinking the width can only make things worse; the only hope of improving is to swap the shorter line for a taller one.

Every time you move, record the best area. When the pointers meet, every container that could beat the best has been considered.

Java

// Two pointers: always discard the shorter line, since it limits the area.
static int maxArea(int[] heights) {
    int left = 0;
    int right = heights.length - 1;
    int best = 0;
    while (left < right) {
        int width = right - left;
        int height = Math.min(heights[left], heights[right]); // water level = shorter line
        best = Math.max(best, width * height);
        if (heights[left] < heights[right]) left++; // move the limiting side
        else right--;
    }
    return best;
}

JavaScript

// Two pointers: always discard the shorter line, since it limits the area.
function maxArea(heights) {
  let left = 0;
  let right = heights.length - 1;
  let best = 0;
  while (left < right) {
    const width = right - left;
    const height = Math.min(heights[left], heights[right]); // water level = shorter line
    best = Math.max(best, width * height);
    if (heights[left] < heights[right]) left++; // move the limiting side
    else right--;
  }
  return best;
}

Complexity

  • Time O(n) — the pointers together move at most n steps
  • Space O(1) — two indices

Not to be confused with "trapping rain water", which sums the water held between all bars rather than choosing a single pair.
