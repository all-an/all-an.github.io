Maximum depth of a binary tree

Medium Tree / DFS

Return the maximum depth of a binary tree: the number of nodes along the longest path from the root down to a leaf. An empty tree has depth 0, a single node depth 1.

Try it

↓

Approach

The depth of a tree is one (for the root) plus the depth of its deeper subtree — a definition that translates straight into recursion, with an empty tree (null) as the base case returning 0.

The iterative alternative is a level-order (BFS) traversal that counts how many levels it processes; that avoids deep recursion on very tall trees.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

// Approach 1 — recursion: 1 + the deeper subtree.
static int maxDepth(TreeNode root) {
    if (root == null) return 0; // base case: an empty tree
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

// Approach 2 — BFS: count the levels.
static int maxDepthBfs(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.add(root);
    int depth = 0;
    while (!queue.isEmpty()) {
        depth++;
        for (int i = queue.size(); i > 0; i--) { // drain exactly one level
            TreeNode node = queue.remove();
            if (node.left != null) queue.add(node.left);
            if (node.right != null) queue.add(node.right);
        }
    }
    return depth;
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// Approach 1 — recursion: 1 + the deeper subtree.
function maxDepth(root) {
  if (!root) return 0; // base case: an empty tree
  return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

// Approach 2 — BFS: count the levels.
function maxDepthBfs(root) {
  if (!root) return 0;
  let level = [root];
  let depth = 0;
  while (level.length > 0) {
    depth++;
    level = level.flatMap(node => [node.left, node.right]).filter(Boolean); // the next level
  }
  return depth;
}

Complexity

  • Time O(n) — every node is visited once
  • Space O(h) — recursion depth = height (BFS uses O(w) for the widest level)

Be careful to say whether depth is counted in nodes (as here) or edges — that makes a difference of one. Related: minimum depth needs care, because a node with one missing child is not yet a leaf.
