Bubble sort

Easy Sorting

Bubble sort repeatedly steps through the array, swapping neighbouring elements that are in the wrong order, so the largest values "bubble up" to the end. It is rarely used in practice but is the easiest sorting algorithm to explain.

Approach

Make repeated passes over the array. In each pass compare every adjacent pair and swap them if the left one is larger. After the first pass the largest element is guaranteed to be at the end; after the second, the second largest is in place, and so on — so each pass can stop one element earlier.

An easy optimisation: if a whole pass makes no swaps, the array is already sorted and you can stop. That makes the best case (already sorted input) O(n).

Java

// Bubble sort with an early exit when a pass makes no swaps.
static void bubbleSort(int[] numbers) {
    for (int pass = 0; pass < numbers.length - 1; pass++) {
        boolean swapped = false;
        for (int i = 0; i < numbers.length - 1 - pass; i++) { // the tail is already sorted
            if (numbers[i] > numbers[i + 1]) {
                int temp = numbers[i];
                numbers[i] = numbers[i + 1];
                numbers[i + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break; // no swaps: sorted
    }
}

JavaScript

// Bubble sort with an early exit when a pass makes no swaps.
function bubbleSort(numbers) {
  for (let pass = 0; pass < numbers.length - 1; pass++) {
    let swapped = false;
    for (let i = 0; i < numbers.length - 1 - pass; i++) { // the tail is already sorted
      if (numbers[i] > numbers[i + 1]) {
        [numbers[i], numbers[i + 1]] = [numbers[i + 1], numbers[i]];
        swapped = true;
      }
    }
    if (!swapped) break; // no swaps: sorted
  }
  return numbers;
}

Complexity

  • Time O(n²) — about n²/2 comparisons in the worst case (O(n) if already sorted)
  • Space O(1) — sorts in place with one temporary

Bubble sort is stable (equal elements keep their order) and in-place, but its quadratic time makes it a poor choice beyond teaching. Prefer merge sort or quick sort — or the language's built-in sort — for real data.
