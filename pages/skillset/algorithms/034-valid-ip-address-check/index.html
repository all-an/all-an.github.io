Valid IP address check

Easy–Medium String

Decide whether a string is a valid IPv4 address: four decimal numbers from 0 to 255, separated by dots, with no leading zeroes — "192.168.1.1" is valid; "256.1.1.1", "1.1.1" and "01.1.1.1" are not.

Approach

Split the string on . and require exactly four parts. Each part must be non-empty, contain only digits, be at most three characters, have no leading zero unless it is the single digit "0", and be numerically at most 255. Check the characters before parsing, because Integer.parseInt happily accepts things like "+1" or "-0".

Watch the split edge cases: in Java "1.1.1.1.".split("\\.") drops the trailing empty string, so use a negative limit — split("\\.", -1) — to keep it and reject the input.

Java

// Split on dots and validate each of the four parts.
static boolean isValidIPv4(String address) {
    String[] parts = address.split("\\.", -1); // -1 keeps trailing empty parts
    if (parts.length != 4) return false;
    for (String part : parts) {
        if (part.isEmpty() || part.length() > 3) return false;
        for (char c : part.toCharArray()) {
            if (!Character.isDigit(c)) return false; // digits only
        }
        if (part.length() > 1 && part.charAt(0) == '0') return false; // no leading zeroes
        if (Integer.parseInt(part) > 255) return false;
    }
    return true;
}

JavaScript

// Split on dots and validate each of the four parts.
function isValidIPv4(address) {
  const parts = address.split('.');
  if (parts.length !== 4) return false;
  return parts.every(part =>
    /^\d{1,3}$/.test(part) &&            // 1-3 digits, nothing else
    (part === '0' || part[0] !== '0') &&  // no leading zeroes
    Number(part) <= 255
  );
}

Complexity

  • Time O(n) — n is the string length; each character is checked a constant number of times
  • Space O(1) — at most four short parts

In real code prefer the platform parser (InetAddress in Java) over hand-rolled checks. IPv6 is a follow-up variant: eight groups of 1–4 hex digits separated by colons, with :: as a shorthand for a run of zero groups.
