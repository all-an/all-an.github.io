Burst balloons (interval DP)

Hard Dynamic Programming

You have balloons with numbers on them. Bursting balloon i earns nums[left] × nums[i] × nums[right], where left and right are its current neighbours (out-of-range neighbours count as 1). What is the most coins you can collect by bursting them all? For [3, 1, 5, 8] the answer is 167.

Approach

Thinking about which balloon to burst first is a trap: bursting it makes its neighbours adjacent, so the sub-problems on each side stop being independent. Flip the question — which balloon is burst last in a range? If balloon k is last in the open interval (left, right), then when it is burst its neighbours are exactly left and right, and everything else in the interval has already gone — and the left part and right part are now independent sub-problems.

So best[left][right] = max over k of best[left][k] + nums[left]·nums[k]·nums[right] + best[k][right]. Pad the array with a 1 at each end, and fill the table for increasing interval widths, since each cell depends on shorter intervals.

Java

// Interval DP: best[l][r] = most coins from bursting everything strictly between l and r.
static int maxCoins(int[] balloons) {
    int n = balloons.length + 2;
    int[] nums = new int[n];
    nums[0] = nums[n - 1] = 1; // virtual balloons worth 1 at both ends
    System.arraycopy(balloons, 0, nums, 1, balloons.length);
    int[][] best = new int[n][n];
    for (int gap = 2; gap < n; gap++) {           // interval width, shortest first
        for (int left = 0; left + gap < n; left++) {
            int right = left + gap;
            for (int last = left + 1; last < right; last++) { // the balloon burst last
                int coins = best[left][last] + nums[left] * nums[last] * nums[right] + best[last][right];
                best[left][right] = Math.max(best[left][right], coins);
            }
        }
    }
    return best[0][n - 1];
}

JavaScript

// Interval DP: best[l][r] = most coins from bursting everything strictly between l and r.
function maxCoins(balloons) {
  const nums = [1, ...balloons, 1]; // virtual balloons worth 1 at both ends
  const n = nums.length;
  const best = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let gap = 2; gap < n; gap++) {           // interval width, shortest first
    for (let left = 0; left + gap < n; left++) {
      const right = left + gap;
      for (let last = left + 1; last < right; last++) { // the balloon burst last
        const coins = best[left][last] + nums[left] * nums[last] * nums[right] + best[last][right];
        best[left][right] = Math.max(best[left][right], coins);
      }
    }
  }
  return best[0][n - 1];
}

Complexity

  • Time O(n³) — n² intervals, each trying up to n last balloons
  • Space O(n²) — the interval table

"Choose the last one" is the standard trick for interval DP where removing an element changes its neighbours — you will meet it again in matrix-chain multiplication and "minimum cost to cut a stick".
