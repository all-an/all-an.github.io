Diameter of a binary tree

Medium Tree / DFS

The diameter of a binary tree is the length (counted in edges) of the longest path between any two nodes. The path need not pass through the root. For 1 / (2 / (4, 5), 3) it is 3 (4 → 2 → 1 → 3).

Approach

The longest path that turns at a given node has length height(left) + height(right) — down the deepest branch on each side. So compute every node's height in one post-order traversal, and while doing so update a global "best" with left + right at each node. The answer is the largest value seen; the path may bend at any node, which is why checking only the root is wrong.

The helper does two jobs: it returns the height to its parent, and it records the diameter as a side effect.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

private static int best; // longest path found so far, in edges

// Compute the diameter with one post-order pass.
static int diameterOfBinaryTree(TreeNode root) {
    best = 0;
    height(root);
    return best;
}

// Returns the node's height and updates 'best' with the longest path bending here.
static int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);
    int right = height(node.right);
    best = Math.max(best, left + right);
    return 1 + Math.max(left, right);
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// Compute the diameter with one post-order pass.
function diameterOfBinaryTree(root) {
  let best = 0; // longest path found so far, in edges

  // Returns the node's height and updates 'best' with the longest path bending here.
  function height(node) {
    if (!node) return 0;
    const left = height(node.left);
    const right = height(node.right);
    best = Math.max(best, left + right);
    return 1 + Math.max(left, right);
  }

  height(root);
  return best;
}

Complexity

  • Time O(n) — every node is visited once
  • Space O(h) — recursion depth equals the tree height

The naive approach — computing height separately at every node — is O(n²) on a skewed tree. Returning one value and updating another as a side effect is a pattern that recurs in "maximum path sum" and similar tree problems.
