Clone a graph

Medium Graph / BFS, DFS

Make a deep copy of a connected, undirected graph: every node and every edge must be duplicated, and the copy must not share any node objects with the original. The difficulty is cycles — a naive copy would loop forever.

Try it

↓

Approach

Traverse the graph (DFS or BFS) while keeping a map from each original node to its copy. When you reach a node: if it is already in the map, return its copy (this is what breaks cycles); otherwise create the copy, register it in the map first, and only then clone its neighbours, adding each neighbour's copy to the new node's neighbour list.

Registering the copy before recursing is the crucial ordering — otherwise a cycle sends the recursion back to a node that has no copy yet.

Java

static class Node {
    int val;
    List<Node> neighbors = new ArrayList<>();
    Node(int val) { this.val = val; }
}

// DFS clone: the map links each original node to its copy and also serves as the visited set.
static Node cloneGraph(Node node) {
    return cloneGraph(node, new HashMap<>());
}

static Node cloneGraph(Node node, Map<Node, Node> copies) {
    if (node == null) return null;
    if (copies.containsKey(node)) return copies.get(node); // already cloned: reuse
    Node copy = new Node(node.val);
    copies.put(node, copy); // register before recursing so cycles terminate
    for (Node neighbor : node.neighbors) {
        copy.neighbors.add(cloneGraph(neighbor, copies));
    }
    return copy;
}

JavaScript

class GraphNode {
  constructor(val) {
    this.val = val;
    this.neighbors = [];
  }
}

// DFS clone: the map links each original node to its copy and also serves as the visited set.
function cloneGraph(node, copies = new Map()) {
  if (!node) return null;
  if (copies.has(node)) return copies.get(node); // already cloned: reuse
  const copy = new GraphNode(node.val);
  copies.set(node, copy); // register before recursing so cycles terminate
  for (const neighbor of node.neighbors) {
    copy.neighbors.push(cloneGraph(neighbor, copies));
  }
  return copy;
}

Complexity

  • Time O(V + E) — every node and every edge is processed once
  • Space O(V) — the map plus the recursion stack

A BFS version with a queue works the same way and avoids deep recursion. The "map from original to copy" trick also solves "copy a linked list with random pointers".
