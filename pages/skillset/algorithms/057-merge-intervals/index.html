Merge intervals

Medium Sorting / Intervals

Given a list of intervals, merge all the overlapping ones — [[1,3], [2,6], [8,10], [15,18]] becomes [[1,6], [8,10], [15,18]], because [1,3] and [2,6] overlap.

Approach

Sort the intervals by start time. Now any interval that overlaps the previous one is adjacent, so a single sweep suffices: keep a result list; for each interval, if it starts at or before the end of the last result interval, they overlap — extend the last one's end to max(end, thatEnd); otherwise append the interval as a new one.

Use max when extending, since the new interval may be entirely inside the last one ([1,10] and [2,3]). Decide whether touching intervals like [1,4] and [4,5] merge — here they do (<=).

Java

// Sort by start, then sweep, extending or appending.
static int[][] merge(int[][] intervals) {
    int[][] sorted = intervals.clone();
    Arrays.sort(sorted, Comparator.comparingInt(interval -> interval[0]));
    List<int[]> merged = new ArrayList<>();
    for (int[] interval : sorted) {
        int[] last = merged.isEmpty() ? null : merged.get(merged.size() - 1);
        if (last != null && interval[0] <= last[1]) {
            last[1] = Math.max(last[1], interval[1]); // overlap: extend the last interval
        } else {
            merged.add(new int[] { interval[0], interval[1] }); // gap: start a new one
        }
    }
    return merged.toArray(new int[0][]);
}

JavaScript

// Sort by start, then sweep, extending or appending.
function merge(intervals) {
  const sorted = intervals.map(([start, end]) => [start, end]).sort((a, b) => a[0] - b[0]);
  const merged = [];
  for (const [start, end] of sorted) {
    const last = merged[merged.length - 1];
    if (last && start <= last[1]) {
      last[1] = Math.max(last[1], end); // overlap: extend the last interval
    } else {
      merged.push([start, end]);        // gap: start a new one
    }
  }
  return merged;
}

Complexity

  • Time O(n log n) — dominated by the sort; the sweep is O(n)
  • Space O(n) — the result list (plus the sorted copy)

Sorting is the crucial first step: without it, overlaps can be anywhere and you would need O(n²) comparisons. The same sort-then-sweep skeleton solves "insert interval", "meeting rooms" and "non-overlapping intervals".
