Word ladder (BFS)

Hard Graph / BFS

Transform a start word into an end word by changing one letter at a time, where every intermediate word must be in a given dictionary. Return the length of the shortest transformation sequence — "hit" → "hot" → "dot" → "dog" → "cog" has length 5. Shortest path in an unweighted graph means BFS.

Try it

Approach

Treat every word as a node, with an edge between two words that differ in exactly one letter. The fewest transformations is the shortest path from the start to the end, and BFS finds shortest paths in unweighted graphs level by level.

Generating neighbours by trying 26 × length single-letter changes and checking the dictionary is far cheaper than comparing the current word with every dictionary word. Removing a word from the dictionary the moment it is first reached doubles as the visited set. A bidirectional BFS, searching from both ends until the frontiers meet, is a good optimisation.

Java

// BFS from beginWord; each level is one more transformation step.
static int ladderLength(String beginWord, String endWord, List<String> wordList) {
    Set<String> unvisited = new HashSet<>(wordList);
    if (!unvisited.contains(endWord)) return 0;
    Queue<String> queue = new ArrayDeque<>();
    queue.add(beginWord);
    int steps = 1;
    while (!queue.isEmpty()) {
        for (int size = queue.size(); size > 0; size--) { // process one whole level
            String word = queue.remove();
            if (word.equals(endWord)) return steps;
            char[] letters = word.toCharArray();
            for (int i = 0; i < letters.length; i++) {
                char original = letters[i];
                for (char c = 'a'; c <= 'z'; c++) {
                    letters[i] = c;
                    String candidate = new String(letters);
                    if (unvisited.remove(candidate)) queue.add(candidate); // remove = mark visited
                }
                letters[i] = original; // restore before changing the next position
            }
        }
        steps++;
    }
    return 0; // no ladder exists
}

JavaScript

// BFS from beginWord; each level is one more transformation step.
function ladderLength(beginWord, endWord, wordList) {
  const unvisited = new Set(wordList);
  if (!unvisited.has(endWord)) return 0;
  let level = [beginWord];
  let steps = 1;
  while (level.length > 0) {
    const nextLevel = [];
    for (const word of level) {
      if (word === endWord) return steps;
      for (let i = 0; i < word.length; i++) {
        for (let code = 97; code <= 122; code++) { // 'a'..'z'
          const candidate = word.slice(0, i) + String.fromCharCode(code) + word.slice(i + 1);
          if (unvisited.delete(candidate)) nextLevel.push(candidate); // delete = mark visited
        }
      }
    }
    level = nextLevel;
    steps++;
  }
  return 0; // no ladder exists
}

Complexity

  • Time O(N × L × 26) — N dictionary words of length L, each expanded once
  • Space O(N × L) — the dictionary set and the queue

The begin word does not have to be in the dictionary; the end word must be. To return the ladders themselves ("Word Ladder II"), record each word's parents during BFS and rebuild all shortest paths afterwards.
