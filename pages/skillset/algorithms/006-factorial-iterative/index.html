Factorial (iterative)

Beginner Math

The factorial of n, written n!, is the product of every integer from 1 to n — 5! = 5 × 4 × 3 × 2 × 1 = 120. By convention 0! = 1. Here we compute it with a loop; the recursive version comes later in the list.

Approach

Start a running product at 1 and multiply it by each integer from 2 up to n. Starting at 1 (not 0) makes 0! and 1! come out right without a special case. Reject negative input, because the factorial is not defined for it.

Factorials grow explosively: 21! already overflows a 64-bit long, so mention BigInteger (Java) or BigInt (JavaScript) if the interviewer asks for large n.

Java

// Iterative factorial with a long; exact up to 20!.
static long factorial(int n) {
    if (n < 0) {
        throw new IllegalArgumentException("n cannot be negative");
    }
    long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}

// Arbitrary size: BigInteger never overflows.
static java.math.BigInteger factorialBig(int n) {
    java.math.BigInteger result = java.math.BigInteger.ONE;
    for (int i = 2; i <= n; i++) {
        result = result.multiply(java.math.BigInteger.valueOf(i));
    }
    return result;
}

JavaScript

// Iterative factorial with a Number; exact only up to 18!.
function factorial(n) {
  if (n < 0) {
    throw new Error('n cannot be negative');
  }
  let result = 1;
  for (let i = 2; i <= n; i++) {
    result *= i;
  }
  return result;
}

// Arbitrary size: BigInt never loses precision.
function factorialBig(n) {
  let result = 1n;
  for (let i = 2n; i <= BigInt(n); i++) {
    result *= i;
  }
  return result;
}

Complexity

  • Time O(n) — n − 1 multiplications
  • Space O(1) — a single running product (the BigInteger result itself grows with n)

The loop uses constant stack space, unlike the recursive version, which adds one stack frame per step and can hit a StackOverflowError for large n.
