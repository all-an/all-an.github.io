Critical connections in a network (Tarjan's bridges)

Hard Graph / Tarjan

In a network of servers connected by bidirectional links, a link is critical (a "bridge") if removing it splits the network into disconnected parts. Find all of them. Tarjan's algorithm does it in one depth-first search.

Try it

↓

Approach

Run a DFS and give each node a discovery time. For each node also compute low: the earliest discovery time reachable from its DFS subtree using at most one back edge (an edge to an already-visited node that is not the parent). After exploring a child v of u, set low[u] = min(low[u], low[v]). If low[v] > discovery[u], then nothing in v's subtree can reach u or above except through the edge u–v — so that edge is a bridge.

Skip the edge back to the parent (or you would see every edge as a cycle). In a graph with parallel edges you must skip only one copy of the parent edge.

Java

private static int clock;

// Tarjan's bridge-finding: one DFS computing discovery and low-link times.
static List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
    for (List<Integer> edge : connections) {
        graph.get(edge.get(0)).add(edge.get(1));
        graph.get(edge.get(1)).add(edge.get(0));
    }
    int[] discovered = new int[n];
    Arrays.fill(discovered, -1);
    int[] lowest = new int[n];
    List<List<Integer>> bridges = new ArrayList<>();
    clock = 0;
    for (int node = 0; node < n; node++) {
        if (discovered[node] == -1) visit(node, -1, graph, discovered, lowest, bridges);
    }
    return bridges;
}

static void visit(int node, int parent, List<List<Integer>> graph, int[] discovered, int[] lowest, List<List<Integer>> bridges) {
    discovered[node] = lowest[node] = clock++;
    for (int next : graph.get(node)) {
        if (next == parent) continue; // do not walk straight back along the tree edge
        if (discovered[next] == -1) {
            visit(next, node, graph, discovered, lowest, bridges);
            lowest[node] = Math.min(lowest[node], lowest[next]);
            if (lowest[next] > discovered[node]) bridges.add(List.of(node, next)); // no way around: a bridge
        } else {
            lowest[node] = Math.min(lowest[node], discovered[next]); // a back edge
        }
    }
}

JavaScript

// Tarjan's bridge-finding: one DFS computing discovery and low-link times.
function criticalConnections(n, connections) {
  const graph = Array.from({ length: n }, () => []);
  for (const [a, b] of connections) {
    graph[a].push(b);
    graph[b].push(a);
  }
  const discovered = new Array(n).fill(-1);
  const lowest = new Array(n).fill(0);
  const bridges = [];
  let clock = 0;

  function visit(node, parent) {
    discovered[node] = lowest[node] = clock++;
    for (const next of graph[node]) {
      if (next === parent) continue; // do not walk straight back along the tree edge
      if (discovered[next] === -1) {
        visit(next, node);
        lowest[node] = Math.min(lowest[node], lowest[next]);
        if (lowest[next] > discovered[node]) bridges.push([node, next]); // no way around: a bridge
      } else {
        lowest[node] = Math.min(lowest[node], discovered[next]); // a back edge
      }
    }
  }

  for (let node = 0; node < n; node++) {
    if (discovered[node] === -1) visit(node, -1);
  }
  return bridges;
}

Complexity

  • Time O(V + E) — a single DFS
  • Space O(V + E) — the adjacency lists plus the recursion stack

The same discovery/low-link idea finds articulation points (nodes whose removal disconnects the graph) and strongly connected components. On huge graphs use an iterative DFS to avoid stack overflow.
