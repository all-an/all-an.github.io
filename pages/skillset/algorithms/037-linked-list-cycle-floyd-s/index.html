Linked list cycle (Floyd's)

Easy–Medium Linked List / Two Pointers

Given the head of a linked list, decide whether it contains a cycle — some node's next pointer leads back to an earlier node, so walking the list never ends. Floyd's "tortoise and hare" detects it using no extra memory.

Try it

↓

Approach

Storing every visited node in a set finds a cycle (a revisit means a loop) but costs O(n) memory. Floyd's algorithm uses two pointers: slow moves one node per step and fast moves two. If the list has no cycle, fast reaches null and you return false. If it has a cycle, fast eventually laps slow inside the loop and they land on the same node — like two runners on a circular track.

Always check both fast and fast.next for null before advancing, or you dereference a null pointer on lists with an even length.

Java

static class ListNode {
    int value;
    ListNode next;
    ListNode(int value) { this.value = value; }
}

// Approach 1 — remember every visited node in a set (O(n) memory).
static boolean hasCycleWithSet(ListNode head) {
    Set<ListNode> visited = new HashSet<>();
    for (ListNode node = head; node != null; node = node.next) {
        if (!visited.add(node)) return true; // add() is false when already present
    }
    return false;
}

// Approach 2 — Floyd's tortoise and hare: O(1) memory.
static boolean hasCycle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;       // one step
        fast = fast.next.next;  // two steps
        if (slow == fast) return true; // the hare lapped the tortoise
    }
    return false; // the hare reached the end
}

JavaScript

class ListNode {
  constructor(value, next = null) {
    this.value = value;
    this.next = next;
  }
}

// Approach 1 — remember every visited node in a set (O(n) memory).
function hasCycleWithSet(head) {
  const visited = new Set();
  for (let node = head; node; node = node.next) {
    if (visited.has(node)) return true;
    visited.add(node);
  }
  return false;
}

// Approach 2 — Floyd's tortoise and hare: O(1) memory.
function hasCycle(head) {
  let slow = head;
  let fast = head;
  while (fast && fast.next) {
    slow = slow.next;       // one step
    fast = fast.next.next;  // two steps
    if (slow === fast) return true; // the hare lapped the tortoise
  }
  return false; // the hare reached the end
}

Complexity

  • Time O(n) — fast catches slow within a couple of laps of the cycle
  • Space O(1) — two pointers, no extra structure (the set version is O(n))

A frequent follow-up is finding where the cycle starts: after the pointers meet, restart one at the head and advance both one step at a time — they meet again at the cycle's first node.
