Sum of array elements

Beginner Array

Given an array of numbers, return their total — [1, 2, 3, 4] sums to 10. It is the simplest example of an accumulator, the pattern behind counting, averaging and reducing.

Try it

↓

Approach

Keep a total that starts at 0 — the identity for addition, so an empty array correctly sums to 0 — and add each element to it as you loop.

In production code, mention overflow: summing many int values can exceed 2³¹ − 1, so accumulate into a long.

Java

// Approach 1 — built-in: IntStream.sum().
static int sumOf(int[] numbers) {
    return Arrays.stream(numbers).sum();
}

// Approach 2 — manual: accumulate into a long to avoid int overflow.
static long sum(int[] numbers) {
    long total = 0;
    for (int number : numbers) {
        total += number;
    }
    return total;
}

JavaScript

// Approach 1 — built-in: reduce folds the array into one value.
function sumOf(numbers) {
  return numbers.reduce((total, number) => total + number, 0);
}

// Approach 2 — manual: accumulate in a loop.
function sum(numbers) {
  let total = 0;
  for (const number of numbers) {
    total += number;
  }
  return total;
}

Complexity

  • Time O(n) — every element is added once
  • Space O(1) — a single accumulator

Always give reduce an initial value (0 above): without one it throws on an empty array.
