Alien dictionary (topological sort)

Hard Graph / Topological Sort

An alien language uses the same letters in an unknown order. You are given words sorted by that language's dictionary order; deduce a possible order of the letters. For ["wrt", "wrf", "er", "ett", "rftt"] a valid order is "wertf". It is topological sorting with a string-comparison twist.

Approach

Every letter that appears is a node. Comparing two adjacent words, find the first position where they differ: the letter in the earlier word must come before the letter in the later word — that is one directed edge. Only that first difference tells you anything; later letters are unconstrained. Also watch for the invalid case where a longer word comes before its own prefix ("abc" before "ab").

Then run a topological sort (Kahn's algorithm: repeatedly take letters with no unmet predecessors). If it consumes every letter, the order it produced is valid; if letters remain, the rules contain a cycle and no alphabet exists. When several orders are valid, any one is accepted.

Java

// Build edges from adjacent words, then topologically sort the letters (Kahn's algorithm).
static String alienOrder(String[] words) {
    Map<Character, Set<Character>> after = new HashMap<>(); // letter -> letters that must follow it
    Map<Character, Integer> waiting = new HashMap<>();      // letter -> unmet predecessors
    for (String word : words) {
        for (char c : word.toCharArray()) {
            after.putIfAbsent(c, new HashSet<>());
            waiting.putIfAbsent(c, 0);
        }
    }
    for (int i = 0; i + 1 < words.length; i++) {
        String first = words[i], second = words[i + 1];
        if (first.length() > second.length() && first.startsWith(second)) return ""; // "abc" before "ab"
        for (int j = 0; j < Math.min(first.length(), second.length()); j++) {
            char a = first.charAt(j), b = second.charAt(j);
            if (a != b) { // the first difference gives one rule: a comes before b
                if (after.get(a).add(b)) waiting.merge(b, 1, Integer::sum);
                break;
            }
        }
    }
    Queue<Character> ready = new ArrayDeque<>();
    for (Map.Entry<Character, Integer> entry : waiting.entrySet()) {
        if (entry.getValue() == 0) ready.add(entry.getKey());
    }
    StringBuilder order = new StringBuilder();
    while (!ready.isEmpty()) {
        char c = ready.remove();
        order.append(c);
        for (char next : after.get(c)) {
            if (waiting.merge(next, -1, Integer::sum) == 0) ready.add(next);
        }
    }
    return order.length() == after.size() ? order.toString() : ""; // "" signals a cycle
}

JavaScript

// Build edges from adjacent words, then topologically sort the letters (Kahn's algorithm).
function alienOrder(words) {
  const after = new Map();   // letter -> letters that must follow it
  const waiting = new Map(); // letter -> unmet predecessors
  for (const word of words) {
    for (const char of word) {
      if (!after.has(char)) after.set(char, new Set());
      if (!waiting.has(char)) waiting.set(char, 0);
    }
  }
  for (let i = 0; i + 1 < words.length; i++) {
    const [first, second] = [words[i], words[i + 1]];
    if (first.length > second.length && first.startsWith(second)) return ''; // "abc" before "ab"
    for (let j = 0; j < Math.min(first.length, second.length); j++) {
      if (first[j] !== second[j]) { // the first difference gives one rule: first[j] comes before second[j]
        if (!after.get(first[j]).has(second[j])) {
          after.get(first[j]).add(second[j]);
          waiting.set(second[j], waiting.get(second[j]) + 1);
        }
        break;
      }
    }
  }
  const ready = [...waiting].filter(([, count]) => count === 0).map(([char]) => char);
  let order = '';
  while (ready.length > 0) {
    const char = ready.shift();
    order += char;
    for (const next of after.get(char)) {
      waiting.set(next, waiting.get(next) - 1);
      if (waiting.get(next) === 0) ready.push(next);
    }
  }
  return order.length === after.size ? order : ''; // '' signals a cycle
}

Complexity

  • Time O(C) — C is the total number of characters across all words
  • Space O(1) — the alphabet is finite, so the graph has a bounded number of nodes and edges (O(U + min(U², N)) in general)

The two easily-missed cases are the prefix rule and letters that appear in words but are never compared — they still belong in the answer, which is why every letter is registered as a node up front.
