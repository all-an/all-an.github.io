Flatten a binary tree to linked list

Medium–Hard Tree

Flatten a binary tree "in place" into a linked list that follows preorder, using each node's right pointer as next and setting every left to null. The tree 1 / (2 / (3, 4), 5 / (null, 6)) becomes 1 → 2 → 3 → 4 → 5 → 6.

Approach

A neat O(1)-space method (the Morris-style splice): for each node that has a left child, find the rightmost node of its left subtree — the last node preorder visits before it would move on to this node's right subtree. Point that rightmost node's right at the node's original right child, then move the whole left subtree over to the right (node.right = node.left, node.left = null). Advance to the next node along right and repeat.

The recursive alternative flattens the right subtree first, then the left, keeping a prev pointer to the node just processed — a reverse-postorder walk that rewires each node to point at prev.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

// Iterative flatten: splice each left subtree between the node and its right child.
static void flatten(TreeNode root) {
    TreeNode current = root;
    while (current != null) {
        if (current.left != null) {
            TreeNode rightmost = current.left;
            while (rightmost.right != null) rightmost = rightmost.right; // last node of the left subtree
            rightmost.right = current.right; // the old right subtree follows the left one
            current.right = current.left;    // move the left subtree to the right
            current.left = null;
        }
        current = current.right;
    }
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// Iterative flatten: splice each left subtree between the node and its right child.
function flatten(root) {
  let current = root;
  while (current) {
    if (current.left) {
      let rightmost = current.left;
      while (rightmost.right) rightmost = rightmost.right; // last node of the left subtree
      rightmost.right = current.right; // the old right subtree follows the left one
      current.right = current.left;    // move the left subtree to the right
      current.left = null;
    }
    current = current.right;
  }
}

Complexity

  • Time O(n) — each node is passed a constant number of times
  • Space O(1) — rewires pointers in place (recursive versions use O(h) stack)

Ask whether the flattened list must follow preorder (it does here) — the result differs for inorder or postorder variants.
