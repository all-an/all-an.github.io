Find all permutations of a string/array

Hard Backtracking

Generate every ordering of the elements of a string or array — the permutations of [1, 2, 3] are six: 123, 132, 213, 231, 312, 321. It is the introductory backtracking problem: build a candidate step by step and undo each choice after exploring it.

↓

Approach

Think of a decision tree. At each level you choose one of the elements not yet used, add it to the current permutation, and recurse to fill the next position. When the permutation is complete, record a copy. Then backtrack: remove the element you added and mark it unused, so the next loop iteration can try a different choice at that position.

An alternative swaps elements in place: at position start, swap each later element into it, recurse on start + 1, then swap back. For inputs with duplicates, sort first and skip a value equal to its predecessor that was not used, to avoid repeated results.

Java

// Backtracking with a "used" flag per element.
static List<List<Integer>> permutations(int[] numbers) {
    List<List<Integer>> results = new ArrayList<>();
    backtrack(numbers, new boolean[numbers.length], new ArrayList<>(), results);
    return results;
}

static void backtrack(int[] numbers, boolean[] used, List<Integer> current, List<List<Integer>> results) {
    if (current.size() == numbers.length) {
        results.add(new ArrayList<>(current)); // record a copy of the finished permutation
        return;
    }
    for (int i = 0; i < numbers.length; i++) {
        if (used[i]) continue;
        used[i] = true;                    // choose
        current.add(numbers[i]);
        backtrack(numbers, used, current, results); // explore
        current.remove(current.size() - 1); // un-choose
        used[i] = false;
    }
}

JavaScript

// Backtracking with a "used" flag per element.
function permutations(numbers) {
  const results = [];
  const used = new Array(numbers.length).fill(false);
  const current = [];

  function backtrack() {
    if (current.length === numbers.length) {
      results.push([...current]); // record a copy of the finished permutation
      return;
    }
    for (let i = 0; i < numbers.length; i++) {
      if (used[i]) continue;
      used[i] = true;              // choose
      current.push(numbers[i]);
      backtrack();                 // explore
      current.pop();               // un-choose
      used[i] = false;
    }
  }

  backtrack();
  return results;
}

Complexity

  • Time O(n × n!) — n! permutations, each copied in O(n)
  • Space O(n) — recursion depth and the current path (the output itself is n × n!)

The count explodes: 10 elements already give 3,628,800 permutations. Never generate them when you only need the next one — use the "next permutation" algorithm instead.
