Coin change (DP – minimum coins)

Medium Dynamic Programming

Given coin denominations and a target amount, find the fewest coins that make the amount exactly, or −1 if impossible — with coins [1, 2, 5] and amount 11 the answer is 3 (5 + 5 + 1). A greedy "biggest coin first" is not always right, which is why this is dynamic programming.

Approach

Let best[a] be the fewest coins that sum to amount a. best[0] = 0. For any other amount, try each coin: if the coin fits, one option is best[a − coin] + 1 — use the coin, then solve the smaller remainder. Take the minimum over all coins. Initialise the table with "infinity" (any number bigger than the possible answer), and if best[amount] is still infinity at the end, return −1.

Why not greedy? With coins [1, 3, 4] and amount 6, taking the biggest coin first gives 4 + 1 + 1 (3 coins), but 3 + 3 is just 2.

Java

// Bottom-up DP: best[a] = fewest coins that make amount a.
static int coinChange(int[] coins, int amount) {
    int[] best = new int[amount + 1];
    Arrays.fill(best, amount + 1); // amount + 1 acts as "infinity": more coins than could ever be needed
    best[0] = 0;
    for (int a = 1; a <= amount; a++) {
        for (int coin : coins) {
            if (coin <= a) {
                best[a] = Math.min(best[a], best[a - coin] + 1);
            }
        }
    }
    return best[amount] > amount ? -1 : best[amount];
}

JavaScript

// Bottom-up DP: best[a] = fewest coins that make amount a.
function coinChange(coins, amount) {
  const best = new Array(amount + 1).fill(Infinity);
  best[0] = 0;
  for (let a = 1; a <= amount; a++) {
    for (const coin of coins) {
      if (coin <= a) {
        best[a] = Math.min(best[a], best[a - coin] + 1);
      }
    }
  }
  return best[amount] === Infinity ? -1 : best[amount];
}

Complexity

  • Time O(amount × coins) — each table cell tries every coin
  • Space O(amount) — the one-dimensional table

A variant asks for the number of ways to make the amount (loop the coins on the outside to avoid counting permutations). Both are instances of unbounded knapsack.
