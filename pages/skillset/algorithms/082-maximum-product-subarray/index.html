Maximum product subarray

Medium–Hard Array / DP

Find the contiguous subarray with the largest product — in [2, 3, -2, 4] it is [2, 3] with product 6. It looks like Kadane's algorithm, but negatives change everything: a very negative product can become the largest after multiplying by another negative.

Try it

↓

Approach

With only non-negative numbers, a running product would be enough. But multiplying by a negative flips the order: the most negative product so far becomes the most positive one. So at every position keep two values — the largest and the smallest product of a subarray ending here. For the next number x, the new largest and smallest are the max and min of x (start fresh), largest × x and smallest × x. A zero resets both, since starting fresh at x always beats extending a product of 0.

The answer is the largest largest seen anywhere. Compute both candidates from the old values before overwriting them.

Java

// Track the largest and smallest product of a subarray ending at each index.
static int maxProduct(int[] numbers) {
    int largest = numbers[0];  // best product ending here
    int smallest = numbers[0]; // worst (most negative) product ending here
    int best = numbers[0];
    for (int i = 1; i < numbers.length; i++) {
        int x = numbers[i];
        int fromLargest = largest * x;
        int fromSmallest = smallest * x; // a negative x turns this into a candidate for the maximum
        largest = Math.max(x, Math.max(fromLargest, fromSmallest));
        smallest = Math.min(x, Math.min(fromLargest, fromSmallest));
        best = Math.max(best, largest);
    }
    return best;
}

JavaScript

// Track the largest and smallest product of a subarray ending at each index.
function maxProduct(numbers) {
  let largest = numbers[0];  // best product ending here
  let smallest = numbers[0]; // worst (most negative) product ending here
  let best = numbers[0];
  for (let i = 1; i < numbers.length; i++) {
    const x = numbers[i];
    const fromLargest = largest * x;
    const fromSmallest = smallest * x; // a negative x turns this into a candidate for the maximum
    largest = Math.max(x, fromLargest, fromSmallest);
    smallest = Math.min(x, fromLargest, fromSmallest);
    best = Math.max(best, largest);
  }
  return best;
}

Complexity

  • Time O(n) — a single pass
  • Space O(1) — three variables

A frequent slip is updating largest and then using the new value to compute smallest; both must be derived from the previous pair. Products can overflow quickly — clarify the value range.
