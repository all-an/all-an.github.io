Find the maximum/minimum in an array

Beginner Array

Given an array of numbers, return its largest and smallest values — for example [3, 7, 1, 9, 4] has a maximum of 9 and a minimum of 1. It is the first exercise in scanning an array while carrying state.

Try it

↓

Approach

Start by assuming the first element is both the minimum and the maximum, then walk the rest of the array once. Whenever an element is smaller than the current minimum, or larger than the current maximum, it replaces it. After one pass the two variables hold the answer — no sorting needed.

Decide up front what an empty array means: there is no maximum, so throw an exception (or return an Optional) instead of returning a made-up number.

Java

// Approach 1 — built-in: streams reduce the array to its extremes.
static int maxOf(int[] numbers) {
    return Arrays.stream(numbers).max().getAsInt();
}

// Approach 2 — manual: one pass carrying the best values so far.
static int[] findMinMax(int[] numbers) {
    if (numbers == null || numbers.length == 0) {
        throw new IllegalArgumentException("Array cannot be empty");
    }
    int min = numbers[0];
    int max = numbers[0];
    for (int number : numbers) {
        if (number < min) min = number;
        if (number > max) max = number;
    }
    return new int[] { min, max };
}

JavaScript

// Approach 1 — built-in: Math.max / Math.min with the spread operator.
// (Very large arrays can overflow the call stack; use a loop for those.)
function maxOf(numbers) {
  return Math.max(...numbers);
}

// Approach 2 — manual: one pass carrying the best values so far.
function findMinMax(numbers) {
  if (numbers == null || numbers.length === 0) {
    throw new Error('Array cannot be empty');
  }
  let min = numbers[0];
  let max = numbers[0];
  for (const number of numbers) {
    if (number < min) min = number;
    if (number > max) max = number;
  }
  return [min, max];
}

Complexity

  • Time O(n) — every element is looked at exactly once
  • Space O(1) — only two variables are kept, whatever the size

Sorting the array first would also work but costs O(n log n) for information one pass can give you. Tracking both values in the same loop is also faster than scanning twice, once for each.
