Reverse a linked list (iterative)

Easy Linked List

Given the head of a singly linked list, reverse it and return the new head — 1 → 2 → 3 → null becomes 3 → 2 → 1 → null. It is the canonical pointer-manipulation problem.

Try it

↓

Approach

Walk the list with three pointers: previous (starts as null), current (starts at the head) and a temporary next. At each node: save current.next, point current.next back at previous, then advance both pointers. When current falls off the end, previous is the new head.

The order matters: if you overwrite current.next before saving it, you lose the rest of the list.

Java

static class ListNode {
    int value;
    ListNode next;
    ListNode(int value) { this.value = value; }
}

// Reverse in place by re-pointing every node at its predecessor.
static ListNode reverseList(ListNode head) {
    ListNode previous = null;
    ListNode current = head;
    while (current != null) {
        ListNode next = current.next; // save the rest before breaking the link
        current.next = previous;      // point backwards
        previous = current;           // advance both pointers
        current = next;
    }
    return previous; // the old tail is the new head
}

JavaScript

class ListNode {
  constructor(value, next = null) {
    this.value = value;
    this.next = next;
  }
}

// Reverse in place by re-pointing every node at its predecessor.
function reverseList(head) {
  let previous = null;
  let current = head;
  while (current) {
    const next = current.next; // save the rest before breaking the link
    current.next = previous;   // point backwards
    previous = current;        // advance both pointers
    current = next;
  }
  return previous; // the old tail is the new head
}

Complexity

  • Time O(n) — each node is visited once
  • Space O(1) — only three pointers, no new nodes

A recursive version exists (reverse the tail, then attach the head to its end) but uses O(n) stack space; the iterative one is what interviewers usually want first.
