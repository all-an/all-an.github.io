Move zeroes to end of array

Easy Array / Two Pointers

Move all the zeroes in an array to the end while keeping the order of the other elements — [0, 1, 0, 3, 12] becomes [1, 3, 12, 0, 0]. The twist is doing it in place, without a second array.

↓

Approach

Use two pointers: read scans every element, write marks where the next non-zero belongs. Each time read finds a non-zero, copy it to write and advance write. When the scan finishes, every non-zero has been packed to the front in its original order; fill everything from write onward with zeroes.

A one-loop variant swaps the non-zero with the element at write instead, which does the zero-filling for free.

Java

// Two pointers: pack the non-zeroes to the front, then zero-fill the rest.
static void moveZeroes(int[] numbers) {
    int write = 0; // next slot for a non-zero value
    for (int read = 0; read < numbers.length; read++) {
        if (numbers[read] != 0) {
            numbers[write++] = numbers[read];
        }
    }
    while (write < numbers.length) {
        numbers[write++] = 0;
    }
}

JavaScript

// Two pointers: pack the non-zeroes to the front, then zero-fill the rest.
function moveZeroes(numbers) {
  let write = 0; // next slot for a non-zero value
  for (let read = 0; read < numbers.length; read++) {
    if (numbers[read] !== 0) {
      numbers[write++] = numbers[read];
    }
  }
  while (write < numbers.length) {
    numbers[write++] = 0;
  }
  return numbers;
}

Complexity

  • Time O(n) — one scan plus one fill, each touching at most n slots
  • Space O(1) — the array is modified in place

The same read/write-pointer pattern solves "remove element", "remove duplicates from a sorted array" and many other in-place filtering problems.
