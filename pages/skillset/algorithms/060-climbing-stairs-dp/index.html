Climbing stairs (DP)

Medium Dynamic Programming

You climb a staircase of n steps, taking 1 or 2 steps at a time. How many distinct ways are there to reach the top? For n = 3 there are 3: 1+1+1, 1+2 and 2+1.

Try it

↓

Approach

To land on step n, your last move was either a 1-step from n − 1 or a 2-step from n − 2. So ways(n) = ways(n − 1) + ways(n − 2) — the Fibonacci recurrence in disguise. Base cases: one way to reach step 0 (do nothing) and one way to reach step 1.

Recursion would recompute values exponentially, so use a loop and keep only the last two results.

Java

// DP with two rolling values: ways(n) = ways(n - 1) + ways(n - 2).
static int climbStairs(int n) {
    int twoBack = 1; // ways to reach step 0
    int oneBack = 1; // ways to reach step 1
    for (int step = 2; step <= n; step++) {
        int current = oneBack + twoBack;
        twoBack = oneBack;
        oneBack = current;
    }
    return oneBack;
}

JavaScript

// DP with two rolling values: ways(n) = ways(n - 1) + ways(n - 2).
function climbStairs(n) {
  let twoBack = 1; // ways to reach step 0
  let oneBack = 1; // ways to reach step 1
  for (let step = 2; step <= n; step++) {
    [twoBack, oneBack] = [oneBack, oneBack + twoBack];
  }
  return oneBack;
}

Complexity

  • Time O(n) — one addition per step
  • Space O(1) — only two rolling values

If you may take any of a set of step sizes (say 1, 3 or 5), the recurrence just sums more previous terms. It is the friendliest gateway problem to dynamic programming.
