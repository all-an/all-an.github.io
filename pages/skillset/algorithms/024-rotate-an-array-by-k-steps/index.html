Rotate an array by k steps

Easy Array

Rotate an array to the right by k steps — [1, 2, 3, 4, 5, 6, 7] rotated by 3 becomes [5, 6, 7, 1, 2, 3, 4]. The interesting version does it in place, in O(n) time.

Try it

↓

Approach

First reduce k with k % n — rotating by n is a no-op. The extra-array method copies each element to index (i + k) % n of a new array. The in-place trick uses three reversals: reverse the whole array, then reverse the first k elements, then reverse the remaining n − k. Try it on the example: [7,6,5,4,3,2,1] → [5,6,7,4,3,2,1] → [5,6,7,1,2,3,4].

Java

// Approach 1 — extra array: element i lands at (i + k) % n.
static int[] rotateCopy(int[] numbers, int k) {
    int n = numbers.length;
    int[] rotated = new int[n];
    for (int i = 0; i < n; i++) {
        rotated[(i + k) % n] = numbers[i];
    }
    return rotated;
}

// Approach 2 — in place: reverse everything, then reverse each part.
static void rotate(int[] numbers, int k) {
    int n = numbers.length;
    k %= n; // rotating by n changes nothing
    reverse(numbers, 0, n - 1);
    reverse(numbers, 0, k - 1);
    reverse(numbers, k, n - 1);
}

static void reverse(int[] numbers, int from, int to) {
    while (from < to) {
        int temp = numbers[from];
        numbers[from++] = numbers[to];
        numbers[to--] = temp;
    }
}

JavaScript

// Approach 1 — extra array: element i lands at (i + k) % n.
function rotateCopy(numbers, k) {
  const n = numbers.length;
  const rotated = new Array(n);
  for (let i = 0; i < n; i++) {
    rotated[(i + k) % n] = numbers[i];
  }
  return rotated;
}

// Approach 2 — in place: reverse everything, then reverse each part.
function rotate(numbers, k) {
  const n = numbers.length;
  k %= n; // rotating by n changes nothing
  reverse(numbers, 0, n - 1);
  reverse(numbers, 0, k - 1);
  reverse(numbers, k, n - 1);
  return numbers;
}

function reverse(numbers, from, to) {
  while (from < to) {
    [numbers[from], numbers[to]] = [numbers[to], numbers[from]];
    from++;
    to--;
  }
}

Complexity

  • Time O(n) — the reversals touch each element a constant number of times
  • Space O(1) — in place (the copy version needs O(n))

A rotation to the left by k is the same as a right rotation by n − k. Always normalize k first, or a large or negative k will index out of bounds.
