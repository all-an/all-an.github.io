Longest substring without repeating characters

Medium Sliding Window

Find the length of the longest substring that contains no repeated character — in "abcabcbb" it is "abc", length 3. The textbook sliding-window problem.

Try it

↓

Approach

Keep a window [start, end] that always holds distinct characters. Extend end one character at a time; remember the last index at which each character was seen. If the new character was last seen inside the window, jump start to just after that earlier occurrence, so the window is duplicate-free again. After each step, the window length is a candidate for the answer.

The check that the previous index is at least start matters: an old occurrence that is already left of the window must be ignored (see "abba").

Java

// Sliding window with a map of each character's last index.
static int lengthOfLongestSubstring(String text) {
    Map<Character, Integer> lastSeen = new HashMap<>();
    int start = 0;
    int best = 0;
    for (int end = 0; end < text.length(); end++) {
        char c = text.charAt(end);
        Integer previous = lastSeen.get(c);
        if (previous != null && previous >= start) {
            start = previous + 1; // move past the earlier duplicate
        }
        lastSeen.put(c, end);
        best = Math.max(best, end - start + 1);
    }
    return best;
}

JavaScript

// Sliding window with a map of each character's last index.
function lengthOfLongestSubstring(text) {
  const lastSeen = new Map();
  let start = 0;
  let best = 0;
  for (let end = 0; end < text.length; end++) {
    const char = text[end];
    if (lastSeen.has(char) && lastSeen.get(char) >= start) {
      start = lastSeen.get(char) + 1; // move past the earlier duplicate
    }
    lastSeen.set(char, end);
    best = Math.max(best, end - start + 1);
  }
  return best;
}

Complexity

  • Time O(n) — each character is handled once as the window grows
  • Space O(k) — k is the size of the character set

A set-based variant removes characters from the left one by one until the duplicate is gone — the same O(n) overall, but slightly more code. The pattern "expand right, shrink left while invalid" solves many window problems.
