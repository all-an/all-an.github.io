Wildcard matching (DP)

Hard Dynamic Programming

Match a string against a pattern where ? matches exactly one character and * matches any sequence, including the empty one — "adceb" matches "*a*b". Unlike regular-expression *, here the star stands on its own.

Approach

Greedy two pointers (O(1) space): walk the text and the pattern together. On a match (equal characters or ?) advance both. On a *, remember its position and the current text position, and tentatively let the star match nothing — advance only the pattern. On a mismatch, if there was an earlier star, backtrack: let that star swallow one more text character (advance the remembered text position by one) and resume the pattern just after the star. With no star to fall back on, the match fails. After the text is consumed, any remaining pattern must be all stars.

DP (easier to justify): table[i][j] is true if the first i text characters match the first j pattern characters. A * gives table[i][j − 1] (matches empty) or table[i − 1][j] (absorbs one more character); ? or an equal character gives table[i − 1][j − 1].

Java

// Greedy two pointers with backtracking to the most recent star.
static boolean isMatch(String text, String pattern) {
    int t = 0, p = 0;
    int starAt = -1;  // position of the latest '*' in the pattern
    int resumeAt = 0; // text position where that star started matching
    while (t < text.length()) {
        if (p < pattern.length() && (pattern.charAt(p) == '?' || pattern.charAt(p) == text.charAt(t))) {
            t++;
            p++;
        } else if (p < pattern.length() && pattern.charAt(p) == '*') {
            starAt = p++;   // the star matches nothing, for now
            resumeAt = t;
        } else if (starAt != -1) {
            p = starAt + 1; // let the star swallow one more character
            t = ++resumeAt;
        } else {
            return false;   // mismatch with no star to fall back on
        }
    }
    while (p < pattern.length() && pattern.charAt(p) == '*') p++; // trailing stars match empty
    return p == pattern.length();
}

JavaScript

// Greedy two pointers with backtracking to the most recent star.
function isMatch(text, pattern) {
  let t = 0;
  let p = 0;
  let starAt = -1;  // position of the latest '*' in the pattern
  let resumeAt = 0; // text position where that star started matching
  while (t < text.length) {
    if (p < pattern.length && (pattern[p] === '?' || pattern[p] === text[t])) {
      t++;
      p++;
    } else if (p < pattern.length && pattern[p] === '*') {
      starAt = p++;   // the star matches nothing, for now
      resumeAt = t;
    } else if (starAt !== -1) {
      p = starAt + 1; // let the star swallow one more character
      t = ++resumeAt;
    } else {
      return false;   // mismatch with no star to fall back on
    }
  }
  while (p < pattern.length && pattern[p] === '*') p++; // trailing stars match empty
  return p === pattern.length;
}

Complexity

  • Time O(m × n) — worst case for the greedy version (typically near-linear); the DP is O(m × n) always
  • Space O(1) — greedy needs only pointers (DP: O(m × n))

Only the most recent star ever needs remembering: an earlier star can always be kept matching what it matched, so re-expanding the latest one is enough. That is why the greedy version is correct.
