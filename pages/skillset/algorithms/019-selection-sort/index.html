Selection sort

Easy Sorting

Selection sort repeatedly selects the smallest remaining element and swaps it into the next position of the sorted prefix. It is simple, and notable for making at most n − 1 swaps.

Try it

↓

Approach

Split the array into a sorted prefix (initially empty) and an unsorted rest. On each step, scan the unsorted part to find the index of its minimum, then swap that element with the first unsorted position — the prefix grows by one. After n − 1 steps the array is sorted.

Unlike bubble or insertion sort, it always does the full O(n²) scan, even on sorted input, and the long-distance swap makes it not stable.

Java

// Selection sort: swap the minimum of the unsorted part into place.
static void selectionSort(int[] numbers) {
    for (int i = 0; i < numbers.length - 1; i++) {
        int smallest = i;
        for (int j = i + 1; j < numbers.length; j++) {
            if (numbers[j] < numbers[smallest]) smallest = j;
        }
        int temp = numbers[i];
        numbers[i] = numbers[smallest];
        numbers[smallest] = temp;
    }
}

JavaScript

// Selection sort: swap the minimum of the unsorted part into place.
function selectionSort(numbers) {
  for (let i = 0; i < numbers.length - 1; i++) {
    let smallest = i;
    for (let j = i + 1; j < numbers.length; j++) {
      if (numbers[j] < numbers[smallest]) smallest = j;
    }
    [numbers[i], numbers[smallest]] = [numbers[smallest], numbers[i]];
  }
  return numbers;
}

Complexity

  • Time O(n²) — always about n²/2 comparisons, best case included
  • Space O(1) — sorts in place

Because it writes so rarely (at most n − 1 swaps), selection sort is occasionally chosen when writes are far more expensive than reads, e.g. on flash memory.
