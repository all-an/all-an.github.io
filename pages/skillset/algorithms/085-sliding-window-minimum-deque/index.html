Sliding window minimum (deque)

Hard Sliding Window / Deque

Slide a window of size k across an array and report the minimum of every window — the mirror image of "sliding window maximum". For [4, 2, 12, 3, 8, 1] and k = 3 the answer is [2, 2, 3, 1].

Try it

↓

Approach

Use a monotonic deque of indices whose values are in increasing order. For each new element: drop the front index if it has left the window; pop from the back every index whose value is greater than or equal to the new element (they can never be a minimum while the new, smaller one is in the window); push the new index. The front of the deque is the index of the minimum of the current window, so once the first k elements are in, record it after every step.

It is the same code as the sliding window maximum with the comparison reversed. Each index is added and removed at most once, so the loop is linear.

Java

// Monotonic deque of indices (values increasing): the front is the window minimum.
static int[] minSlidingWindow(int[] numbers, int k) {
    int n = numbers.length;
    if (n == 0) return new int[0];
    int[] minimums = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        if (!deque.isEmpty() && deque.peekFirst() <= i - k) {
            deque.pollFirst(); // the front index left the window
        }
        while (!deque.isEmpty() && numbers[deque.peekLast()] >= numbers[i]) {
            deque.pollLast();  // larger values can never be the minimum again
        }
        deque.offerLast(i);
        if (i >= k - 1) {
            minimums[i - k + 1] = numbers[deque.peekFirst()];
        }
    }
    return minimums;
}

JavaScript

// Monotonic deque of indices (values increasing): the front is the window minimum.
function minSlidingWindow(numbers, k) {
  const deque = []; // indices; shift() from the front, pop() from the back
  const minimums = [];
  for (let i = 0; i < numbers.length; i++) {
    if (deque.length > 0 && deque[0] <= i - k) {
      deque.shift(); // the front index left the window
    }
    while (deque.length > 0 && numbers[deque[deque.length - 1]] >= numbers[i]) {
      deque.pop();   // larger values can never be the minimum again
    }
    deque.push(i);
    if (i >= k - 1) {
      minimums.push(numbers[deque[0]]);
    }
  }
  return minimums;
}

Complexity

  • Time O(n) — each index enters and leaves the deque once
  • Space O(k) — the deque holds at most k indices

A related trick: a queue that supports "get minimum" in O(1) can be built from two stacks that each track a running minimum — handy when the window slides over a stream.
