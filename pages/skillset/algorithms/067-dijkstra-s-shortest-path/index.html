Dijkstra's shortest path

Medium–Hard Graph / Shortest Path

Dijkstra's algorithm finds the shortest path from one source node to every other node in a graph whose edge weights are all non-negative — the algorithm behind route planners and network routing.

Try it

↓

Approach

Keep the best-known distance to every node (∞ at first, 0 for the source) and a priority queue of nodes ordered by distance. Repeatedly take the closest unsettled node — because all weights are non-negative, no later path can improve on its distance, so it is final — and relax each outgoing edge: if going through this node gives a shorter route to a neighbour, update the neighbour and queue it.

A negative edge breaks the "closest node is final" argument; use Bellman-Ford there. Stale queue entries (a node queued twice with different distances) are simply skipped when popped with a distance larger than the recorded one.

Java

// Dijkstra with a min-heap of {node, distance}. graph.get(u) holds {v, weight} edges.
static int[] dijkstra(List<List<int[]>> graph, int source) {
    int[] distance = new int[graph.size()];
    Arrays.fill(distance, Integer.MAX_VALUE);
    distance[source] = 0;
    PriorityQueue<int[]> queue = new PriorityQueue<>(Comparator.comparingInt(entry -> entry[1]));
    queue.add(new int[] { source, 0 });
    while (!queue.isEmpty()) {
        int[] closest = queue.poll();
        int node = closest[0];
        if (closest[1] > distance[node]) continue; // stale entry: a shorter route was found later
        for (int[] edge : graph.get(node)) {
            int next = edge[0];
            int candidate = distance[node] + edge[1];
            if (candidate < distance[next]) {      // relax the edge
                distance[next] = candidate;
                queue.add(new int[] { next, candidate });
            }
        }
    }
    return distance;
}

JavaScript

// A minimal binary min-heap of [priority, node] pairs.
class MinHeap {
  constructor() { this.items = []; }
  get size() { return this.items.length; }
  push(item) {
    this.items.push(item);
    let i = this.items.length - 1;
    while (i > 0) { // sift up
      const parent = (i - 1) >> 1;
      if (this.items[parent][0] <= this.items[i][0]) break;
      [this.items[parent], this.items[i]] = [this.items[i], this.items[parent]];
      i = parent;
    }
  }
  pop() {
    const top = this.items[0];
    const last = this.items.pop();
    if (this.items.length > 0) {
      this.items[0] = last;
      let i = 0;
      for (;;) { // sift down
        const left = 2 * i + 1;
        const right = left + 1;
        let smallest = i;
        if (left < this.items.length && this.items[left][0] < this.items[smallest][0]) smallest = left;
        if (right < this.items.length && this.items[right][0] < this.items[smallest][0]) smallest = right;
        if (smallest === i) break;
        [this.items[i], this.items[smallest]] = [this.items[smallest], this.items[i]];
        i = smallest;
      }
    }
    return top;
  }
}

// Dijkstra with a min-heap. graph[u] holds [v, weight] edges.
function dijkstra(graph, source) {
  const distance = new Array(graph.length).fill(Infinity);
  distance[source] = 0;
  const heap = new MinHeap();
  heap.push([0, source]);
  while (heap.size > 0) {
    const [dist, node] = heap.pop();
    if (dist > distance[node]) continue; // stale entry: a shorter route was found later
    for (const [next, weight] of graph[node]) {
      const candidate = dist + weight;
      if (candidate < distance[next]) {   // relax the edge
        distance[next] = candidate;
        heap.push([candidate, next]);
      }
    }
  }
  return distance;
}

Complexity

  • Time O((V + E) log V) — each edge may push one heap entry
  • Space O(V + E) — the graph, distances and heap

Without a heap (scanning for the closest node each round) it is O(V²), which is actually better for very dense graphs. To recover the actual path, remember each node's predecessor whenever you relax an edge.
