Find all subsets (power set)

Hard Backtracking / Bit Manipulation

Generate every subset of a set, including the empty set and the set itself — the power set of [1, 2, 3] has 2³ = 8 subsets: [], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3].

Approach

Backtracking: for each element there are two choices — leave it out or put it in. Recurse through the elements; at every step record the current subset (each path through the decision tree is one subset). Bitmask: a set of n items has 2ⁿ subsets, and the numbers 0 to 2ⁿ − 1 written in binary enumerate them — bit i tells you whether item i is included. It is short and loop-only, but limited to about 30 items in Java.

A third view builds the answer iteratively: start with [[]], and for each new item append a copy of every existing subset with that item added — the count doubles each time.

Java

// Approach 1 — bitmask: every number from 0 to 2^n - 1 picks one subset.
static List<List<Integer>> subsetsBitmask(int[] numbers) {
    int n = numbers.length;
    List<List<Integer>> subsets = new ArrayList<>();
    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) subset.add(numbers[i]); // bit i set: include item i
        }
        subsets.add(subset);
    }
    return subsets;
}

// Approach 2 — backtracking: at each index, record the subset, then try adding each later element.
static List<List<Integer>> subsets(int[] numbers) {
    List<List<Integer>> results = new ArrayList<>();
    backtrack(numbers, 0, new ArrayList<>(), results);
    return results;
}

static void backtrack(int[] numbers, int start, List<Integer> current, List<List<Integer>> results) {
    results.add(new ArrayList<>(current)); // every path is a valid subset
    for (int i = start; i < numbers.length; i++) {
        current.add(numbers[i]);                        // choose
        backtrack(numbers, i + 1, current, results);    // explore with only later elements
        current.remove(current.size() - 1);             // un-choose
    }
}

JavaScript

// Approach 1 — bitmask: every number from 0 to 2^n - 1 picks one subset.
function subsetsBitmask(numbers) {
  const n = numbers.length;
  const subsets = [];
  for (let mask = 0; mask < (1 << n); mask++) {
    subsets.push(numbers.filter((_, i) => mask & (1 << i))); // bit i set: include item i
  }
  return subsets;
}

// Approach 2 — backtracking: at each index, record the subset, then try adding each later element.
function subsets(numbers) {
  const results = [];
  const current = [];

  function backtrack(start) {
    results.push([...current]); // every path is a valid subset
    for (let i = start; i < numbers.length; i++) {
      current.push(numbers[i]);  // choose
      backtrack(i + 1);          // explore with only later elements
      current.pop();             // un-choose
    }
  }

  backtrack(0);
  return results;
}

Complexity

  • Time O(n × 2ⁿ) — 2ⁿ subsets, each built in O(n)
  • Space O(n) — recursion depth beyond the output itself

With duplicate values, sort first and skip an element equal to the previous one at the same recursion level, or the same subset will appear more than once.
