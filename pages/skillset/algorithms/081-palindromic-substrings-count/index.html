Palindromic substrings count

Medium–Hard String / DP

Count how many substrings of a string are palindromes, with different positions counted separately — "abc" has 3 (a, b, c) and "aaa" has 6 (three a, two aa, one aaa).

Try it

↓

Approach

It is the same expand-around-centre idea as the longest palindromic substring, but instead of remembering the longest, count every successful expansion. From a given centre, each step outward that still matches yields one new palindrome (a, then xax, then yxaxy…). Add them all up across all 2n − 1 centres.

A DP table dp[i][j] = (s[i] == s[j]) && (j − i < 3 || dp[i + 1][j − 1]) gives the same count in O(n²) time and space.

Java

// Count palindromes by expanding around every centre.
static int countSubstrings(String text) {
    int count = 0;
    for (int center = 0; center < text.length(); center++) {
        count += expandAndCount(text, center, center);      // odd-length palindromes
        count += expandAndCount(text, center, center + 1);  // even-length palindromes
    }
    return count;
}

// Every step outward that still matches is one more palindrome.
static int expandAndCount(String text, int left, int right) {
    int found = 0;
    while (left >= 0 && right < text.length() && text.charAt(left) == text.charAt(right)) {
        found++;
        left--;
        right++;
    }
    return found;
}

JavaScript

// Count palindromes by expanding around every centre.
function countSubstrings(text) {
  let count = 0;
  for (let center = 0; center < text.length; center++) {
    count += expandAndCount(text, center, center);      // odd-length palindromes
    count += expandAndCount(text, center, center + 1);  // even-length palindromes
  }
  return count;
}

// Every step outward that still matches is one more palindrome.
function expandAndCount(text, left, right) {
  let found = 0;
  while (left >= 0 && right < text.length && text[left] === text[right]) {
    found++;
    left--;
    right++;
  }
  return found;
}

Complexity

  • Time O(n²) — up to n centres, each expanding up to n / 2 steps
  • Space O(1) — only counters and indices

A string of all identical characters is the worst case: every substring is a palindrome, so the answer itself is n(n + 1)/2 and every expansion runs to the end.
