Longest increasing subsequence (DP + binary search, O(n log n))

Hard DP / Binary Search

Find the length of the longest strictly increasing subsequence of an array (elements need not be adjacent) — for [10, 9, 2, 5, 3, 7, 101, 18] it is 4 (for example 2, 3, 7, 101). A simple O(n²) DP exists; patience sorting with binary search brings it to O(n log n).

Approach

O(n²) DP: let length[i] be the longest increasing subsequence ending at index i. It is 1 plus the best length[j] over all earlier j with a smaller value. The answer is the maximum entry.

O(n log n): keep an array tails, where tails[k] is the smallest possible last value of an increasing subsequence of length k + 1. It is always sorted. For each number, binary-search the first entry that is greater than or equal to it and overwrite that entry (or append if none exists). Overwriting keeps the tails as small as possible, which leaves the most room to extend later. The final length of tails is the answer — although tails itself is not necessarily a real subsequence.

Java

// Approach 1 — O(n^2) DP: best length of a subsequence ending at each index.
static int lisQuadratic(int[] numbers) {
    int[] length = new int[numbers.length];
    int best = 0;
    for (int i = 0; i < numbers.length; i++) {
        length[i] = 1; // the number alone
        for (int j = 0; j < i; j++) {
            if (numbers[j] < numbers[i]) length[i] = Math.max(length[i], length[j] + 1);
        }
        best = Math.max(best, length[i]);
    }
    return best;
}

// Approach 2 — O(n log n): tails[k] = smallest last value of an increasing subsequence of length k + 1.
static int lengthOfLIS(int[] numbers) {
    int[] tails = new int[numbers.length];
    int size = 0;
    for (int number : numbers) {
        int low = 0, high = size;
        while (low < high) { // first position whose tail is >= number
            int middle = (low + high) >>> 1;
            if (tails[middle] < number) low = middle + 1;
            else high = middle;
        }
        tails[low] = number;         // replace, or extend when low == size
        if (low == size) size++;
    }
    return size;
}

JavaScript

// Approach 1 — O(n^2) DP: best length of a subsequence ending at each index.
function lisQuadratic(numbers) {
  const length = new Array(numbers.length).fill(1); // each number alone
  let best = 0;
  for (let i = 0; i < numbers.length; i++) {
    for (let j = 0; j < i; j++) {
      if (numbers[j] < numbers[i]) length[i] = Math.max(length[i], length[j] + 1);
    }
    best = Math.max(best, length[i]);
  }
  return best;
}

// Approach 2 — O(n log n): tails[k] = smallest last value of an increasing subsequence of length k + 1.
function lengthOfLIS(numbers) {
  const tails = [];
  for (const number of numbers) {
    let low = 0;
    let high = tails.length;
    while (low < high) { // first position whose tail is >= number
      const middle = (low + high) >> 1;
      if (tails[middle] < number) low = middle + 1;
      else high = middle;
    }
    tails[low] = number; // replace, or extend when low === tails.length
  }
  return tails.length;
}

Complexity

  • Time O(n log n) — one binary search per element (the DP version is O(n²))
  • Space O(n) — the tails array

Searching for the first tail ≥ the number (not just >) is what makes the sequence strictly increasing; using > instead would compute the longest non-decreasing subsequence.
