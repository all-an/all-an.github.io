Valid BST check

Medium Tree / BST

Given a binary tree, decide whether it is a valid binary search tree: for every node, all values in its left subtree are smaller and all values in its right subtree are larger. The trap is checking only each node against its direct children.

Try it

↓

Approach

Comparing a node only with its parent is wrong: in 5 / (1, 4 / (3, 6)) the node 3 is smaller than its parent 4 (fine locally) but sits in 5's right subtree, where everything must exceed 5. So pass down an allowed range: the root may be anything; going left tightens the upper bound to the parent's value, going right tightens the lower bound. Any node outside its range makes the tree invalid.

Alternative: an inorder traversal of a valid BST is strictly increasing — check that each value is larger than the previous one.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

// Pass the allowed (low, high) range down the tree.
static boolean isValidBST(TreeNode node) {
    return isValid(node, Long.MIN_VALUE, Long.MAX_VALUE); // long so Integer.MIN/MAX values still pass
}

static boolean isValid(TreeNode node, long low, long high) {
    if (node == null) return true;
    if (node.value <= low || node.value >= high) return false; // outside the allowed range
    return isValid(node.left, low, node.value)     // left values must be < this node
        && isValid(node.right, node.value, high);  // right values must be > this node
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// Pass the allowed (low, high) range down the tree.
function isValidBST(node, low = -Infinity, high = Infinity) {
  if (!node) return true;
  if (node.value <= low || node.value >= high) return false; // outside the allowed range
  return isValidBST(node.left, low, node.value)      // left values must be < this node
      && isValidBST(node.right, node.value, high);   // right values must be > this node
}

Complexity

  • Time O(n) — each node is checked once
  • Space O(h) — recursion depth equals the tree height

Ask whether duplicates are allowed; here they are not (the bounds are strict). Using long bounds in Java matters when a node holds Integer.MIN_VALUE or MAX_VALUE.
