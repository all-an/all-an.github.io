Anagram check

Easy String / Hashing

Two strings are anagrams if one can be rearranged into the other using every letter exactly once — "listen" and "silent" are, "hello" and "world" are not.

Try it

↓

Approach

Two easy routes. Sort: sort the letters of both strings and compare — anagrams produce identical results (O(n log n)). Count: if the lengths differ, they cannot be anagrams; otherwise count the letters of the first string in a map, then walk the second string decrementing the counts — if a count is already zero (or missing) the strings differ. This is O(n).

Java

// Approach 1 — sort both strings and compare them.
static boolean isAnagramSorted(String a, String b) {
    char[] first = a.toLowerCase().toCharArray();
    char[] second = b.toLowerCase().toCharArray();
    Arrays.sort(first);
    Arrays.sort(second);
    return Arrays.equals(first, second);
}

// Approach 2 — count letters: increment for the first string, decrement for the second.
static boolean isAnagram(String a, String b) {
    if (a.length() != b.length()) return false;
    Map<Character, Integer> counts = new HashMap<>();
    for (char c : a.toLowerCase().toCharArray()) counts.merge(c, 1, Integer::sum);
    for (char c : b.toLowerCase().toCharArray()) {
        int remaining = counts.getOrDefault(c, 0);
        if (remaining == 0) return false; // letter is missing or over-used
        counts.put(c, remaining - 1);
    }
    return true;
}

JavaScript

// Approach 1 — sort both strings and compare them.
function isAnagramSorted(a, b) {
  const normalize = text => [...text.toLowerCase()].sort().join('');
  return normalize(a) === normalize(b);
}

// Approach 2 — count letters: increment for the first string, decrement for the second.
function isAnagram(a, b) {
  if (a.length !== b.length) return false;
  const counts = new Map();
  for (const char of a.toLowerCase()) counts.set(char, (counts.get(char) || 0) + 1);
  for (const char of b.toLowerCase()) {
    if (!counts.get(char)) return false; // letter is missing or over-used
    counts.set(char, counts.get(char) - 1);
  }
  return true;
}

Complexity

  • Time O(n) — counting version; the sorting version is O(n log n)
  • Space O(k) — k distinct characters — O(1) for a fixed alphabet

For lowercase a–z only, an int[26] replaces the map. Clarify whether spaces, punctuation and case count; a common variant strips non-letters first.
