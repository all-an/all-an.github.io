Bellman-Ford algorithm

Medium–Hard Graph / Shortest Path

Bellman-Ford also computes single-source shortest paths, but unlike Dijkstra it allows negative edge weights — and it can detect a negative cycle, where the "shortest" path would be unbounded below.

Approach

Start with distance 0 to the source and ∞ elsewhere. Then repeat V − 1 times: relax every edge — if dist[u] + w < dist[v], improve dist[v]. The reason V − 1 rounds suffice: a shortest path has at most V − 1 edges, and round k is guaranteed to fix every shortest path of k edges.

Then do one extra round. If any edge can still be relaxed, a negative cycle is reachable from the source and no finite shortest path exists. An optimisation is to stop early when a whole round changes nothing.

Java

// Bellman-Ford over an edge list {from, to, weight}. Returns null if a negative cycle is reachable.
static long[] bellmanFord(int nodeCount, int[][] edges, int source) {
    long[] distance = new long[nodeCount];
    Arrays.fill(distance, Long.MAX_VALUE);
    distance[source] = 0;
    for (int round = 1; round < nodeCount; round++) {
        boolean changed = false;
        for (int[] edge : edges) {
            if (distance[edge[0]] != Long.MAX_VALUE && distance[edge[0]] + edge[2] < distance[edge[1]]) {
                distance[edge[1]] = distance[edge[0]] + edge[2];
                changed = true;
            }
        }
        if (!changed) break; // already stable
    }
    for (int[] edge : edges) { // one more round: any improvement means a negative cycle
        if (distance[edge[0]] != Long.MAX_VALUE && distance[edge[0]] + edge[2] < distance[edge[1]]) {
            return null;
        }
    }
    return distance;
}

JavaScript

// Bellman-Ford over an edge list [from, to, weight]. Returns null if a negative cycle is reachable.
function bellmanFord(nodeCount, edges, source) {
  const distance = new Array(nodeCount).fill(Infinity);
  distance[source] = 0;
  for (let round = 1; round < nodeCount; round++) {
    let changed = false;
    for (const [from, to, weight] of edges) {
      if (distance[from] + weight < distance[to]) {
        distance[to] = distance[from] + weight;
        changed = true;
      }
    }
    if (!changed) break; // already stable
  }
  for (const [from, to, weight] of edges) { // one more round: any improvement means a negative cycle
    if (distance[from] + weight < distance[to]) return null;
  }
  return distance;
}

Complexity

  • Time O(V × E) — V − 1 rounds over all edges
  • Space O(V) — just the distance array

Slower than Dijkstra, so use it only when negative weights are possible. It is the basis of distance-vector routing protocols, and of currency-arbitrage detection (a negative cycle in log-transformed exchange rates).
