3Sum

Medium Two Pointers

Find all unique triplets in an array that add up to zero — [-1, 0, 1, 2, -1, -4] gives [-1, -1, 2] and [-1, 0, 1]. It extends Two Sum with sorting and two pointers, and de-duplication is the real challenge.

Approach

Sort the array. For each index i, the problem becomes Two Sum on the rest with target −numbers[i]: put left just after i and right at the end, and move them inward — sum too small → advance left, too big → retreat right, exactly zero → record the triplet.

Uniqueness comes from skipping duplicates: skip an i equal to the previous i, and after a match skip repeated values on the left side. Sorting is what makes duplicates adjacent and the pointer moves valid.

Java

// Sort, fix the first number, then two-pointer the remaining pair.
static List<List<Integer>> threeSum(int[] numbers) {
    int[] sorted = numbers.clone();
    Arrays.sort(sorted);
    List<List<Integer>> triplets = new ArrayList<>();
    for (int i = 0; i < sorted.length - 2; i++) {
        if (i > 0 && sorted[i] == sorted[i - 1]) continue; // skip a repeated first number
        int left = i + 1;
        int right = sorted.length - 1;
        while (left < right) {
            int sum = sorted[i] + sorted[left] + sorted[right];
            if (sum < 0) {
                left++;  // need a larger sum
            } else if (sum > 0) {
                right--; // need a smaller sum
            } else {
                triplets.add(List.of(sorted[i], sorted[left], sorted[right]));
                left++;
                right--;
                while (left < right && sorted[left] == sorted[left - 1]) left++; // skip repeats
            }
        }
    }
    return triplets;
}

JavaScript

// Sort, fix the first number, then two-pointer the remaining pair.
function threeSum(numbers) {
  const sorted = [...numbers].sort((a, b) => a - b);
  const triplets = [];
  for (let i = 0; i < sorted.length - 2; i++) {
    if (i > 0 && sorted[i] === sorted[i - 1]) continue; // skip a repeated first number
    let left = i + 1;
    let right = sorted.length - 1;
    while (left < right) {
      const sum = sorted[i] + sorted[left] + sorted[right];
      if (sum < 0) {
        left++;  // need a larger sum
      } else if (sum > 0) {
        right--; // need a smaller sum
      } else {
        triplets.push([sorted[i], sorted[left], sorted[right]]);
        left++;
        right--;
        while (left < right && sorted[left] === sorted[left - 1]) left++; // skip repeats
      }
    }
  }
  return triplets;
}

Complexity

  • Time O(n²) — O(n log n) sort plus n two-pointer sweeps of O(n)
  • Space O(1) — beyond the sorted copy and the output

O(n²) is the best known for the general problem. The same skeleton generalises to 4Sum (two nested loops plus two pointers, O(n³)) and to "3Sum closest".
