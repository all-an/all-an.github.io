Reconstruct binary tree from traversals

Medium–Hard Tree / Recursion

Given a tree's preorder and inorder traversals (all values distinct), rebuild the tree — preorder [3, 9, 20, 15, 7] with inorder [9, 3, 15, 20, 7] is the tree with root 3, left child 9, and right subtree rooted at 20.

Try it

↓

Approach

The first element of the preorder list is always the root. Find that value in the inorder list: everything to its left belongs to the left subtree, everything to its right to the right subtree — and you also learn the size of each. Then recurse: the next preorder elements (as many as the left subtree has) describe the left subtree, and the rest describe the right subtree.

To avoid the O(n) search for the root in every call, first store each value's inorder index in a hash map. Then consume the preorder list with a single moving index, and pass around the inorder bounds instead of slicing arrays.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

private static int preorderIndex; // next root to consume from the preorder list

static TreeNode buildTree(int[] preorder, int[] inorder) {
    Map<Integer, Integer> inorderIndex = new HashMap<>(); // value -> position, for O(1) lookups
    for (int i = 0; i < inorder.length; i++) inorderIndex.put(inorder[i], i);
    preorderIndex = 0;
    return build(preorder, inorderIndex, 0, inorder.length - 1);
}

// Build the subtree whose inorder values occupy [low, high].
static TreeNode build(int[] preorder, Map<Integer, Integer> inorderIndex, int low, int high) {
    if (low > high) return null;
    TreeNode root = new TreeNode(preorder[preorderIndex++]); // preorder starts with the root
    int split = inorderIndex.get(root.value);
    root.left = build(preorder, inorderIndex, low, split - 1);   // left of the root in inorder
    root.right = build(preorder, inorderIndex, split + 1, high); // right of the root in inorder
    return root;
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

function buildTree(preorder, inorder) {
  const inorderIndex = new Map(inorder.map((value, i) => [value, i])); // value -> position, for O(1) lookups
  let preorderPosition = 0; // next root to consume from the preorder list

  // Build the subtree whose inorder values occupy [low, high].
  function build(low, high) {
    if (low > high) return null;
    const root = new TreeNode(preorder[preorderPosition++]); // preorder starts with the root
    const split = inorderIndex.get(root.value);
    root.left = build(low, split - 1);   // left of the root in inorder
    root.right = build(split + 1, high); // right of the root in inorder
    return root;
  }

  return build(0, inorder.length - 1);
}

Complexity

  • Time O(n) — each node is created once, with an O(1) index lookup
  • Space O(n) — the index map and the recursion stack

The values must be distinct, or the split point is ambiguous. Preorder with postorder alone is not enough to identify a tree in general, but inorder combined with either preorder or postorder always is; postorder works the same way by reading the list from the end.
