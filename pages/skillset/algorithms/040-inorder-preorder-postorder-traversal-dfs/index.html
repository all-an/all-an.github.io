Inorder / preorder / postorder traversal (DFS)

Easy–Medium Tree / DFS

Depth-first traversal explores as deep as possible before backing up. For a binary tree there are three orders, named for when the node itself is visited: preorder (node, left, right), inorder (left, node, right) and postorder (left, right, node).

Approach

The recursion is three lines; only the position of the "visit" line changes. Preorder visits the node first — useful for copying a tree. Inorder visits it between its children — on a binary search tree this yields the values in sorted order. Postorder visits it last — useful for deleting a tree, since children go before their parent.

Recursion depth equals the tree's height, so a very skewed tree can overflow the stack; the iterative versions use an explicit stack instead (shown for inorder below).

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

// Recursive: the position of the "add" line decides the order.
static void preorder(TreeNode node, List<Integer> out) {
    if (node == null) return;
    out.add(node.value);      // node, then children
    preorder(node.left, out);
    preorder(node.right, out);
}

static void inorder(TreeNode node, List<Integer> out) {
    if (node == null) return;
    inorder(node.left, out);
    out.add(node.value);      // left, node, right
    inorder(node.right, out);
}

static void postorder(TreeNode node, List<Integer> out) {
    if (node == null) return;
    postorder(node.left, out);
    postorder(node.right, out);
    out.add(node.value);      // children, then node
}

// Iterative inorder with an explicit stack.
static List<Integer> inorderIterative(TreeNode root) {
    List<Integer> out = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode current = root;
    while (current != null || !stack.isEmpty()) {
        while (current != null) {   // go as far left as possible
            stack.push(current);
            current = current.left;
        }
        current = stack.pop();
        out.add(current.value);
        current = current.right;    // then explore the right subtree
    }
    return out;
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// Recursive: the position of the "push" line decides the order.
function preorder(node, out = []) {
  if (!node) return out;
  out.push(node.value);      // node, then children
  preorder(node.left, out);
  preorder(node.right, out);
  return out;
}

function inorder(node, out = []) {
  if (!node) return out;
  inorder(node.left, out);
  out.push(node.value);      // left, node, right
  inorder(node.right, out);
  return out;
}

function postorder(node, out = []) {
  if (!node) return out;
  postorder(node.left, out);
  postorder(node.right, out);
  out.push(node.value);      // children, then node
  return out;
}

// Iterative inorder with an explicit stack.
function inorderIterative(root) {
  const out = [];
  const stack = [];
  let current = root;
  while (current || stack.length > 0) {
    while (current) {          // go as far left as possible
      stack.push(current);
      current = current.left;
    }
    current = stack.pop();
    out.push(current.value);
    current = current.right;   // then explore the right subtree
  }
  return out;
}

Complexity

  • Time O(n) — each node is visited exactly once
  • Space O(h) — h is the tree height — the recursion or explicit stack (O(n) worst case for a skewed tree)

Level-order (BFS) is the counterpart when you need to go level by level. Pairing two of these orders (e.g. preorder + inorder) uniquely identifies a tree, which is the basis of "reconstruct a tree from traversals".
