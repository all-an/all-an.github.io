Product of array except self

Medium Array / Prefix

Given an array, return a new array where each element is the product of all the other elements — [1, 2, 3, 4] gives [24, 12, 8, 6]. The catch: no division, and O(n) time.

Try it

↓

Approach

The product of everything except numbers[i] equals (product of everything to its left) × (product of everything to its right). Build the answer in two sweeps. Left to right: store in result[i] the running product of the elements before i. Right to left: keep a running product of the elements after i and multiply it into result[i].

Using division (total product ÷ each element) fails as soon as the array contains a zero, which is why the problem forbids it. The two-sweep method handles zeroes naturally, and the output array doubles as the working storage, so no extra arrays are needed.

Java

// Two sweeps: prefix products left to right, then suffix products right to left.
static int[] productExceptSelf(int[] numbers) {
    int n = numbers.length;
    int[] result = new int[n];
    int left = 1;
    for (int i = 0; i < n; i++) {
        result[i] = left;   // product of everything before i
        left *= numbers[i];
    }
    int right = 1;
    for (int i = n - 1; i >= 0; i--) {
        result[i] *= right; // multiply by the product of everything after i
        right *= numbers[i];
    }
    return result;
}

JavaScript

// Two sweeps: prefix products left to right, then suffix products right to left.
function productExceptSelf(numbers) {
  const n = numbers.length;
  const result = new Array(n).fill(1);
  let left = 1;
  for (let i = 0; i < n; i++) {
    result[i] = left;   // product of everything before i
    left *= numbers[i];
  }
  let right = 1;
  for (let i = n - 1; i >= 0; i--) {
    result[i] *= right; // multiply by the product of everything after i
    right *= numbers[i];
  }
  return result;
}

Complexity

  • Time O(n) — two linear sweeps
  • Space O(1) — extra space beyond the required output array

A simpler variant keeps separate prefix[] and suffix[] arrays (O(n) extra space); the running-variable version above is the space-optimized form of the same idea. Mind integer overflow when the values are large.
