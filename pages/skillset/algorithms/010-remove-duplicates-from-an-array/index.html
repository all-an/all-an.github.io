Remove duplicates from an array

Beginner Array / Hashing

Given an array, return a new array with the duplicate values removed — [1, 2, 2, 3, 1] becomes [1, 2, 3]. It is the standard first use of a hash set.

Try it

↓

Approach

Walk the array with a hash set of the values seen so far. If an element is already in the set, skip it; otherwise add it to the set and to the result. Because the set answers "seen before?" in constant time, the whole pass is linear, and the original order is preserved.

If the array is already sorted, duplicates sit next to each other, so a two-pointer sweep can remove them in place with O(1) extra space.

Java

// Approach 1 — built-in: LinkedHashSet drops duplicates but keeps order.
static List<Integer> removeDuplicates(int[] numbers) {
    Set<Integer> unique = new LinkedHashSet<>();
    for (int number : numbers) {
        unique.add(number); // add() ignores values already present
    }
    return new ArrayList<>(unique);
}

// Approach 2 — sorted input: compare each element with the last one kept.
static int removeDuplicatesSorted(int[] sorted) {
    if (sorted.length == 0) return 0;
    int write = 1; // next slot for a new unique value
    for (int read = 1; read < sorted.length; read++) {
        if (sorted[read] != sorted[write - 1]) {
            sorted[write++] = sorted[read];
        }
    }
    return write; // length of the de-duplicated prefix
}

JavaScript

// Approach 1 — built-in: a Set drops duplicates but keeps insertion order.
function removeDuplicates(items) {
  return [...new Set(items)];
}

// Approach 2 — sorted input: compare each element with the last one kept.
function removeDuplicatesSorted(sorted) {
  if (sorted.length === 0) return 0;
  let write = 1; // next slot for a new unique value
  for (let read = 1; read < sorted.length; read++) {
    if (sorted[read] !== sorted[write - 1]) {
      sorted[write++] = sorted[read];
    }
  }
  return write; // length of the de-duplicated prefix
}

Complexity

  • Time O(n) — one pass with constant-time set lookups
  • Space O(n) — the set can hold every element (O(1) for the sorted in-place version)

Set membership relies on equals/hashCode in Java, so custom objects need both overridden to be de-duplicated correctly.
