Number of islands (DFS/BFS on a grid)

Medium Graph / DFS, BFS

Given a grid of 1s (land) and 0s (water), count the islands — groups of land cells connected horizontally or vertically. It is the entry-level graph problem: a grid is a graph in disguise.

Try it

↓

Approach

Scan the grid cell by cell. Each time you meet an unvisited 1, you have found a new island: increment the counter, then run a flood fill (DFS or BFS) from that cell that visits every connected land cell in the four directions and marks it visited so it is never counted again. Marking is easiest by overwriting the cell with 0 ("sinking" the island), which avoids a separate visited array — clone the grid first if you must not modify the input.

Java

// Count islands: every unvisited land cell starts a new flood fill.
static int numIslands(char[][] grid) {
    int islands = 0;
    for (int r = 0; r < grid.length; r++) {
        for (int c = 0; c < grid[r].length; c++) {
            if (grid[r][c] == '1') {
                islands++;
                sink(grid, r, c); // erase the whole island so it is not counted again
            }
        }
    }
    return islands;
}

// DFS: turn this land cell and all connected land into water.
static void sink(char[][] grid, int r, int c) {
    if (r < 0 || c < 0 || r >= grid.length || c >= grid[r].length || grid[r][c] != '1') return;
    grid[r][c] = '0';
    sink(grid, r + 1, c);
    sink(grid, r - 1, c);
    sink(grid, r, c + 1);
    sink(grid, r, c - 1);
}

JavaScript

// Count islands: every unvisited land cell starts a new flood fill.
function numIslands(grid) {
  let islands = 0;
  for (let r = 0; r < grid.length; r++) {
    for (let c = 0; c < grid[r].length; c++) {
      if (grid[r][c] === '1') {
        islands++;
        sink(grid, r, c); // erase the whole island so it is not counted again
      }
    }
  }
  return islands;
}

// DFS: turn this land cell and all connected land into water.
function sink(grid, r, c) {
  if (r < 0 || c < 0 || r >= grid.length || c >= grid[r].length || grid[r][c] !== '1') return;
  grid[r][c] = '0';
  sink(grid, r + 1, c);
  sink(grid, r - 1, c);
  sink(grid, r, c + 1);
  sink(grid, r, c - 1);
}

Complexity

  • Time O(R × C) — every cell is visited a constant number of times
  • Space O(R × C) — worst-case recursion depth when the whole grid is one snaking island

On a huge grid, recursive DFS can overflow the stack; use an explicit stack or a BFS queue instead. The same flood-fill skeleton solves "max area of island", "surrounded regions" and "flood fill".
