House robber (DP)

Medium Dynamic Programming

Houses on a street hold money, but robbing two adjacent houses triggers the alarm. What is the most you can take? For [2, 7, 9, 3, 1] the best is 12 (2 + 9 + 1).

Try it

↓

Approach

At each house you make a choice. If you rob it, you get its money plus the best total from houses up to two back. If you skip it, you keep the best total up to the previous house. So best(i) = max(best(i − 1), best(i − 2) + money[i]). Only the previous two values are needed, so two variables replace the whole table.

Java

// DP with two rolling values: skip this house, or rob it and take the best from two back.
static int rob(int[] money) {
    int twoBack = 0; // best total up to two houses ago
    int oneBack = 0; // best total up to the previous house
    for (int amount : money) {
        int current = Math.max(oneBack, twoBack + amount);
        twoBack = oneBack;
        oneBack = current;
    }
    return oneBack;
}

JavaScript

// DP with two rolling values: skip this house, or rob it and take the best from two back.
function rob(money) {
  let twoBack = 0; // best total up to two houses ago
  let oneBack = 0; // best total up to the previous house
  for (const amount of money) {
    const current = Math.max(oneBack, twoBack + amount);
    twoBack = oneBack;
    oneBack = current;
  }
  return oneBack;
}

Complexity

  • Time O(n) — one pass
  • Space O(1) — two rolling values

The circular-street variant ("House Robber II", where the first and last houses are adjacent) is solved by running this same function twice: once without the first house and once without the last, then taking the larger result.
