Serialize and deserialize a binary tree

Medium–Hard Tree / Design

Turn a binary tree into a string (serialize) and rebuild the identical tree from that string (deserialize) — the way trees are saved to disk or sent over a network. The encoding must record where the missing children are, or the shape is lost.

↓

Approach

Serialize with a preorder traversal, writing each node's value and a marker (here #) for every null child. The markers are what make the string unambiguous — without them, many different trees produce the same list of values.

Deserialize by reading the tokens back in the same order: take the next token; if it is the marker, return null; otherwise create a node and recursively build its left child, then its right child, from the tokens that follow. Because preorder visits a node before its children, the tokens arrive in exactly the order the recursion needs them. A level-order (BFS) encoding works as well and is what LeetCode uses.

Java

static class TreeNode {
    int value;
    TreeNode left, right;
    TreeNode(int value) { this.value = value; }
}

// Preorder with "#" for every missing child.
static String serialize(TreeNode root) {
    if (root == null) return "#";
    return root.value + "," + serialize(root.left) + "," + serialize(root.right);
}

// Consume the tokens in the same preorder to rebuild the tree.
static TreeNode deserialize(String data) {
    Deque<String> tokens = new ArrayDeque<>(Arrays.asList(data.split(",")));
    return build(tokens);
}

static TreeNode build(Deque<String> tokens) {
    String token = tokens.poll();
    if (token.equals("#")) return null;
    TreeNode node = new TreeNode(Integer.parseInt(token));
    node.left = build(tokens);  // the left subtree's tokens come first
    node.right = build(tokens);
    return node;
}

JavaScript

class TreeNode {
  constructor(value, left = null, right = null) {
    this.value = value;
    this.left = left;
    this.right = right;
  }
}

// Preorder with "#" for every missing child.
function serialize(root) {
  if (!root) return '#';
  return root.value + ',' + serialize(root.left) + ',' + serialize(root.right);
}

// Consume the tokens in the same preorder to rebuild the tree.
function deserialize(data) {
  const tokens = data.split(',');
  function build() {
    const token = tokens.shift();
    if (token === '#') return null;
    const node = new TreeNode(Number(token));
    node.left = build();  // the left subtree's tokens come first
    node.right = build();
    return node;
  }
  return build();
}

Complexity

  • Time O(n) — each node is written and read once
  • Space O(n) — the string plus the recursion stack

For a BST the markers are unnecessary: a plain preorder list identifies the tree uniquely, because the ordering rule tells you where each value belongs.
