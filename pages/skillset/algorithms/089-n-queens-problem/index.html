N-Queens problem

Hard Backtracking

Place n queens on an n × n chessboard so that no two attack each other — no two share a row, column or diagonal. Count the solutions or print the boards; for n = 4 there are 2, for n = 8 there are 92.

Try it

↓

Approach

Place one queen per row, top to bottom. For the current row, try each column: a square is safe if no earlier queen shares its column or either diagonal. Recurse to the next row; if a row has no safe square, backtrack — undo the previous placement and try its next column.

Checking safety in O(1) needs three sets: occupied columns, occupied diagonals (cells on the same "↘" diagonal share row − column) and occupied anti-diagonals (cells on the same "↙" diagonal share row + column). Because you place exactly one queen per row, rows never clash.

Java

// Count the N-Queens solutions by placing one queen per row.
static int solveNQueens(int n) {
    return place(0, n, new boolean[n], new boolean[2 * n], new boolean[2 * n]);
}

static int place(int row, int n, boolean[] columns, boolean[] diagonals, boolean[] antiDiagonals) {
    if (row == n) return 1; // all queens placed: one solution
    int count = 0;
    for (int column = 0; column < n; column++) {
        int diagonal = row - column + n; // shifted so the index is never negative
        int antiDiagonal = row + column;
        if (columns[column] || diagonals[diagonal] || antiDiagonals[antiDiagonal]) continue;
        columns[column] = diagonals[diagonal] = antiDiagonals[antiDiagonal] = true;   // place
        count += place(row + 1, n, columns, diagonals, antiDiagonals);
        columns[column] = diagonals[diagonal] = antiDiagonals[antiDiagonal] = false;  // remove
    }
    return count;
}

JavaScript

// Count the N-Queens solutions by placing one queen per row.
function solveNQueens(n) {
  const columns = new Set();
  const diagonals = new Set();     // cells sharing row - column
  const antiDiagonals = new Set(); // cells sharing row + column
  let count = 0;

  function place(row) {
    if (row === n) {
      count++; // all queens placed: one solution
      return;
    }
    for (let column = 0; column < n; column++) {
      if (columns.has(column) || diagonals.has(row - column) || antiDiagonals.has(row + column)) continue;
      columns.add(column);                // place
      diagonals.add(row - column);
      antiDiagonals.add(row + column);
      place(row + 1);
      columns.delete(column);             // remove
      diagonals.delete(row - column);
      antiDiagonals.delete(row + column);
    }
  }

  place(0);
  return count;
}

Complexity

  • Time O(n!) — roughly — pruning cuts the tree far below n^n
  • Space O(n) — recursion depth and the three lookup structures

To print the boards, keep the queen's column for each row and render them at the leaf. A bitmask version — three integers whose set bits mark attacked columns — is the fastest and a favourite follow-up.
