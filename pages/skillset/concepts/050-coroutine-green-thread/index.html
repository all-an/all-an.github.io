Coroutine / green thread

A coroutine is a function that can pause in the middle and later resume exactly where it left off, with its local variables intact. At a suspension point the runtime saves the task's frames and locals — its continuation — onto the heap, releases the thread it was using, and restores them on resume, often on a different thread. That is the whole trick: a paused task costs a heap object instead of a blocked OS thread.
Suspension is cooperative, never preemptive: a task yields only at those points, so a tight CPU loop with no suspension point keeps its thread until it returns. JavaScript spells the points yield and await and Kotlin marks them with suspend; Java's virtual threads make every blocking call one, which is why Loom code can stay plain and sequential while still yielding.
This page is the mechanism inside one task. Its counterpart, Fiber / green thread, is the same runtime seen from the scheduler's side: how many of these paused tasks fit onto how few OS threads.

// Java
// Reads the carrier OS thread that is currently running this virtual thread.
String carrier() {
  String label = Thread.currentThread().toString(); // "VirtualThread[#25]/runnable@worker-2"
  return label.substring(label.indexOf('@') + 1);
}

Thread task = Thread.startVirtualThread(() -> {
  int total = 0;

  for (int step = 1; step <= 3; step++) {
    // 'total' lives in this task's own stack, so it survives every suspension untouched.
    total += step;
    System.out.println("step " + step + " (total " + total + ") on " + carrier());

    try {
      // Suspension point: the frames are copied to the heap, the carrier thread is released
      // to run other tasks, and this continuation is rescheduled 50 ms later.
      Thread.sleep(50);
    } catch (InterruptedException e) {
      Thread.currentThread().interrupt();
      return;
    }
  }

  System.out.println("finished with total " + total);
});

task.join();
// step 1 (total 1) on ForkJoinPool-1-worker-1
// step 2 (total 3) on ForkJoinPool-1-worker-3   <- same task, resumed on another carrier
// step 3 (total 6) on ForkJoinPool-1-worker-3
// finished with total 6
// JavaScript
// A generator is a coroutine with the machinery exposed: yield suspends it, next() resumes
// it, and everything between the two lives on in the generator object.
function* countTo(name, steps) {
  let total = 0; // an ordinary local, but it survives every suspension untouched

  for (let step = 1; step <= steps; step += 1) {
    total += step;
    console.log(`${name} step ${step} (total ${total})`);

    // Suspension point: control returns to the caller right here, and resumes right here.
    yield total;
  }
}

const first = countTo("first", 3);
const second = countTo("second", 3);

// The caller is the scheduler: nothing preempts, each side runs until it yields by itself.
let firstRunning = true;
let secondRunning = true;
while (firstRunning || secondRunning) {
  if (firstRunning) firstRunning = !first.next().done;
  if (secondRunning) secondRunning = !second.next().done;
}
// first step 1 (total 1)
// second step 1 (total 1)
// first step 2 (total 3)
// second step 2 (total 3)
// first step 3 (total 6)
// second step 3 (total 6)
