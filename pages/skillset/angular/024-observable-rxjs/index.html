Observable / RxJS

Observables from RxJS model streams of asynchronous values — HTTP responses, events, timers. Operators like map and switchMap compose them declaratively.

import { interval } from 'rxjs';
import { map, take } from 'rxjs/operators';

// A stream that emits 0,2,4,6,8 then completes
const evens$ = interval(1000).pipe(
  map(n => n * 2),
  take(5),
);

const sub = evens$.subscribe(v => console.log(v));
// sub.unsubscribe() when done to release the stream
