Built-in control flow

Angular 17 introduced block control flow — @if, @for and @switch — a faster, built-in replacement for the structural directives. @for requires a track expression.

@if (user) {
  <p>Hello, {{ user.name }}</p>
} @else {
  <p>Please log in</p>
}

@for (item of items; track item.id) {
  <li>{{ item.name }}</li>
} @empty {
  <li>No items yet</li>
}
