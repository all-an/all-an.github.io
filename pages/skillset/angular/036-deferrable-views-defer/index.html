Deferrable views (@defer)

@defer blocks (v17+) lazily load a section of a template on a trigger — viewport, interaction or idle — with placeholder, loading and error states built in.

@defer (on viewport) {
  <app-heavy-chart [data]="data" />
} @placeholder {
  <p>Scroll to load the chart&hellip;</p>
} @loading (minimum 200ms) {
  <p>Loading&hellip;</p>
} @error {
  <p>Failed to load.</p>
}
