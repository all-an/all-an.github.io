Two-way binding

The "banana in a box" syntax [(ngModel)] combines property and event binding to keep an input and a component property in sync.

<!-- Requires FormsModule; keeps name in sync both ways -->
<input [(ngModel)]="name" />
<p>Hello, {{ name }}</p>

<!-- Equivalent to binding value and (ngModelChange) together -->
<input [ngModel]="name" (ngModelChange)="name = $event" />
