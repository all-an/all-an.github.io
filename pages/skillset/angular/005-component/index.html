Component

A component is a class decorated with @Component that binds a template and styles to a selector. It is the fundamental UI building block; apps are trees of components.

import { Component } from '@angular/core';

@Component({
  selector: 'app-counter',
  standalone: true,
  template: '<button (click)="count = count + 1">Clicks: {{ count }}</button>',
})
export class CounterComponent {
  count = 0; // component state, rendered in the template
}
