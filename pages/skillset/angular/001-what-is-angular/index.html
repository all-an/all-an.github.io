What is Angular

Angular is a TypeScript-based framework for building single-page applications (SPAs). It bundles components, dependency injection, routing, forms and reactivity, maintained by Google.
Every app is a tree of components that the framework renders and keeps up to date.

// A minimal Angular component — the atom of every Angular app
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  standalone: true,
  template: '<h1>Hello, {{ name }}!</h1>',
})
export class AppComponent {
  name = 'Angular';
}
