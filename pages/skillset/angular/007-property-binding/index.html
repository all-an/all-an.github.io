Property binding

Square brackets bind a DOM property to a component expression: [prop]="value". Unlike interpolation it passes the real value — number, boolean, object — not a string.

<!-- Bind element and directive properties -->
<img [src]="avatarUrl" [alt]="user.name" />
<button [disabled]="isSaving">Save</button>
<app-user [user]="currentUser"></app-user>
