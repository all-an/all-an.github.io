State management

As apps grow, shared state needs structure. NgRx offers a Redux-style store; the newer @ngrx/signals SignalStore models state with signals for a lighter, reactive approach.

import { signalStore, withState, withMethods, patchState } from '@ngrx/signals';

export const CounterStore = signalStore(
  withState({ count: 0 }),
  withMethods((store) => ({
    increment() { patchState(store, { count: store.count() + 1 }); },
  })),
);
