TypeScript foundation

Angular is written in and for TypeScript — typed classes, interfaces and decorators are the language of the framework.
Static types catch mistakes at compile time and power the editor tooling you rely on.

// TypeScript building blocks Angular leans on
interface User {
  id: number;
  name: string;
}

// Generics and type inference
function first<T>(items: T[]): T | undefined {
  return items[0];
}

const user: User = { id: 1, name: 'Ada' };
