T6: Exhaustively Test Near Bugs

A bug found in one spot usually means its neighbors are under-tested too — cover them while you're there.

Avoid — one bug found, one test added, moving on
@Test void fixesOffByOneOnLastPage() { /* ... */ }
Prefer — the whole neighborhood gets covered, not just the reported case
@Test void fixesOffByOneOnLastPage() { /* ... */ }
@Test void firstPage() { /* ... */ }
@Test void middlePage() { /* ... */ }
@Test void emptyResultSet() { /* ... */ }
