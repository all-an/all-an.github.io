J2: Don't Inherit Constants

Inheriting an interface just to use its constants leaks those constants into your public API — import them instead.

Avoid — Circle's public API now includes Constants' PI, whether it wants to or not
interface Constants { double PI = 3.14159; }
class Circle implements Constants { /* ... */ }
Prefer — imported explicitly, not inherited
import static physics.Constants.PI;

class Circle { /* ... */ }
