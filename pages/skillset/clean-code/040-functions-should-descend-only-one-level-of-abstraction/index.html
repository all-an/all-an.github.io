G34: Functions Should Descend Only One Level of Abstraction

Every line inside a function should sit one level of abstraction below the function's own name.

Avoid — high-level page building mixed with low-level I/O
void renderPage(Page page) {
    StringBuilder html = new StringBuilder();
    html.append("<html>");
    for (Section s : page.sections) html.append(renderSection(s));
    html.append("</html>");
    System.out.write(html.toString().getBytes());
}
Prefer — one level per function
void renderPage(Page page) {
    String html = buildHtml(page);
    writeToOutput(html);
}
