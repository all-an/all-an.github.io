G31: Hidden Temporal Couplings

If one call must happen before another, make that ordering visible in the code, not just in a comment.

Avoid — recordScore silently requires addStudent to run first
Gradebook gradebook = new Gradebook();
gradebook.addStudent(student);
gradebook.recordScore(student, 95);
Prefer — the return value carries the dependency forward
Gradebook gradebook = new Gradebook();
Enrollment enrollment = gradebook.addStudent(student);
gradebook.recordScore(enrollment, 95); // impossible to call out of order
