T1: Insufficient Tests

If every condition and boundary the code can reach isn't tested, some of them are untested.

Avoid — only the happy path is covered
@Test void divides() { assertEquals(2, divide(4, 2)); }
Prefer — every condition and boundary the code can reach gets a test
@Test void divides() { assertEquals(2, divide(4, 2)); }
@Test void divideByZeroThrows() { assertThrows(ArithmeticException.class, () -> divide(4, 0)); }
@Test void negativeNumerator() { assertEquals(-2, divide(-4, 2)); }
