G35: Keep Configurable Data at High Levels

A constant buried deep in the call stack is hard to find and hard to change — keep it near the top.

Avoid — 3 is buried inside a low-level loop
class RetryPolicy {
    void run() {
        for (int i = 0; i < 3; i++) { /* ... */ }
    }
}
Prefer — one named constant, easy to find and change
class RetryPolicy {
    static final int MAX_RETRIES = 3;
    void run() {
        for (int i = 0; i < MAX_RETRIES; i++) { /* ... */ }
    }
}
