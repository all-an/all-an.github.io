G13: Artificial Coupling

Don't couple two modules that don't actually depend on each other just because it's convenient right now.

Avoid — a general-purpose constant hidden inside an unrelated class
class DeliveryTruck {
    static final int SECONDS_PER_DAY = 86_400; // used by scheduling code, not trucks
}
Prefer — the constant lives with the concept it belongs to
class TimeConstants {
    static final int SECONDS_PER_DAY = 86_400;
}
