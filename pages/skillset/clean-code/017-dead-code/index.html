G9: Dead Code

Dead code is code that never runs. It comes in four shapes: unreachable branches — the if whose condition is impossible, the catch for an exception the call cannot throw, the switch case for a status retired last year; uncalled functions, methods whose last caller disappeared several refactors ago; unused declarations, the field nothing reads and the local nothing consumes; and commented-out code, lines disabled with comment markers instead of deleted, kept "just in case".
The problem is not the wasted bytes — it is that dead code rots. It is never exercised, so it silently drifts out of step with the conventions and the design around it, and the next reader has to work out whether it is a rule they must respect or a corpse they can ignore. Worse, it lends false confidence: a defensive branch that looks like it handles a case is doing nothing at all, a function nobody calls is a trap for whoever calls it first, an unused field looks like state the class depends on, and no one who finds a commented-out block ever dares to be the one who deletes it.
Delete it. Version control remembers it if you ever need it back, and nothing else has to.

Avoid — branches that can never be reached
// Java
public String describe(Order order) {
    if (order == null) {
        return "no order";
    }

    // OrderStatus lost its LAYAWAY member two releases ago; this arm is unreachable.
    switch (order.status()) {
        case PAID:     return "paid";
        case SHIPPED:  return "shipped";
        case CANCELLED: return "cancelled";
        default:       return "layaway";
    }
}

private BigDecimal shippingFor(Order order) {
    if (order.weightInGrams() < 0) {
        // weightInGrams() is validated at construction and can never be negative,
        // so this arm has never run and never will.
        return STANDARD_FEE;
    }
    return order.isExpress() ? EXPRESS_FEE : STANDARD_FEE;
}
Prefer — only the code that actually runs
// Java
public String describe(Order order) {
    if (order == null) {
        return "no order";
    }

    return switch (order.status()) {
        case PAID      -> "paid";
        case SHIPPED   -> "shipped";
        case CANCELLED -> "cancelled";
    };
}

private BigDecimal shippingFor(Order order) {
    return order.isExpress() ? EXPRESS_FEE : STANDARD_FEE;
}
Avoid — a method no one calls and a field nothing reads
// Java
public class InvoiceService {

    private final AuditLog auditLog; // assigned in the constructor, never read again

    public Money total(Invoice invoice) {
        return invoice.lineItems().stream()
            .map(LineItem::amount)
            .reduce(Money.ZERO, Money::plus);
    }

    // Last caller was removed three refactors ago — now unreachable, but
    // still here being maintained, compiled, and read by everyone.
    private Money totalWithLegacyTax(Invoice invoice) {
        return total(invoice).times(LEGACY_TAX_MULTIPLIER);
    }
}
Prefer — delete both; git remembers if they are ever needed again
