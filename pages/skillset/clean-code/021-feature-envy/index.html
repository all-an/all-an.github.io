G14: Feature Envy

A method that reaches into another object's data more than its own belongs on that object instead.

Avoid — InvoicePrinter reaches deep into Order and Customer to do its job
class InvoicePrinter {
    void print(Order order) {
        System.out.println(order.getCustomer().getName() + ": " + order.getTotal());
    }
}
Prefer — the summary moves to the object that owns the data
class Order {
    String summary() {
        return customer.getName() + ": " + total;
    }
}
