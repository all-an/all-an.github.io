G30: Functions Should Do One Thing

A function that does several things should be split into several functions, each doing one.

Avoid — validation, calculation and notification, all in one function
void processOrder(Order order) {
    if (order.items.isEmpty()) throw new IllegalArgumentException();
    double total = 0;
    for (Item i : order.items) total += i.price;
    order.total = total;
    emailService.send(order.customer.email, "Your total is " + total);
}
Prefer — one function per responsibility, orchestrated by a fourth
void processOrder(Order order) {
    validate(order);
    order.total = calculateTotal(order);
    notifyCustomer(order);
}
