G16: Obscured Intent

Code should read as clearly as it's written — dense one-liners and magic constants hide what it's actually doing.

Avoid — packed bit-twiddling with no explanation
int r = (a & 0xFF) << 8 | b & 0xFF;
Prefer — each step named
int highByte = a & 0xFF;
int lowByte = b & 0xFF;
int combined = (highByte << 8) | lowByte;
