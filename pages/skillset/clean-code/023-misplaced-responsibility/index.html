G17: Misplaced Responsibility

Put code where a reader would naturally look for it, not wherever was convenient to write it.

Avoid — PI defined on a report class that happens to use it once
class ReportGenerator {
    static double PI = 3.14159; // belongs on a Circle/Math abstraction, not here
}
Prefer — the constant lives on the concept it describes
class Circle {
    static final double PI = 3.14159;
}
