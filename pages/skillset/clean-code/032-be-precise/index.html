G26: Be Precise

Vague behavior — an unhandled tie, an ignored edge case — becomes a bug the moment someone relies on it.

Avoid — silent about ties, and throws on an empty list
Customer highestSpender(List<Customer> customers) {
    return customers.stream().max(Comparator.comparing(Customer::getTotalSpent)).get();
}
Prefer — the tie-break rule and the empty case are both explicit
Optional<Customer> highestSpender(List<Customer> customers) {
    return customers.stream()
        .max(Comparator.comparing(Customer::getTotalSpent).thenComparing(Customer::getId));
}
