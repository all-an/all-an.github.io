F3: Flag and Selector Arguments

A flag argument is a boolean passed into a function to switch its behaviour — a loud admission that the function does more than one thing.
At the call site the flag is meaningless on its own: render(true) tells the reader nothing, who must open the function to learn what true selects, and the body splits into two tangled paths.
A selector argument is the same smell grown up: an enum, an int or a string that picks one of several behaviours instead of just two. The boolean is merely the two-valued case, and the cure is identical — the extra parameter exists only to avoid splitting a function that was already doing several jobs.
Split it into well-named functions, one per behaviour, so each does a single thing and the call says what it means.

Avoid — a boolean that picks which behaviour runs
// Java
// Two behaviours wearing one name; the body forks on the flag.
public String render(boolean isSummary) {
    if (isSummary) {
        return renderSummaryView();
    }
    return renderFullView();
}

// Call site: what does `true` mean here? You have to go read render().
String html = render(true);
Prefer — one function per behaviour, each named for what it does
// Java
public String renderSummary() {
    return renderSummaryView();
}

public String renderFull() {
    return renderFullView();
}

// Call site reads as plain intent — no flag to decode.
String html = renderSummary();
Avoid — an enum that picks which behaviour runs
// Java
public enum ReportFormat { CSV, PDF, HTML }

// Three behaviours wearing one name; the body forks on the selector.
public byte[] export(Report report, ReportFormat format) {
    switch (format) {
        case CSV:  return toCsv(report);
        case PDF:  return toPdf(report);
        case HTML: return toHtml(report);
    }
}

// Call site: the argument is doing the choosing, not the function name.
byte[] file = export(report, ReportFormat.PDF);
Prefer — one function per behaviour, the selector gone
// Java
public byte[] exportCsv(Report report) { return toCsv(report); }

public byte[] exportPdf(Report report) { return toPdf(report); }

public byte[] exportHtml(Report report) { return toHtml(report); }

// Call site names the behaviour it wants.
byte[] file = exportPdf(report);
