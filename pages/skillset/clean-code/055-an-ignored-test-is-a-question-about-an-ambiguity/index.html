T4: An Ignored Test Is a Question about an Ambiguity

A disabled test should state exactly what's ambiguous about it, so it becomes a question someone can answer.

Avoid — disabled with no explanation of why
@Disabled // TODO: figure out later
@Test void handlesLeapYear() { /* ... */ }
Prefer — the disabled test states exactly what's unresolved
@Disabled("Unclear whether Feb 29 should roll to Mar 1 or stay Feb 28 — ask product")
@Test void handlesLeapYear() { /* ... */ }
