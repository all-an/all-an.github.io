G33: Encapsulate Boundary Conditions

Boundary arithmetic like +1 and -1 scattered through the code invites off-by-one bugs — give it one name, one place.

Avoid — the same +1 computed twice, separately
if (level + 1 < tank.capacity) { /* ... */ }
level = level + 1;
Prefer — computed once, used everywhere it's needed
int nextLevel = level + 1;
if (nextLevel < tank.capacity) { /* ... */ }
level = nextLevel;
