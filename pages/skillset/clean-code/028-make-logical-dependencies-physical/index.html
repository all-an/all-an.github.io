G22: Make Logical Dependencies Physical

If one module's correctness depends on another's internals, express that dependency in code, not in a comment or assumption.

Avoid — relies on PageBuilder using the same page size, by assumption
class HourlyReport {
    int getPageCount() {
        return PAGE_SIZE; // assumes PageBuilder agrees, nothing enforces it
    }
}
Prefer — the dependency is made physical
class HourlyReport {
    int getPageCount() {
        return PageBuilder.PAGE_SIZE;
    }
}
