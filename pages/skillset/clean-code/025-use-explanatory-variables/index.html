G19: Use Explanatory Variables

Break a complex expression into named intermediate variables so each piece explains itself.

Avoid — the condition has to be parsed to be understood
if (a > 0 && b < 100 && (a + b) % 2 == 0) { /* ... */ }
Prefer — each clause is named
boolean isPositive = a > 0;
boolean isBelowLimit = b < 100;
boolean isEvenSum = (a + b) % 2 == 0;
if (isPositive && isBelowLimit && isEvenSum) { /* ... */ }
