G21: Understand the Algorithm

Passing tests isn't proof of correctness — walk through the algorithm by hand before trusting it.

Avoid — green tests hid an integer-division bug
double average(int[] xs) {
    int sum = 0;
    for (int x : xs) sum += x;
    return sum / xs.length; // truncates silently for most real inputs
}
Prefer — the algorithm was actually worked through by hand
double average(int[] xs) {
    int sum = 0;
    for (int x : xs) sum += x;
    return (double) sum / xs.length;
}
