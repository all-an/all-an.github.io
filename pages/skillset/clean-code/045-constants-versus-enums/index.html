J3: Constants versus Enums

A group of related integer constants is better expressed as an enum, which is type-safe and self-describing.

Avoid — plain ints: no type safety, nothing stops an invalid value
static final int SEASON_WINTER = 0;
static final int SEASON_SPRING = 1;
static final int SEASON_SUMMER = 2;
Prefer — type-safe, self-describing, exhaustive in a switch
enum Season { WINTER, SPRING, SUMMER }
