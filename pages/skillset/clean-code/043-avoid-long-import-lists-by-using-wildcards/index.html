J1: Avoid Long Import Lists by Using Wildcards

A long block of single-class imports is noise — a wildcard import says the same thing in one line.

Avoid — five lines to say "we use java.util"
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;
Prefer — one line, same meaning
import java.util.*;
