T9: Tests Should Be Fast

A slow test suite gets run less often — keep tests fast so nothing discourages running them.

Avoid — a real network/database round trip on every run
@Test void savesUser() {
    Thread.sleep(2000); // waits on a real database
    repository.save(new User("Ada"));
}
Prefer — an in-memory fake keeps the same test near-instant
@Test void savesUser() {
    InMemoryRepository repository = new InMemoryRepository();
    repository.save(new User("Ada"));
}
