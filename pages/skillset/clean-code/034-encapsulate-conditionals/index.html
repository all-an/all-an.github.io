G28: Encapsulate Conditionals

Extract a compound boolean expression into a well-named function instead of making the reader parse it inline.

Avoid — the reader has to parse the condition to know what it means
if (timer.hasExpired() && !timer.isRecurrent()) { /* ... */ }
Prefer — the condition names itself
if (shouldStopTimer(timer)) { /* ... */ }

boolean shouldStopTimer(Timer timer) {
    return timer.hasExpired() && !timer.isRecurrent();
}
