G7: Base Classes Depending on Their Derivatives

The whole point of splitting a base class from its derivatives is that the base can be understood, tested and deployed without knowing the derivatives exist. The moment the base mentions a subclass by name, that independence is gone.
The usual symptom is a chain of instanceof checks or a switch on a type name inside the parent: every new subclass forces an edit to the class it was supposed to extend, and the base has to be redeployed along with it. It is inheritance pointed backwards.
Push the varying behaviour into an abstract method the derivatives override. The base then depends only on the abstraction it declared, and a new subclass is a new file rather than a change to an old one.

Avoid — the base class knows every subclass by name
// Java
public abstract class Employee {
    private static final BigDecimal MONTHS_PER_YEAR = BigDecimal.valueOf(12);

    public BigDecimal monthlyPay() {
        // Every new employee type means editing — and redeploying — this base class.
        if (this instanceof SalariedEmployee salaried) {
            return salaried.annualSalary().divide(MONTHS_PER_YEAR, RoundingMode.HALF_UP);
        }
        if (this instanceof HourlyEmployee hourly) {
            return hourly.hourlyRate().multiply(BigDecimal.valueOf(hourly.hoursWorked()));
        }
        throw new IllegalStateException("Unknown employee type: " + getClass());
    }
}
Prefer — the base declares the abstraction and knows nothing else
// Java
public abstract class Employee {
    // What every employee must answer; how it is answered is the derivative's business.
    public abstract BigDecimal monthlyPay();
}

public class SalariedEmployee extends Employee {
    private static final BigDecimal MONTHS_PER_YEAR = BigDecimal.valueOf(12);

    @Override
    public BigDecimal monthlyPay() {
        return annualSalary.divide(MONTHS_PER_YEAR, RoundingMode.HALF_UP);
    }
}

public class HourlyEmployee extends Employee {
    @Override
    public BigDecimal monthlyPay() {
        return hourlyRate.multiply(BigDecimal.valueOf(hoursWorked));
    }
}

// A commissioned employee is now a new file, with no edit to Employee at all.
