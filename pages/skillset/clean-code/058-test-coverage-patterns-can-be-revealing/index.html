T8: Test Coverage Patterns Can Be Revealing

Reading which lines a coverage report marks as covered can reveal dead code or an unreachable condition.

Avoid — a typo makes the second branch unreachable, unnoticed
if (status == OK || status == OK) { /* ... */ }
Prefer — the coverage report flags the dead branch, exposing the typo
if (status == OK || status == RETRY) { /* ... */ }
