N2: Choose Names at the Appropriate Level of Abstraction

A name should match the abstraction level of the code around it, not leak a lower-level implementation detail.

Avoid — "phoneNumber" leaks a physical-modem assumption
interface Modem {
    void dial(String phoneNumber);
}
Prefer — works for a phone line, cable, or anything else
interface Modem {
    void connect(String connectionLocator);
}
