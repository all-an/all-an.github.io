T7: Patterns of Failure Are Revealing

When several tests fail together, look for what they share — that shared thing is usually where the real bug is.

Avoid — three unrelated-looking failures, each investigated on its own
test_saveToDisk     FAILED
test_saveToNetwork  FAILED
test_saveToCache    FAILED
Prefer — noticing all three call the same serialize() reveals the one real bug
// All three failing tests share one thing: they all call serialize().
// That's where the actual bug lives — not in three separate places.
