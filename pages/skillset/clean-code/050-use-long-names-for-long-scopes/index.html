N5: Use Long Names for Long Scopes

A name's length should match its scope — short names for tight scopes, descriptive names for long-lived ones.

Avoid — i still means something fifty lines into the loop body
for (int i = 0; i < 10; i++) {
    // ... fifty lines later ...
    doSomething(i); // what is i, again?
}
Prefer — the name still makes sense far from its declaration
for (int retryAttempt = 0; retryAttempt < 10; retryAttempt++) {
    // ... fifty lines later ...
    doSomething(retryAttempt);
}
