G10: Vertical Separation

Distance on the page is distance in the reader's head. Variables and functions should be defined close to where they are used: a local variable declared just above its first use, a private function defined just below the one that calls it.
The old habit of hoisting every declaration to the top of the method is a leftover from languages that demanded it. Today it only means the reader meets a list of names with no idea what they are for, then has to hold all of them in mind while scrolling to find out. The same goes for a helper parked hundreds of lines away from its only caller — following the code becomes a hunt through the file.
Keep the definition and the use within one screen of each other, and reading the code becomes a straight line down the page rather than a search.

Avoid — declarations hoisted far from where they matter
// Java
public Report buildReport(Query query) {
    // A wall of names, none of which mean anything yet.
    List<Row> rows;
    BigDecimal total;
    String title;
    LocalDate generatedOn;

    rows = database.fetch(query);

    title = query.name() + " — " + rows.size() + " results";

    total = rows.stream()
        .map(Row::amount)
        .reduce(BigDecimal.ZERO, BigDecimal::add);

    generatedOn = clock.today();

    return new Report(title, rows, total, generatedOn);
}

// ... four hundred lines of unrelated code ...

// The only caller is buildReport(), far above and out of sight.
private String formatTitle(Query query, int rowCount) { /* ... */ }
Prefer — each name introduced where it is first needed
// Java
public Report buildReport(Query query) {
    List<Row> rows = database.fetch(query);

    String title = formatTitle(query, rows.size());

    BigDecimal total = rows.stream()
        .map(Row::amount)
        .reduce(BigDecimal.ZERO, BigDecimal::add);

    LocalDate generatedOn = clock.today();

    return new Report(title, rows, total, generatedOn);
}

// Defined directly below its caller, so reading continues straight down the page.
private String formatTitle(Query query, int rowCount) {
    return query.name() + " — " + rowCount + " results";
}
