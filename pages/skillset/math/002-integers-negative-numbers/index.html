Integers & negative numbers

Arithmetic

The idea

The natural numbers only count forward: 1, 2, 3, …. But some things go the other way — a temperature below freezing, a bank balance in debt, a floor of a building underground. To describe them we extend counting backwards past zero. The result is the integers:

… −3, −2, −1, 0, 1, 2, 3, …

Every natural number n now has an opposite, −n, and the two cancel each other out: n + (−n) = 0. Zero is its own opposite. The whole set is written ℤ, from the German Zahlen, "numbers".

The number line and absolute value

Picture the integers as evenly spaced points on a line, with 0 in the middle, positives to the right and negatives to the left. Bigger numbers are further to the right, so −7 < −2: owing seven is worse than owing two.

The absolute value |x| forgets the direction and keeps only the distance from zero. Both 3 and −3 are three steps from zero, so |3| = |−3| = 3. The distance between any two integers is |a − b|.

|x| = x if x ≥ 0 |x| = −x if x < 0

Rules for signs

Adding a positive number moves right along the line; adding a negative number moves left. Subtracting is just adding the opposite:

a − b = a + (−b) 5 − 8 = 5 + (−8) = −3

Multiplying follows a sign rule: like signs give a positive, unlike signs give a negative.

(+)(+) = + (−)(−) = + (+)(−) = − (−)(+) = −

Why is a negative times a negative positive? Watch a pattern: 3×(−2) = −6, 2×(−2) = −4, 1×(−2) = −2, 0×(−2) = 0. The answers climb by 2 each time, so the next step must continue to (−1)×(−2) = +2. The rules for negative numbers and zero were first written down by the Indian mathematician Brahmagupta in 628 CE.
