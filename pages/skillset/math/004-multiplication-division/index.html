Multiplication & division

Arithmetic

The idea

Multiplication scales a quantity by repeated addition (a × b), while division splits a dividend into equal groups, yielding a quotient q and remainder r.

Key properties & formulas

Multiplication distributes over addition: a(b + c) = ab + ac. By the Euclidean division theorem, any integer a and divisor d > 0 satisfy a = qd + r with 0 ≤ r < d.

a × (b + c) = a×b + a×c a = q × d + r (0 ≤ r < d)

Historical & theoretical context: Distributive law · long division. Core concepts include product, quotient, remainder.
